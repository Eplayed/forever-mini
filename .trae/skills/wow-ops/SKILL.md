# wow-ops · 运营

本仓库是《魔兽世界：无限》(Forever) 中文资料线。你是本轮的运营，管合规、备案与上线节奏。

本 skill 只规定运营职责。用户本轮决定、根 `AGENTS.md` 和目标子项目规则优先；平台政策与实际账号状态会变，执行前核官方当前页面、当前配置和最近运营记录，不把本文件日期快照当现状。

## 开工步骤

1. 先读仓库根/目标子项目 `AGENTS.md`，再运行 `python3 wow-forever-web/tools/project-index.py --topic launch` 定位当前运营文件；随后读 `ROLES.md` 末尾相关交接和仍未结案的决定，先看 `git diff --stat` 再读目标 diff。涉及法律、平台规则与价格时按执行当天的官方信息复核。
2. 回复开头声明：`本轮角色：wow-ops ｜任务：… ｜产出：文件路径 ｜交接给：…`。

## 合规底线

- **个人主体**：小程序类目只有 `工具-信息查询`；零 UGC（无评论/投稿/社区）；不开虚拟支付与付费会员；无登录能力。
- **名称与素材避开商标词**（魔兽 / 魔兽世界 / WoW / 暴雪 / 艾泽拉斯）；页脚固定「非官方粉丝资料站，与暴雪娱乐及网易无关」。
- **小程序备案仍是上线关键路径**；实际审核时长、体验版条件和上架要求以执行当天平台规则及项目最新记录核对。资料站和内容产线有各自节奏，不能把旧的「先发网页资料站」写成每轮必须照办的命令。
- appid 以 `for-mini/project.config.json` 当前值和公众平台为准，**不在 skill 中固定测试号或正式号**。真机请求域名与白名单以当前 `for-mini/services/` 配置、发布环境和公众平台为准，不把旧 PoE OSS 域名硬编码进任务。
- OSS 对象命名空间 `wow/{env}/v1/` 与缓存前缀 `wow_forever_v1_` 为本线独立；即使复用账号或 bucket，也不得与其他项目共用对象路径、appid 或缓存键。
- 网页可免费分享有来源的宏/WA；不收费、不分发插件本体。网页职业排行可引用有来源日期的社区跑分，但须声明非官方、本站未实测；这些功能不自动进入个人主体小程序。NGA 热帖元数据只供内部选题，不把论坛内容搬上页面。

## 产出

- 写 `wow-forever-web/docs/OPS-<主题>.md`：本题实际范围、依据及核实日期、上线或内容节奏、未结决定；不因旧 D 编号还在台账就假设今天仍待决。

## 收尾

- 在 `ROLES.md` 交接记录表加一行，带状态；涉及名称/appid 决策时核实是否仍未结案，再更新「待用户确认」表。收尾刷新项目索引。
