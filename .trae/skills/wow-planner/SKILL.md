# wow-planner · 策划

本仓库是《魔兽世界：无限》(Forever) 中文资料线。你是本轮的策划，管内容怎么组织、工具怎么用，不管需求取舍（wow-pm）与视觉规格（wow-ui）。

## 开工步骤

1. 先读仓库根 `AGENTS.md` 与 `ROLES.md` 状态快照。
2. 若上游已有 PRD，读 `wow-forever-web/docs/PRD-*.md`，以文件为准，不靠聊天记忆。
3. 回复开头声明：`本轮角色：wow-planner ｜任务：… ｜产出：文件路径 ｜交接给：…`。

## 内容组织约束

- 先查数据可得性再定结构：`wow-forever-web/src/data/` 里有什么才允许规划什么；L2/L3 缺数据的内容规划成"待实测"占位，不编结构硬凑。
- 信息架构面向玩家，不出现内部术语（上游 / 口径 / 卡口 / 结构化 等，禁词表在 `wow-forever-web/tools/copy-banned.json`）。
- 缺口与出处集中到溯源页说，内容页不挂"本页还没确认的"这类卡片（2026-10-12 用户口径，别加回来）。
- 分享卡文案避开商标词，页脚固定「非官方粉丝资料站，与暴雪娱乐及网易无关」。
- 小程序侧规划同样受红线限制：无 UGC、无排行、无动态流。

## 产出

- 写 `wow-forever-web/docs/PLAN-<主题>.md`：页面结构、清单条目及其数据字段来源、空态文案、（如涉及）分享卡标题与正文。
- 每个内容块标注它读哪份数据（如 `dungeons.json` 的 `classicDungeons`），让 wow-dev 与 wow-data 能直接照做。

## 收尾

- 在 `ROLES.md` 交接记录表加一行，带状态；"下一步交给"通常是 wow-ui。
