## 5. 过程中真正发现的几件事（都不是"改期望改绿"）

1. **`wx.request` 在微信运行时里确实回传 `ETag`**（键名就是 `ETag`，还带 `Content-Length`）。R1 的 §8.1 把这条列为最大未验项，现在有了实证：响应头里有 `Cache-Control / Content-Length / Date / ETag / Last-Modified / x-fake-oss / appservice-request-id`。客户端的 `headerGet()` 按小写比对键名，所以两种大小写都吃得下。
2. **`Cache-Control: immutable` 会让"换服务端内容"看起来失效**。批次文件按设计发一年期 immutable，模拟器照头缓存后，同一 URL 换成篡改版也读不到——第一版 C 组断言因此一直"通过不了"。这不是校验失效，是缓存生效；测法改成**每个场景换一个端口**（URL 变了才是新资源），并在 `oss-fake-server.js` 上留 `FAKE_OSS_NOCACHE=1`。这条同时说明：**真发批次后想让线上立刻换新批，只能靠指针（max-age=60），批次文件本身永远不换字节。**
3. **首页会记住已经不存在的副本 id**。快照里查不到的 id 会在「最近查过的副本」里挂成一排原始编号，所以 `syncRecent()` 读到快照里没有的 id 就顺手把存储清干净。
4. **详情页的"最近看过"不能等分片取回才记**。断网首用时详情根本没取到，结果首页一直是空的；改成索引里找到条目就记，取分片只是补内容。
5. **往 `for-mini/` 里写截图会触发热重载**。开发者工具开着 `compileHotReLoad`，脚本把截图写进项目目录 → 小程序被打回首页 → 后面所有"导航后路由没到位"全是假红。改成先写 `/tmp` 再拷进 `docs/screenshots/`。
6. **本机的 automator 拿不到页面元数据**：`currentPage()` / `page.$()` / `element.tap()` 全部超时或报 `getPageMetaByWebviewId` 解构失败（automator 0.12.1 与 IDE 3.17.0 不匹配；`checkVersion` 还要打桩跳过）。所以脚本走 `evaluate` 通道：导航、读页面实例自己的 `data`、调页面自己的事件处理器、截图。`mockWxMethod('request')` 在这台机器上直接报 `wx.request not exists`，才改用本地假 OSS 而不是 mock。
7. **筛选计数差点按"抄下来的数"写死**。中途两条断言（"全部"按钮应等于结果数、各可信度之和应等于结果数）其实是我把口径写错了：分面计数的正确规则是"同一维度里每个按钮＝选它会得到几座"，所以选中项计数==结果数、非选中几项之和==「全部」。断言按这条规则重写，页面代码没改。

## 6. 没验到的（不要当成已通过）

1. **真实点击**。`element.tap()` 在本机稳定超时，所以搜索框输入、筛选按钮、收藏星、卡片跳转都是**调用页面自己的处理器 + 合成事件对象**验的逻辑；WXML 绑定本身（`bindtap`/`catchtap`/`bindinput`、`data-` 传参、点星不冒泡进卡片）必须在开发者工具里手点一遍，或用真机。
2. **分享卡片冷启动**。`onShareAppMessage` 返回的路径写了（`/pages/dungeon/index?id=…`），但没真发过微信会话：本轮没登录真 appid（`touristappid`），也没做真机冷启动。假 id 的兜底分支已验（A 组）。
3. **真机与域名白名单**。iOS/Android 上 `wx.request` 的响应头是否同样回传 `ETag`、`immutable` 缓存行为、storage 10 MB 上限与隐私模式下 `getStorageSync` 抛错，都没验——这些只在模拟器和 Node 桩里跑过。要等独立 appid + 把 bucket 域加进 request 合法域名。
4. **线上批次没发**。B–F 组的"线上"是本地假 OSS（真 HTTP 语义、真 ETag），不是阿里云那个 bucket；`upload` / `verify` / `rollback` 本轮一次都没对真 Bucket 执行（站主口径：先报备再用钥匙）。
5. **主包体积没量过实际值**。只卡了"三份快照合计 45.3 KB ≤ 60 KB"这一层预算；`oss-preview/`、`oss-build/`、`docs/`、`.oss-env` 都已在 `packOptions.ignore` 里排除，但没在开发者工具里读"代码包大小"面板的实际数字（要登录 appid 才出全量统计）。
6. **详情/掉落没有主包快照**（设计上就不打），所以断网首用只能看索引字段——这是有意的限制，界面按 PRD 写了"要联网才能取"。
7. **图片一个都没用**：客户端原画、首领头像、区域底图、物品图标都不在这一单，索引里带的 `iconKey` 也只是键。掉落表按红线不写百分比，界面已固定这句。
