# 冒险清单与跑本规划验证

日期：2026-11-12。角色：wow-dev。状态：本地实现完成，候选批次 `b15c45e8000d`。

按站主修订，小程序用于离开电脑时安排下次跑本。副本详情可以设为下次目标，首页和冒险清单可以打开该本的任务接取路线。接取路线按地区整理，显示等级门槛、NPC 或开启物品、已有坐标和前置。阵营筛选保留未标阵营的任务。首版保存一个下次跑本计划，移除了逐条任务状态和角色档案。

装备目标可从配装和副本掉落加入。清单按物品 ID 去重，保留多个来源，计划副本可掉的目标排在前面。点来源直达已展开的掉落项。计划、阵营选择与装备目标保存在本机。

- 数据候选包含原有 396 条任务，146 条有可下发的阵营信息，144 条有前置文本，49 条记录物品开启。保留接取点与坐标，缺项沿用现有事实口径。
- `export-mini.js` 与本地 beta 构建通过。主包快照 57.2 KB，单本详情分片最大 19.9 KB。现有副本详情请求包含任务，首页读取本机计划和装备摘要，有装备目标时才在清单页读取一次现有掉落索引。
- 微信官方编译器编译 20 份 WXML 与 21 份 WXSS。JS 语法检查通过。用本地候选批次与页面处理器验证保存和取消计划、首页跳转、阵营筛选、旧版任务数据、装备去重、已获得切换、存储失败、重开恢复。首页与空清单没有发起掉落索引请求。
- 分发契约 245 条通过，1 条失败是本机已有的 PoE 凭据路径判定，报 `.oss-env`。该检查不发送请求。
- 调整前在 375px 微信开发者工具实点验证了装备加入和掉落直达，仍适用的 [BIS 加入装备目标实拍](screenshots/adventure-2026-11-12/01-bis-added.png) 留档。用户停止界面操作后完成了本次减法。简版计划卡、任务路线和阵营按钮尚需模拟器实点与真机验证，未使用旧界面截图替代。

数据与小程序代码均在本地。发布时新版代码需与候选数据配套才能显示已有阵营与前置。
