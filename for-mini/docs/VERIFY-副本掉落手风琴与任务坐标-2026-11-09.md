# 副本掉落手风琴与任务接取坐标

2026-11-09，北京时间。主角色 wow-dev，接取数据由 wow-data 核对。

- 参考 Anthropic 的 `frontend-design`，在现有暗色、暖金和品质令牌上做副本档案。头像、首领名和掉落数组成整行触区，展开后显示同组掉落。装备属性、装等、卖价与物品编号在原行展开。首领同一时刻只展开一个，切换首领会收起已展开的装备。
- 按首领 ID 归组，旧批次允许按唯一首领名归组。无法挂到名单的条目集中在「其他掉落」，保留原首领标签。独立反查和物品页的既有链接可访问，反查或配装点回副本会自动展开并高亮相应物品。
- 任务卡分开显示接取人、地点与坐标所属地图。396 条任务中 346 条有接取人，370 条有地点，187 条有坐标。领主大厅四条均有具体接取地点，三条有数字坐标，鬼魅随从为西翼第二间房、坐标待实测。可核出处和坐标异值见 [数据记录](../../wow-forever-web/docs/DATA-副本任务接取位置-2026-11-09.md)。
