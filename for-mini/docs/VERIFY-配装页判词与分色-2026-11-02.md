## 二、判词撤了哪些、留了哪些

**撤（界面出口）**：列表行那颗 `两家一致 / 两家分歧 / 另一家没列` 角标、弹层里同一颗、
`CMP_CN` 常量、`.cmp / .cmp-same / .cmp-diff` 三条样式。整页 grep 这三个词已经 0 命中。

**留（事实层）**：分发层 `bis/set/*.json` 里逐格的比较结果 `alt[].state` 一条没删，
弹层照样把另一份名单那一件列出来，只把标签换成中性的一句
**「另一份名单在这一格列的是：防御者的皮头盔 装等 30」**；那一格只有主源列了装备时写**「另一份名单没单列这一格的装备」**。

为什么不撞红线：红线要的是"两家只并列不裁决、本站不排强弱"。那三个词是本站贴的一层标签，
换成"是谁列的"之后并列关系反而更清楚——**数据没减，减的是措辞**。
网页配装页不需要跟着改：那三个词在网页端本来就没出现过（`grep` 过 `app/src`）。

# 追加：站主真机两张图之后的第二轮（同一天下午）

## 一、「bis 装备图没显示」= 线上还停在 10-27 那一批，不是页面取不到

真机那一屏写的是**「分发层没给这一套（warrior · 联盟）登记过图」**——这是页面在 `posterLink` 里查不到键时
说的那句，不是取图失败。回线上核：

```
GET wow/beta/v1/manifest.json             → buildId d25932f1c7a3（10-27 那一批）
GET …/builds/d25932f1c7a3/bis/index.json  → 顶层键里没有 posterLink，也没有 dropLink
```

上一轮把 76 张图发上了 `assets/`，但**带 `posterLink` 的那份索引还在本地批次里没传**——
正是上一轮结尾写的"图上线 ≠ 玩家看得到"。现象与预期一致，缺的是那一次 `upload`。

**这一传会带上什么**（按逻辑文件名对拍；按路径比会因 buildId 全部"看起来变了"，那是假账）：
线上 9 个入口文件**内容全都变了**，本地另有多出的 2 个：`macros/index.json`、`professions/index.json`；
索引层合计 **418 KB**（分片另计）。数据核对日期从线上的 **2026-10-26** 跳到本地的 **2026-11-01**，
等于把 11-01 那次跟版（客户端 70707、DF 首领名单、GI 配方快照…）整批发出去。
**这一步等站主点头**：它是发数据批次，会连带工作树里别条线未提交的 `app/data` 改动。

## 二、「装备文字区分不明显」有数值原因：我给来源选的那档蓝，和稀有装备名是同一个色

量了 RGB 三分量差之和：

| 候选 | 与六个品质色最近的一档 | 距离 |
| --- | --- | --- |
| `--azure`（上一版来源档） | **`--q3` 稀有装备名** | **34** ← 就是它 |
| `--gold`（这一版来源档） | `--q0` 灰（配装页几乎不出现） | 114 |
| `--txt-muted`（这一版属性档） | `--q0` 灰 | 37（属性档本该退后） |

34 意味着"来源"那一行和"又一个装备名"在屏幕上是同一件事。而且 `--azure` 对底对比度 7.28、
`--txt-dim` 是 8.8，两行只是"都挺亮"，没有主次——站主看到的"不明显"就是这个。

**换档后的规格（三个通道一起给，不靠色相单打）**：

| 档 | 令牌 | 对底对比度 | 形状 |
| --- | --- | --- | --- |
| 装备属性（装等 / 品质档 / 可换 N 件 / 弹层属性行） | `--txt-muted` | 5.81 | 无 |
| 从哪来（副本 / 任务 / 专业 / 商人） | `--gold` | 7.57 | **左侧一条 3rpx 竖线** `--gold-line` |
| 可点记号「看这座本 ›」 | `--gold-hi` | 11.09 | 箭头符号 |

装备名照旧走品质色（那是游戏通用语言，不动）。图例改成
「名字颜色按品质走 · 灰的是装备给的 · 金的是从哪来的（那条竖线就是来源行）·「可换」是这一格还列了几件」。
**门禁加了一条算得出来的**：来源档与六个品质色的最小距离必须 ≥ 100（实测 114），
并把"azure 当年只有 34"写进断言文案——下次再挑一个贴着品质色的颜色，回归当场红，不用等真机截图。

## 三、这一轮我自己的三次失手（都记下来，都是一类问题）

1. **全文件字符串替换改一个变量名**，而那个名字在同一文件里本来就有第二处（546 行读 `app.wxss` 的那份）
   → `SyntaxError: Identifier 'tokensCss' has already been declared`，整轮回归没起来（`rc=2`，日志里只剩一行 rc）。

   那个扫描是全文正则、不剔注释。要么注释里只写令牌名，要么改扫描器；这次选了前者。

另外还有一条**上一轮已经犯过、这一轮才看清影响面的**：`断网有缓存` 那条历史红一发作，
