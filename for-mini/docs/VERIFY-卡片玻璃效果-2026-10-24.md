# 验证记录 · 首页与副本页卡片的玻璃效果（2026-10-24）

本轮角色：wow-dev ｜指令：「首页和副本页卡片添加玻璃效果，让页面的背景更容易看到。」
上一版（2026-10-23）只把卡片不透明度降到 0.72，量出来卡片内外只差 6 个级别 —— 等于没透，
所以这一轮不是再拧一个数，而是把"玻璃"补齐三件：**面色更透 + 顶部一道反光沿 + 身后画面虚化**，
并且把压暗底图那一层松开一点（不然卡片再怎么透，透出来的也是一块纯色）。

## 1. 改了什么（只 4 个样式文件，没有数据与逻辑改动）

| 位置 | 改动 |
| --- | --- |
| `for-mini/app.wxss` | `--panel-glass` 0.72 → **0.5**；`--scrim-page` 0.88 → **0.76**；新增 `--glass-sheen`（顶部 2px 反光沿 + 底部压暗）、`--glass-blur`（`blur(14px) saturate(112%)`）、`--glass-line`（更亮的玻璃边框） |
| `pages/home/index.wxss` | `.cd` / `.entry` / `.race` / `.mini` 四层玻璃：`background: var(--glass-sheen), var(--panel-glass)` + `backdrop-filter: var(--glass-blur)` |
| `pages/dungeons/index.wxss` | `.drow` / `.card` 同款；`.drow` 边框从 `--line` 换成 `--glass-line`；**搜索框不动**（见 §3） |
| `pages/classes/index.wxss` | `.card` 同款（站主本轮只点名两页，这一页吃同一个令牌，不给它虚化就会和另两页明显不一致，所以按同款改；不认可只回退这一处） |

页面 wxss 里仍然一个裸色值都没有，颜色全部回 `app.wxss`。

## 2. 量出来的数（不是"看着像"）

方法：同一页拍两帧 —— 铺上底图 / 用 `setData({bgUrl:''})` 撤掉底图，卡片内容与位置完全一样，
只有"身后有没有那张图"这一个变量。截图缩放与视口原点都不写死：缩放按 `.pagebg` 的 CSS 宽去除以
像素宽算（本次 586/390 = 1.503），视口原点按两帧的差找第一处"整行都不同"的行（本次落在第 137 行）。

**卡片内部蓝色通道的差 = 底图透进来的量**（`py_glass` 取整块卡片内像素逐点差的中位数，
卡片里那块副本缩略图在两帧里是同一份像素，不会把读数带偏）：

| 取样块 | 上一版（0.72 + 压暗 0.88） | 这一版（0.5 + 压暗 0.76 + 虚化） |
| --- | --- | --- |
| 首页倒计时卡 `.cd` | 约 7 | **22** |
| 副本列表第一行 `.drow` | 约 7 | **15** |
| 首页入口卡 `.entry`（自带一张卡图盖着） | 0 | **0**（负对照，符合预期） |
| 首页种族卡 `.race`（在底图范围之外，图只铺顶部约 703rpx） | 0 | 0（负对照） |

**逐行文字的真实对比度**（不是整卡最亮点，而是每个文字元素自己那一小块的主色，
主色 = 该块里最常见的颜色，字形只占少数像素所以不会带偏）：

| --- | --- | --- | --- | --- | --- |
| `.cd-brand` | 24rpx | `--txt-dim` | 34,42,56 / 15,20,31 | 7.06 | 4.5 |

最差的一档是倒计时卡底部那行 20rpx 说明文字，5.21:1，仍在 AA 线以上。
中途试过另一版：把反光做成占卡片高 16% 的一整片高光带 —— 那一版整卡最亮一块到 (45,53,67)，
同一块上的小字掉到 3.98:1，**并且把 m01 那把"按颜色找卡片顶边再量切角"的探针带偏**
（高光把上沿染亮，探针从顶边往下错位，切角比值 0.0037，门禁假红）。
所以反光最后只留 2px 一道沿，两个问题一起解决。

**虚化到底有没有作用**：把三页的 `backdrop-filter` 那几行删掉重拍一帧做对照
（两帧的页边缝隙 |Δ|=0.01，证明内容完全同帧可比）——卡片内部平均 |Δ| 1.4~2.0、
横向纹理从 3.203 降到 2.963（首页）/ 4.347 降到 4.002（副本页），
即**开发者工具这个内核确实把身后的画面糊掉了**，不是写了一条被忽略的属性。

## 3. 三条照实说的边界

1. **搜索框没跟着改，是故意的**：它是原生 `<input>`，由原生层绘制，
   `backdrop-filter` 与渐变层作用不到它身上。在它身上写这两条等于报一个假效果，
   所以只留面色玻璃，并加了一条门禁卡住这个写法。
2. **真机没验**。虚化只在开发者工具（Chromium 内核）里量到生效；老内核不认时那一条整条忽略，
   退化成一层面色玻璃 —— 版式、层级、可读性都不受影响，但"糊没糊"要真机看。
   另外 38 行列表每行都开虚化，低端机滚动开销我没测（本机量不了帧率）。
3. **底图只铺页面顶部约 703rpx**（`widthFix`、按屏宽铺满、高度按原图比例走，是站主 10-23 定的"top 居中"）。
   所以"往下滑就又没有背景可透了"不是 bug：首页种族卡、副本页第四行往后，卡片背后本来就是纯色页底
   （上表两个 0 的负对照就是这件事的证据）。要让整页都有得透，得改底图的铺法
   （比如给页面底图一个 100vh 的高度按 top 裁切，或让它在尾部渐隐），**那是另一个决定，等站主看**。

## 4. 门禁

| 命令 | 结果 |
| --- | --- |
| `node tools/mini-m01-check.js` | **49 / 49**（切角探针按新令牌算出目标色 15,20,31，比值 0.0149 在区间内） |
| `node tools/mini-m02-check.js` | **108 / 108**（本轮新增 5 条：两页"卡片真的透底"量像素 10~60 级、反光与虚化必须是令牌、两页三层齐全、原生 input 不许冒充、alpha 下限 0.45） |

新增的两条"透底"判据取的是**下限 10 / 上限 60**：低于 10 就是又糊成纯色（上一版 7 会被抓住），
高于 60 就是底图亮到会把字吃掉。数值判据不写死像素：缩放与视口原点都从当帧的 `.pagebg` 与两帧之差现算。

顺带修了一条与本轮无关的红：`mini-m02` 有两条按 `wow-forever-web/src/img/...` 硬路径查素材文件，
而另一条线当时正把整棵 `src/` 改名成 `app/`（写这段时还在未提交暂存区，随后已随 `2b897e4e` 落库），这两条因此假红。
先改成两个根都认，落库后再收回到只认 `app/img/` —— 它核的是"这张图本地真的有文件"，不是躺在哪个根下。

# 第二轮（同日，站主三次指令：「首页、副本、职业页这 3 个页面卡片毛玻璃效果不够」）

## 7. 根因不在配方，在"没有东西可透"

第一版加强是闷头拧配方（面色更透、虚化更狠、反光更亮），量出来透出量只从 22 走到 24。
停下来看实拍才明白：**那张页面底图是 `widthFix` 锚在顶部的，只有上面约 703rpx 有图**，
副本列表 29 行里只有头两行背后有图，首页种族卡、职业页阵营框全在图下面——
卡片背后本来就是纯色页底，玻璃透得再狠也透不出东西。

所以这一轮补的是**一层整页环境底图**：同一张图 `position: fixed` 铺满视口、
自己先糊掉（`filter: blur(26px) saturate(150%)`，画在图上的 filter 比 `backdrop-filter` 通用），
压在原来那道暗底下面，只当一片柔和的色场给卡片去透。规则写在全局 `app.wxss` 一处，
三页 wxml 各加一行 `<image class="pagebg-ambient">`，`bgUrl` 取不到时和原图一起不渲染。

配方同时再上一档：

| 令牌 | 第一轮 | 第二轮 |
| --- | --- | --- |
| `--panel-glass` | `rgba(19, 26, 40, 0.5)`（卡片内部只有 15,20,31，跟页底 11,15,22 差不到一档） | `rgba(28, 39, 60, 0.46)`（亮一档＝磨砂那层乳白） |
| `--glass-blur` | `blur(14px) saturate(112%)` | `blur(30px) saturate(180%) brightness(1.10)` |
| `--glass-sheen` | 2px 沿 + 底部压暗 | 2px 沿更亮 + 上半 22% 一小段乳白 + 底部压暗更足 |
| `--glass-line` | 白 0.16 | 白 0.22 |

职业页这一轮才真的动到"看得见的卡片"：两个**阵营框**改成"阵营色染在玻璃上"
（`background: var(--fac-*-bg), var(--glass-sheen), var(--panel-glass)`，阵营色仍在最前，识别没丢），
**组合卡那一排**原来什么都没有，现在给一层面色玻璃 + 虚化。

## 8. 第二轮量出来的数

| 取样块 | 第一轮透出量 | 第二轮 |
| --- | --- | --- |
| 首页倒计时卡 `.cd` | 22 | **27** |
| 副本列表第一行 `.drow` | 15 | **20** |
| 首页入口卡 `.entry` / 图外的种族卡（负对照） | 0 | 0 |

逐行文字对比度（同一套测法：每个元素自己那一小块的主色 vs 它的令牌色）：
最差一档仍是倒计时卡底部那行 20rpx 说明文字，**4.86:1**（第一轮 5.21，AA 线 4.5）；
其余 5.19 / 5.67 / 5.68 / 5.93 / 6.07 / 6.44 / 6.52 / 6.63 / 8.11 / 10.30。
**这一档只剩 0.36 的余量**——再要透，就得先动那行小字的颜色或把它挪进更暗的一块，不能继续压暗层。

## 9. 顺手把一把已经错过三次的探针换掉（重要）

m01 那条"切角铭牌"判据一直是**按颜色找卡片顶边**。这个做法被带偏过三次：
① 背景图压暗后整屏接近 `--panel`（量到 cut=-37）；② 卡片上玻璃面色；
③ 这一轮顶部那段乳白反光把卡片上沿十几像素染亮，比值从 0.0149 掉到 0，直接假红。
现在改成**量几何**：卡片在哪由 DOM 说（`.cd` 的 rect），角有没有被切由像素说
（只在 DOM 报的那一行往下 60 像素的窗口里找"不是页底色"的最长一段连续像素，
比较第一行与 14 像素后的右端点）。视口原点仍按两帧之差现算，缩放按 `.pagebg` 的 CSS 宽现算，
页底色仍从 `app.wxss` 现读——三个数都不写死。改完实测比值 0.0240，落在 0.01~0.045 区间。

跟着换掉一条已经失去依据的门禁：m02 原来卡"alpha ≥0.45，否则切角探针认不出卡片"，
而那个原因已经随探针一起不存在了，改成卡"面色是半透明、且比页底亮一档"（玻璃的定义 + 磨砂的来源）。

| 命令 | 结果 |
| --- | --- |
| `node tools/mini-m01-check.js` | **49 / 49**（切角探针已换成量几何，ratio 0.0240） |

## 11. 第二轮仍要人看的

- **性能**：现在每页是"一张 fixed 糊掉的全屏图 + 每张卡一次 `backdrop-filter`"，
  副本列表 29 行都开虚化。开发者工具里滚动正常，**低端真机的帧率我没测**（本机量不了）。
  要退让有两条：只给前 N 行开虚化，或环境底图保留、卡片虚化撤掉（退成面色玻璃 + 一片糊底）。
- **老内核**：不认 `backdrop-filter` 时退化成"面色玻璃 + 已经糊掉的环境底图"，
  磨砂感还在、版式不变；`filter: blur()` 的覆盖面比 `backdrop-filter` 宽，但仍属真机未验。
- 环境底图这一层是**新增的页面视觉**，不是站主点名的东西（他点的是卡片），
  做了是因为不做就没有东西可透。不认可就删 `.pagebg-ambient` 那一行与那条规则，配方部分不受影响。
