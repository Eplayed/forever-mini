本轮角色：wow-data ｜任务：区域图选路定了 A——**缺的那几张让 Windows 侧从游戏里截官方那张区域图**，

## 一、要什么、为什么是这 10 张

## 二、要的是哪一张图（这条最重要）

**要暴雪自己那张区域地图**，不是任何插件画的图。

- 游戏里打开地图，选到那一区（区域那一层，不是大陆总览、不是世界全图）。
- **截之前请把 OpenMap、HandyNotes、XR_DungeonGuide、DungeonsForever 这几个会在地图上画东西的插件临时取消勾选**。
  这一步会写客户端 `WTF/` 里的插件清单——**属于设置层，不动游戏文件本体**，截完再勾回来即可。
  如果你不想动这个设置，回一句，我们改要"带图钉的原图 + 一份图钉位置清单"，我们自己判能不能用；
  **但不要拿插件自己画的那张图当这一批的回件**（那是第三方美术，不是官方那张）。
- 2548 河林、2652 辛德拉是《无限》新加的区域。**如果游戏里根本没有这两区的地图**，
  就在 RESULT 里写 `no_ingame_map`，不要拿别的图凑，也不要留空当成功。

## 三、交付形状

放到共享里 `ziliao-export/zone-captures-2026-10-28/`（**新目录**，别覆盖以前任何一批）：

```
zone-captures-2026-10-28/
  zcap_<地图号>.png          例如 zcap_1424.png —— 整屏或整窗截图都行
  RESULT.json                见下
```

`RESULT.json` 每张一条：

```json
{
  "mapId": "1424",
  "zoneEn": "Hillsbrad Foothills",
  "file": "zcap_1424.png",
  "shotSha256": "…",
  "windowSize": [宽, 高],
  "mapPictureBox": [左, 上, 右, 下],
  "boxHow": "目视量 / 客户端给的坐标 / 其它（写清）",
  "hasAddonPins": false,
  "status": "ok | no_ingame_map | 其它，并写原因"
}
```

`mapPictureBox` 是**那张地图画面本身**在截图里的像素框（不含周边按钮、标题条、黑边）。
给不出精确框就给一个"整屏截图 + 你目视的框"，我们这边会再对一次——
**但一定要给**，因为我们的点位是按画面区算的百分比，裁错边就等于把所有点整体挪位。

三条不要做：**不要缩放、不要裁成正方形、不要在图上写任何字或加水印**。原样交。

## 四、回来后本站怎么处理（先把契约写死，免得来回改）

1. 逐张校验：裁出 `mapPictureBox` 后**宽高比必须落在 1.5000 ± 0.01**
   （本轮实测：客户端官方区域图 12 片拼完，画面盒就是 (0,0)→(1002,668)，比例 1.5000；
   我们现在用的那 37 张是 560×373 = 1.5013，同一参照物）。对不上的退回，不硬塞。
2. 缩放到与现有那批同一档，转 webp 落 `app/img/art/maps/<地图号>.webp`。
3. `app/img/art/manifest.json` 逐张登记：`origin: game-capture`、抓取日期、
   来源写"Windows 侧从《无限》游戏内官方区域地图截屏（第三方插件的叠加层已临时关闭）"，
   并保留"整目录删除即退回只显示数字"的下线方案。
4. 重跑 `node tools/build-data.js` → `cd app && npm run build` → `python3 tools/site-check.py`
   （世界页那条"图框数 = 数据有图数"的断言会从 36/8 变成 44/0 或对应的新数，跟着改判据，
   **不是把断言删掉**）。
5. 拿 1436 那张对照做**位置核验**：挑 2–3 只有坐标的稀有怪，分别画在"游戏截的"与"我们现有的"两张图上，
   看落点是否同一处。这一条验的才是"坐标参照物对不对"，验完才敢把新图当点位底图用。

## 五、边界（和以前几单一样）

只读；不改客户端文件、不注入、不装任何会动游戏文件的工具；不把客户端本体或插件原包上传到任何地方；
拿不到就照实登记，不许用邻近的图或别的区域凑。**这一批图是"游戏画面截图"那一档**，
和 XR 那 25 张副本图同一类，进仓库时按同一套 manifest 登记，不当成暴雪直接发布的素材。
