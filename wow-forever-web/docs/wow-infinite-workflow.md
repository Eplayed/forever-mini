## 三、数据采编工作流（可反复跑的那条流水线）

> 具体源清单、可用性与接入顺序见同目录 `wow-infinite-sources.md`（2026-10-06 两轮实测）。要点：英文官方名是 **Forever** 不是 Infinite；**英文侧资料已成体系**——`wowhead.com/forever` 用真实浏览器可达，含每职业天赋计算器、逐本副本指南、三张天梯、beta 改动新闻流与 Blue Tracker，`wowclassicforever.info` 最像数据库（4809 新物品 / 4963 新法术索引、有简中路由）。但这些**只能当对答案的参照系：禁止搬数据、禁止进自动化管线**（可达性依赖本机出网通道，脚本直取仍是 403）。脚本直取拿不到的还有 NGA、抖音、微博、Reddit。60 级译名可用 `cmangos/classic-db` 的 1.12 国服中文 locale（**只取名字，不取掉落与数值**）。Forever 独有内容仍要走"B站实测 ASR + 关键帧 OCR"，其中 **OCR 是尚未验证的能力缺口**。

每一步都写了输入、输出、失败条件，跑歪了能立刻发现是哪一步的问题。

**第 1 步 定源（官方层）**
输入：`wow.blizzard.cn` 的 forever 专页、未来展望座谈会回顾、职业深度解析、新闻稿。
输出：`base-data/wow/evidence/official.jsonl`，一行一条 `{日期, 出处URL, 原文摘录, 涉及对象}`。
失败条件：页面是 JS 渲染抓不到正文 → 我改用浏览器渲染后再摘，抓不到就不入库。
说明：这层只定"不能错的东西"——地下城名单、机制名称、系统规则、上线时间。

**第 2 步 采集候选（实测层）**
输入：B站/抖音 关键词（"魔兽 无限 beta 副本"、"无限 地下城"、"无限 改动"），按播放量和发布日期排。
输出：`候选清单.json`，含 `{标题, 链接, 播放数, 时长, 发布日期, up主}`，供你花 5 分钟勾选。
失败条件：结果里出现 60 级怀旧/私服内容 → 按标题与发布时间过滤，来源不明的不进清单。

**第 3 步 转写**
输入：你勾选的视频链接。
输出：`video2text/output/` 下的文字稿，文件名带来源链接。
成本：你之前实测的 5.5 倍实时速度——1 小时素材约 11 分钟机器时间；9 座本按 20 小时素材估，约 3.6 小时。跑之前记得设 OMP 线程，不然会退化。

**第 4 步 抽取成结构化草稿**
输入：文字稿 + 官方层证据。
输出：按第五节 schema 填的 JSON，**每条数据挂 `evidence` 引用**（指向第 1/3 步的原文）。
失败条件：抽取不出、字段为空的条目一律留在候选区，不进正文。

**第 5 步 冲突比对（准确性的主闸门）**
规则：官方原文 > 两个互不相关来源一致 > 单一来源。
输出：`conflicts.json`，列出同一对象的不同说法。
处置：**两源不一致就不写进正文**，宁缺毋滥。这跟你 POE1 上"查不到权威中文名就保留英文、禁止硬造"是同一条纪律。

**第 6 步 人工校对（你唯一的重投入环节）**
输入：草稿 + 冲突清单。
输出：改完的 JSON + 该对象的 `verifiedAt` 刷新。
成本见下表，建议按本交付、按本签核，不要攒到最后。

**第 7 步 门槛与发布**
```bash
npm run wow:coverage      # 卡覆盖率，不达标直接失败
npm run wow:build:dev     # 生成 translated-data/wow/dev
npm run wow:upload:dev    # 只传 dev，先本地验证
npm run wow:publish       # 你确认后才跑
```
硬性保护：地下城或 BOSS 抓到 0 条就失败，**禁止覆盖 release**（照天梯那套）；产物必须非空、带更新时间、关键字段为中文。

**第 8 步 线上重核**
Beta 内容和正式服之间是"过期品"，不是"待微调"。正式版上线后 48 小时内，把所有 `betaOnly: true` 的对象整体重审一遍，逐本清标记。

## 五、数据结构（字段与类型，先对齐再开工）

摘要文件 `translated-data/wow/{env}/miniprogram_data/dungeons_digest.json`，只放列表页要用的轻字段：

```jsonc
{
  "generatedAt": "string, ISO8601, 生成时间",
  "gameVersion": "string, 如 infinite-beta / infinite-1.0",
  "betaOnly": "boolean, 是否测试服内容（正式服上线后必须为 false）",
  "sourceNote": "string, 前台可展示的一句话口径",
  "dungeons": [{
    "id": "string, 英文小写连字符",
    "nameCn": "string, 中文名，无权威译名则保留英文",
    "bossCount": "number",
    "difficulty": "string, 普通|英雄|团队",
    "iconUrl": "string, 自有 OSS 绝对路径",
    "detailFile": "string, 指向分文件的相对路径",
    "verifiedAt": "string, ISO8601, 最后一次人工核对时间"
  }]
}
```

详情文件 `translated-data/wow/{env}/miniprogram_data/wow_dungeons/{id}.json`，点开才拉：

```jsonc
{
  "id": "string",
  "route": [{ "stepNo": "number", "area": "string", "action": "string", "tip": "string" }],
  "bosses": [{
    "orderNo": "number",
    "nameCn": "string",
    "abilities": [{
      "name": "string",
      "kind": "string, 读条|瞬发|被动|召唤",
      "playerAction": "string, 玩家该怎么处理（写可验证的动作，不写精确数值）"
    }],
    "drops": [{ "nameCn": "string", "itemType": "string, 武器|防具|饰品|材料", "how": "string, 获取途径" }]
  }],
  "meta": {
    "sourceTypes": "string[], 本条用到的来源类型",
    "conflictCount": "number, 曾有几种互斥说法",
    "betaOnly": "boolean",
    "verifiedAt": "string"
  }
}
```

**溯源证据不进 OSS**：`base-data/wow/evidence/` 只留在 p2-database，里面是原始链接和摘录，专门用来查问题。前台不显示任何"待校准、来源不足、冲突"这类内部词。

## 八、风险登记（每条都写了触发信号和退路）

| 风险 | 触发信号 | 退路 |
| --- | --- | --- |
| 游戏延期或国服不同步 | 官网改口、Beta 再延期 | 内容结构不变，只推里程碑；同期先用"与原版 60 差异"这类长青内容撑住首页 |

| 暴雪对第三方工具态度进一步收紧 | 新公告 | 立即停更角色/数值相关内容，退回纯资料形态；必要时下线 |
| 你的校对时间挤不出来 | W2 交付速度下滑 | 首发降到 3 座本，甚至 2 座本先上线 |
