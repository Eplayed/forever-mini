# 双皮肤图文与公众号内联排版升级验证记录 · 2026-11-19

## 一、对标「宁静之光」的核心发现与改造目标

通过对目标公众号「宁静之光」两大合集（**《魔兽冒险笔记》** 11–18 页副本手账系列、**《#魔兽无限日报》** 50+ 期热修与社区事件系列）的 DOM 结构、内联 CSS 与卡片组件的拆解，确认其高质感与高复用率来自三项核心机制：
1. **双视觉皮肤矩阵**：
   - **「冒险笔记」复古羊皮纸手账风（`theme="grimoire"`）**：拟物皮质古书封面 + 做旧羊皮纸内页 + 阶段面包屑（`总览 > 出发前 > 必刷掉落 > 常见问题`）+ 区域与副本双地图标注 + 关键进本步**红色火漆蜡封印章** + 品质色装备属性胶囊卡 + 常见避坑 FAQ 与封底四格导流尾页。
   - **「无限服日报」暗调毛玻璃信息卡风（`theme="frosted-daily"`）**：1 张主题原画做高斯模糊压暗遮罩（Frosted Dark Glass）作为整篇卡片的统一底板，搭配 5 类模块化组件（三列 KPI 数字栏、`改动前 → 改动后` 属性箭头盒 + 高清技能图标行、区域/分类胶囊标签表、纵向彩色圆环时间线、双栏对比盒）。
2. **同源双壳输出（彻底解决图文文字 100% 重复问题）**：
   - **小绿书 / 头条 3:4 轮播模式（`carousel`，`1080×1440`）**：渲染完整卡片顶栏（栏目名 + 日期/阶段）、双行海报大标题与底栏（页码 + 来源 + 水印），配 300 字故事感引言与 `#话题标签`。
   - **公众号长文内嵌模式（`wechat/inline`，`1080×自适应高度`）**：自动**剥离**图片上的顶栏、重复大标题与底栏页码，只渲染中间紧凑的数据信息盒；将原来的海报大标题转为公众号 HTML 正文的 `21px` 深色小标题 + 2~3 段克制叙事正文。
3. **零冗余微信内联 CSS 富文本与双色语义高亮（`article.html`）**：
   - 全文 `0` 个 `<svg>`、`0` 个 `<table>`，纯内联 `<section>` 与 `<p>` 兼容微信 ProseMirror 编辑器；
   - 顶部 `1080×120` 极简白底栏目横幅 + `3px` 金色左竖线导语块 + `21px` 深紫炭色（`#2E1F3D`）小标题配 `44px × 3px` 短横线；
   - **双色语义高亮**：定性机制/结论自动渲染为**暗金色 `#A7803A`**，定量数字/经验/等级自动渲染为**赤陶橙红 `#C0612B`**（或特殊等级湛蓝 `#1D7FB8`）；
   - 文末固定：**上下金线四行总结句 + 资料与数据核对来源 + `1080×392` 暖米色「跑本无限助手」小程序引导尾卡** + 浏览器顶部悬浮 **「📋 一键复制公众号正文（直接粘贴微信后台）」** 按钮。
