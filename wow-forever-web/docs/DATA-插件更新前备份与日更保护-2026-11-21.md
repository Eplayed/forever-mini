## 四、更新后核对与回退

更新完成后在仓库根执行：

```powershell
$B="C:\GAME\World of Warcraft\ziliao-addons-backup"
python -X utf8 "$B\tools\addon_baseline.py" "$B\2026-11-21-pre-update\AddOns" "C:/GAME/World of Warcraft/_forever_/Interface/AddOns"
python -X utf8 "$B\tools\verify_addons_isolated.py" "C:/GAME/World of Warcraft/_forever_/Interface/AddOns" after-update
```

- 第一条列出哪些插件改了版本、哪些登记文件变了或**缺失**。缺失说明新版改了路径或删了文件，抽取器会读不到。
- 第二条在隔离副本里试跑，全 0 说明新版能被日更正常抽取。数据差异仍走管理台「插件待审」或日更报告判断。
- **回退方式 A（推荐，固定旧数据源，不动游戏）**：给日更进程设环境变量 `WOW_ADDONS=C:/GAME/World of Warcraft/ziliao-addons-backup/2026-11-21-pre-update/AddOns`。日更在 WSL 跑时改用 `/mnt/c/...` 写法。`addons_root.py` 最先读这个变量，`daily.sh` 开头的 `explain()` 会打印命中的路径。
- **回退方式 B（游戏也回旧版）**：退出游戏，用 `robocopy <备份>\<目录> <AddOns>\<目录> /MIR` 回装对应目录。有爱下次可能再提示更新。
