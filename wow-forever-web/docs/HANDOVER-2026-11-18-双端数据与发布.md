## 4. Windows 日常更新与门禁

1. 打开管理台「00 水源台 · 更新」，点「检查插件更新」。有差异时先看条数变化、ID 和来源，逐项应用已核实的快照。副本可点「合并副本掉落与坐标」生成成品。待审报告保存在 `tools/admin/review/addons/`。
2. 全量更新从管理台运行日更，命令行入口是 `bash tools/daily.sh`。流程依次探源、抽插件、重抓各板块、合并、跑门禁、对账、写日报、尝试同步 MacBook。管理台 Windows 计划任务 `WoW Forever Data Console` 负责启动服务，日更由接手人发起。
3. 日更失败时看水源台步骤及 `docs/DATA-每日体检-YYYY-MM-DD.md`。失败步骤的完整日志路径在脚本输出末尾。日报中的对账结果要核对时间。同一天只想跑插件层时可用 `--quick`，调试跳过门禁的产物要补跑门禁之后再发布。
4. 数据改完，先跑 `node tools/build-data.js`。涉及 L0 定名加 `python -X utf8 tools/audit-translations.py --strict`。涉及地图、配装等网页展示，先构建网页，再跑对应 `site-check.py` 和单测。小程序需要导出和同源构建，关键页面交互保留渲染证据。

常用命令以 `D:\project\forever\wow-forever-web` 为工作目录。

```powershell
git status -sb
python -X utf8 tools/project-index.py --topic updates
python -X utf8 tools/daily-probe.py
node tools/build-data.js
npm --prefix app run build
python -X utf8 tools/site-check.py --only dungeon_geo,prof_tiers,data_versions
node tools/export-mini.js
node tools/oss-release.js build --env beta --check-identity
node tools/oss-release-test.js
```

11 月 18 日用当前数据复跑了数据校验，退出码 0，三份派生索引写入被隔离。30 级配装、宏、猎人宠物的核对日仍为 11 月 5 日，距今 13 天。起名词库本地核对日已到 11 月 18 日。下一次构建若碰到超期门禁，按板块回源核查后更新核对证据。

## 5. 发布、验收与回滚

### 网页

在管理台「02 双管道同步」按网页构建、打包、验收、发布走。打包前确认目标改动和 Git 工作区，打包后记录 `release/latest.json` 的包名和 SHA-256。命令行对应入口如下，最后一条会发布到线上。

```powershell
python -X utf8 tools/release-package.py
python -X utf8 tools/pkg-verify.py
python -X utf8 tools/deploy-gh-pages.py --push
```

发布后用 `gh api repos/Eplayed/wuxian-atlas/pages/builds/latest` 查到本次提交已 `built`，再回读改动的 JSON 和页面，最后在管理台「01 本地 vs 线上」重新对账。新配装上站时，核对 27 套团前与 18 套 T1 的索引计数，点开 60 级页的备选和副本跳转。回滚时从 `release/latest.json` 找已验的上一包，指定其 `site/` 目录重新部署，同样复核提交和数据哈希。

### 微信小程序

1. 在同一管理台按「导出 → 成批」生成候选。记录 ID、校验重跑一致性，有新增图标、原画或配装底图时先传素材。配装底图走 `oss-release.js posters --env beta`，普通素材可点「同步图标与图片」。
2. 点「上传换指针」后，运行 `node tools/oss-release.js verify --env beta` 回读该批，核对文件数、哈希和标志开关，再确认真机请求命中的批次。当前客户端实际读取 `wow/beta/v1/`。
3. 小程序页面代码更新走微信开发者工具上传与公众平台审核发布。验证 60 级 BiS、T1、整套加入清单时，实点职业和专精切换、备选弹层、副本直跳、加入后清单。分发层现有验证覆盖数据与代码逻辑，真机交互仍待复测。
4. 网络异常时同时检查微信请求合法域名、`manifest.json` 返回值及客户端缓存的批次号。历史预览发现默认 OSS 域名未加到白名单时，非调试环境会降为离线。线上数据回滚用「回滚」选择已验证的批次，当前上一批为 `5f2154f39539`。真机若继续请求新批，等指针短缓存到期后重进并回读。

本地候选与线上不同的时候，`verify --env beta` 会按本机生成清单对拍。复核已发布旧批时保留原批次目录和清单，分别核对线上指针、该批文件与本地候选。11 月 18 日的小程序全批回读与 11 月 17 日页面代码验证见前述发布记录。
