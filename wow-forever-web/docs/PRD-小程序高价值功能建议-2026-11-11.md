# 小程序高价值功能建议

日期：2026-11-11。角色：wow-pm。下文保留原建议，首版范围以 2026-11-12 站主修订为准。

## 2026-11-12 首版修订

玩家离开电脑时可以选定下次要跑的副本。首页直接打开该本的任务接取路线，展示地区、NPC、物品开启、已知坐标和前置。阵营只作为可选筛选，资料未标阵营的任务仍可查看。保留装备目标，优先展示计划副本能掉的目标。首版只保存一个下次跑本计划，逐条任务状态与角色档案从首版范围中移除。

## 产品判断

把“查完就走”升级为“为下一次游戏做好准备，并记住还没完成的目标”。手机的优势是游戏外随时规划、游戏中不用切出电脑画面、微信群内直接打开同一条资料。留存来自重复发生的任务和自己的进度，不以增加页面数量、签到或频繁提醒为目标。

建议先贯通：装备加入目标 → 按副本汇总目标 → 进本前核对任务接取 → 手动标记完成 → 首页继续上次目标。保留现有详情页内展开装备的交互。

## 功能优先级

| 顺序 | 功能与真实场景 | 用户为何会再打开 | 相对投入与前提 |
| --- | --- | --- | --- |
| P0-1 | **我的装备目标**：从配装或副本装备点“想要”，按副本/首领归组，手动勾“已获得” | 每次跑本前看缺件，拿到后更新，下次继续 | 中；需可靠物品 ID 与归属桥。多来源并列，无来源的不归到某副本；不计算提升率或掉率 |
| P0-2 | **出发前任务清单**：按阵营、等级显示任务，分接取地区，记录未接/已接/已完成；NPC坐标同页看 | 避免到了门口才发现漏接，换副本重复用 | 中；优先少量资料完整的副本。未知前置标待核，不能因空值判“无前置”；物品开启任务独立表达 |
| P0-3 | **首页继续冒险**：记住手动选择的职业、阵营、等级；优先露出上次副本、未完成目标和常用入口 | 每次打开少选几遍，从上次位置继续 | 小至中；无登录，无角色查询。本机偏好和勾选不是游戏实况，清缓存会丢失 |
| P1-1 | **专业备料单**：选配方与制作次数，汇总已确认相同材料，填已有数量，显示缺多少；复制清单 | 做装备、药水、练专业前反复核料 | 中；第一版以制作次数计，不把次数冒充产出件数；未知产量、技能涨点概率不推算；不做最低价冲级路线 |
| P1-2 | **区域收集册**：手动选区域，查书籍/稀有位置和掉落，保存想去与已收集 | 探索与收集持续数周，外出时也能规划 | 中至高；先列表与已核坐标，地图需核对投影/层级。没有玩家位置，不宣称最近路线；没有刷新数据，不做实时追踪 |
| P1-3 | **传承目标册**：按已核挑战条件查看奖励、手动勾选，继续未完成目标 | 长周期成长；多个职业玩法可持续回访 | 中；区分账号级目标与单角色目标，避免重复计数；不冒充战网同步；不做自动最优加点 |
| P2-1 | **团本开门任务进度**：按阵营列依赖步骤与接取点，保存进行到哪一步 | 连续多天的长任务链容易忘，组队前可转发同一任务 | 中至高；逐步补齐任务 ID、依赖、NPC坐标后上线，不能拿经典版任务链直接套无限服 |
| P2-2 | **普查历史对比**：同一来源的连续样本显示趋势，可固定关注职业 | 选服选职业时有用，但当前占比页通常是阶段性需求 | 中至高；先建立稳定日采样和历史库。国服/海外、不同时间窗不得拼线，不补造过去数据 |

P0 三项作为一个版本，先做单份本机冒险档案。多角色档案放后续，避免第一版增加切换和进度归属复杂度。分享优先复用副本、物品、配方深链；私人进度不默认随分享传播。微信群是玩家主动分享既有资料的渠道，不建设社区或组队大厅。

## 第一版范围与验收

1. 从现有装备展开区两次点击内加入目标，重开小程序保留；能撤销勾选与移除，切换阵营不误混不适用任务。
2. 同一物品 ID 去重，多来源保留；数据升级或条目消失后不误标成已获得、不悄悄丢进度。缺来源明确待补。
3. 首页一键继续最近副本，展示真实剩余目标数；没有记录时仍是正常工具首页，不强制填档案。
4. 任务以稳定 ID 保存状态；没有稳定 ID 的条目先只查阅。首批副本应覆盖阵营任务、前置任务、物品开启任务，核实关联后再选名单。
5. 本地记录仅服务本人，无公开投稿、登录或实时游戏读取；存储失败有提示，不把失败显示成保存成功。
6. 首屏不批量拉取所有副本明细，目标按需关联，图片复用现有素材；断网准确区分缓存与缺数据。
7. 开发验收需小程序导出、相关契约检查、开发者工具实拍与真机路径检查；本轮仅需求文档，未运行代码/界面门禁。

## 复访效果如何判断

首发前留存一段现有基线，发布后观察：目标创建使用、清单再次打开、继续入口使用、任务勾选、分享落地与整体次日/七日回访。以后台实际可用统计为准；自定义事件要开发时核实能力与数据最小化，不上传个人清单正文。没有基线不承诺留存提升百分比，单次 PV 上升也不能证明粘性变好。

排序是产品判断，尚无玩家行为数据验证。起名、人口占比适合提供入口价值；跑本、装备目标、备料和收集更适合作为重复使用的主流程。暂不增加签到、积分、排行榜、新闻流或实时拍卖行行情；这些不能直接利用当前资产解决同一个高频问题，部分也超出现行产品边界。
