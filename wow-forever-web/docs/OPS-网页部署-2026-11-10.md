## 首发步骤

1. 确定要发布的 Git 提交或改动范围。工作树已有其他任务的改动，本机已有 `app/dist/`，现有产物的构建身份未经验证。发布前把实发网站 ICP 备案号加到页脚并链接到工信部，保留项目要求的非官方说明。[阿里云备案流程与网站开通](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)
2. 使用下方命令构建并验包。发布脚本会同步素材、校验数据、运行单测、执行 Vite 构建并生成带校验和的归档。正式发布前还要跑界面门禁。只发布打包出的站点文件，解包后让 `index.html`、`assets/`、`data/`、`img/` 同处站点根目录。
3. 如使用服务器，配置 Nginx 提供静态文件，放行 TCP 80 和 443。域名用 `A` 记录指向该实例的公网 IPv4，为实际访问的主机名配置 TLS 证书，再将 HTTP 跳转至 HTTPS。站点使用 Vue Router 的哈希路由，如 `/#/world`，静态文件按实际路径返回，旧 `.html`、缺图和缺 JSON 保留 404。
4. 切流前保留上一版目录，按完整版本切换站点目录，确保可切回。用下方线上验包命令确认首页、深链接及静态资源，另抽查配装模型和备案页脚。开通后 30 日内提交公安联网备案申请，通过后补挂公安备案标识与查询链接。[阿里云个人网站公安备案指南](https://help.aliyun.com/zh/icp-filing/basic-icp-service/quick-start-for-public-security-network-filing-for-personal-websites)
