# PRD｜装配师配置案例库与服务线（2026-10-21）

**主角色：wow-pm。状态：已定（先免费积累案例、首个 DD 分享入口与首期范围）／待用户确认（露露授权、实际配置内容与 Forever 复现结果）／阻塞（小程序直跳网页；收费订单不在本期需求内）。**

## 1. 需求与判断

站主在网易 DD 看见“装配师”：玩家需要知道谁做过某类界面配置、适配什么游戏版本、用了什么插件或 WeakAuras（WA）、实际效果如何，以及怎样复现或回退；站主也希望展示配置者、分享案例并承接服务。

这个想法有价值，但首先应做的是**经过授权、能查证的配置案例库**。一张“漂亮的界面”不足以成为攻略；玩家要能判断版本兼容性、配置所需插件、步骤和故障回退。资料站首期只覆盖 **Forever**。正式服可作为调研对象，未来若做正式服目录，另立产品范围和数据，不混进本仓库的 Forever 基底。

站主已提供一个具体的网易 DD **配置分享**入口：[【露露】EllesmereUI 全职业监控 无限服 丝滑流畅 10.14.1](https://url.cc.163.com/0VZOwE)，分享码 `144659`。2026-10-21 核查短链 HTTP 跳转到 `dd.163.com/wow/plugin` 的 `config-share` 页面，并带独立分享标识 `sn=c4e0c6b560234a3eb651759e6917f593`。这证明它是可定位的配置分享入口，**尚不能证明它是“装配师”主页**，也不能从标题推定 `10.14.1` 是游戏版本、配置包版本或已经适配当前 Forever 客户端。页面内配置内容、作者身份、使用许可与安装效果仍待实际查看和验证。不能据此自动采集、发布他人信息或宣称与网易 DD 合作。

## 2. 首期产品：免费案例查询与分享

### 2.1 用户路径

网页入口“界面与插件配置” → 按职业／专精、使用场景、游戏版本筛选 → 打开案例 → 看授权截图和配置目标 → 核对插件／WA 版本与适用日期 → 按原创步骤自行配置 → 如失败，按回退说明恢复。宏与 WA 字符串只在网页上**免费**展示，并注明作者、原帖、采集日期；不提供付费解锁、会员权限、交换码或付费下载。

配置者页先呈现其**同意公开**的昵称、简介、原始主页链接与已授权案例。不做平台内排名、评分、评论、投稿或用户私信。联系方式不是默认字段；作者同意公开也应再次核对用途。若原始主页直接销售插件／WA／宏配置，来源链接只作内部溯源，不把它作为网页上的接单跳转。页面注明“玩家整理，非官方资料”，不暗示作者或网易 DD 对本站背书。

### 2.2 一条合格案例的最小资料

| 字段 | 内容与验收 |
| --- | --- |
| 作者与授权 | 原作者昵称、公开主页 URL、可核验的授权记录、允许展示的素材范围、撤回渠道 |
| 适用范围 | Forever、当前补丁或客户端版本、职业／专精、屏幕比例和分辨率、最近实测日期；缺项明示“未核实” |
| 效果与用途 | 授权前后截图；解释哪些信息更易看清，而非只写“美观”“最强” |
| 配置清单 | 插件名、原发布页、版本、用途、必要性；插件包由原作者／原渠道发布，本站不重新打包分发 |
| 操作步骤 | 本站实测后自行撰写的安装、导入、调整、备份与回退步骤；记录测试环境与已知冲突 |
| 宏／WA | 只在网页免费分享；记录作者、原帖、抓取日期、适用版本和可用性验证；来源不清或未获许可则不上线 |
| 核查记录 | 来源 URL、抓取日期、授权状态、最后复核日期；版本变化后标“待复核”，不继续保证兼容 |

**改造他人的界面或插件**需要区分：本站可以基于使用体验提出自己的布局和参数调整，但不未经许可复制、改包或以本站名义分发别人的插件、截图、字符串与说明。对插件代码的修改须先确认作者许可和发布方式。禁止提供战斗循环提示、自动指导或其他仓库红线功能。

### 2.3 采集办法

先从站主提供的分享入口或作者公开原帖人工筛选，记录原始链接、分享码、跳转页和核查日期；联系作者取得页面截图、配置细节和展示范围的明确同意；由本站在 Forever 环境复现，再写独立说明。**分享码是线索，不是转载许可；不爬取客户端登录态、批量抓取通讯方式、搬运完整配置包或攻略正文。**撤回授权后下架相应素材和人物页，保留内部撤回记录。

首批候选就是这条 EllesmereUI 分享：先确认 DD 中实际展示的作者、适用游戏版本、插件／WA 内容和安装方式，再取得作者对**本站展示素材**的授权，最后在 Forever 环境从备份、安装到回退走一遍。只有四项都成立，它才升级为 **1 个可公开的 Forever 样例**；缺授权或复现证据时只留内部线索卡，不发布案例。分享码本身可作为“去原平台查看”的来源，但不替代本站复现与原创说明。

## 3. 页面与验收边界

首期预计一个案例列表页、一个案例详情页。列表卡片只放用途、职业／专精、版本、最近验证日期和授权缩略图；详情页承担安装、截图、来源与回退。站内搜索只检索已发布案例。现有新站 `app/` 是唯一页面实现目标；`src/` 旧站不新增页面。案例事实数据进入 `wow-forever-web/src/data/` 唯一基底，需有可回查来源和审核状态。UI、数据结构、工程实现分别由后续角色接文件交接。

首期验收：一条真实案例的授权、来源、版本、截图与步骤齐全；原始来源内部可回查，允许公开的非付费作者链接可打开；本站有人按步骤在对应版本复现并实际演练回退；无付费入口、无未授权包或人物联系方式、无循环提示；桌面与 375px 页面有实拍证据，构建和新站回归通过。

## 4. 免费帮助积累案例

站主已明确：**先免费帮助玩家配置，积累真实案例，不收费。**首期不叫“接单”，也不做订单、价格、支付、付费优先级或返佣。一次免费帮助结束后，记录玩家遇到的问题、设备／版本条件、解决步骤和回退结果；要把玩家的截图、角色信息或反馈公开，还需单独征得同意。案例只发布能复现的步骤，不把私下聊天直接搬上站。

免费答疑先由站主人工进行；网站本期不提供投稿、私信或收集个人联系方式的表单。wow-ops 后续核对平台联系与个人信息处理方式，再决定是否展示一个免费求助入口。国服运营方 [2026-09-24 专项治理公告](https://wow.blizzard.cn/news/20260924/43790_1314928.html) 明确点名“付费 WA 及配置分享付费”，[暴雪插件开发政策](https://eu.forums.blizzard.com/en/wow/t/wow-user-interface-add-on-development-policy/1642) 也限制插件相关服务收费；如果将来改变为收费模式，必须先另起需求与规则核查，不能沿用这份免费方案直接加价格。

## 5. 小程序与外跳

本仓库现行小程序边界是个人主体、`工具-信息查询`、零 UGC、无 `web-view` 跳转；宏／WA 字符串的放开决定**仅限网页**。因此，站主设想的“小程序点装配师，直接跳网页请求帮助”**不作为现阶段功能**。即使帮助免费，现行项目也没有小程序内的网页直跳能力和求助入口方案。复制网页地址等替代方式是否适合，仍需先核对平台规则和小程序类目，不在本期默认为可行。

若未来要重新讨论，先由 wow-ops 以届时官方小程序类目／跳转规则、主体资格及实际服务模式给出书面结论，再由 wow-pm 修改这份范围。当前小程序只继续做已定的 Forever 信息查询；网页免费案例库可先独立验证需求。
