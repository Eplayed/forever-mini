# 差异化小插件候选：传承五人本补缺

日期：2026-11-13；主角色：wow-pm。
状态：已定（研究与目标人群）；待用户确认（选题）。没有开发、安装或发布插件。

## 1. 本轮范围与结论

用户要求单个小插件起步，认为此前奖励卖价、聊天复制等建议差异化弱。本轮明确服务“练级、做任务和跑五人本”的玩家，随后要求重点研究无限服特色传承系统。

传承值得列为优先研究方向，但“传承总览、挑战进度、最近可拿的一点、各小号进度、加点模拟”已有直接竞品。建议验证一个单独流程：**队伍下一本去哪，才能补上大家缺的传承条件；打完是否实际记入进度。**

产品暂称“传承补缺”。价值是减少组队反复询问和无效重复跑本。差异化是假设，不能宣称首创或空白市场。单人缺本列表本身不构成差异化；小队对照才是候选核心。

此前文档中的“奖励卖价标记优先”不再作为当前推荐。用户尚未批准具体开发选题。

## 2. 系统规则与需求依据

[国服官方传承说明](https://wow.blizzard.cn/news/24307383/index.html)，发布于2026-09-24，本轮读取于2026-11-13：传承通过挑战获得账号点数，各角色独立分配；上线口径每个角色最多花16点，完成更多挑战仍有装饰奖励用途。地下城类别分三个挑战组，完成各组所需最终首领后获得对应点数；不是每打一个副本就给一点。

由此提出需求假设：玩家需要知道“这次打本能补哪个条件”和“离完成整组还缺什么”。不能根据进入副本、参加击杀或队友完成直接推定自己的条件完成。

上面的数字是官方上线说明口径，不作为永不变更的硬编码。当前国服客户端的逐项条件、跨角色合并方式与刷新时机仍需核实。

## 4. 单一核心流程

目标用户：几个朋友一边练级一边补五人本传承，决定下一本时不知道彼此还缺什么。

1. 玩家打开小面板，查看自己的地下城传承缺项。
2. 在当前队伍中，成员主动启用同步后，将已知缺项并排显示；没安装、没同意同步或状态过期的成员显示“未知”。
3. 点选一个副本，显示“哪些已知成员缺此条件”“哪些人只差这一项完成整组”。只统计可核实状态，不给DPS或职业强度分。
4. 出本或手动刷新时，对比此前快照与游戏返回的当前条件，显示“新增完成／尚未记录／无法读取”。记录没变不自动诊断成游戏BUG。

演示语义（非真实队伍数据）：副本甲有3名已知队员缺项，其中1名补完即可完成该组；副本乙有1名已知队员缺项。显示依据与未知人数，交由玩家选择，不声称最快或最优路线。

## 5. 首版裁剪

首版只做普通规则集、地下城三组挑战、当前五人队伍、一张对照表和一次前后进度比较。单人可用，但必须明确单人功能与现有插件高度重叠。

暂不做：全65项规划、传承天赋模拟、专业冲点成本、世界探索路径、地图替换、跨小号最优路线、团本、PvP、招募平台、自动喊话、网页或小程序联动。也不采用战斗日志推断完成。

同步仅限插件内支持的当前队伍通信，成员主动启用，不自动发送聊天消息。不能承诺不装插件也能读取队友完整进度。队伍通信接口可用性是待测条件。

复杂度判断：中等；比纯卖价标记复杂，难点在条件识别、同步和状态可信度。未经接口探针，不承诺1至3天可交付，也不宣称“非常容易”。

## 6. 本仓库可复用与缺口

只读检查 `wow-forever-web/app/data/legacy.json`：标注客户端构建1.60.1.70790，已有65项挑战、21项专长的资料结构；地下城组包含62031、62032、62033三个候选挑战ID。

但这三项目前只有“完成以下地下城”这样的总要求，条目仍为L2；不能据此生成完整副本子条件表。现有数据不等于插件运行所需的实时账号进度，网站能显示也不证明游戏插件接口已可用。

wow-data后续需要核实当前国服的挑战ID、criteria子项、对应副本/最终首领及特殊计数规则，不能按副本推荐等级猜所属组。网络资料提示个别副本等级与挑战分组不直观，只作核对线索，不直接发布为本插件规则。

## 7. 选题继续推进的门槛

先由wow-dev按本文做最小可行性探针，再决定是否完整实现：

- 与游戏原生传承窗口逐项一致；未知状态不显示未完成，也不显示完成。
- 进本前后能读取同一组条件，不靠击杀日志；真实打本后观察完成与延迟两类状态。
- 两台客户端/两个队员验证同步、未安装、离队、重组与旧快照失效；只在本机模拟数据不能算通过。
- 核实一个条件完成是否真的让整组完成，不把条件数当点数。
- 对比至少Legacy Forever和一款总览类插件：现有产品若已把小队流程做得足够好，则放弃重复开发。
- 找一组实际五人玩家试用，观察他们是否据此决定下一本，是否减少询问；只觉得“面板好看”不足以证明价值。

上述是建议验收门槛，尚未执行。若队伍同步不可行或队友不愿安装，不能悄悄退化成个人清单后仍宣称差异化成立，应重新评估选题。
