## 对本站旧结论的修正

`DATA-客户端模型线-2026-10-26.md` 曾报的 21.4% 是**在旧 DB2 CSV 上按“目录与部位相符的独立 `.m2`”算的历史格位命中率**；10-27 发现解析器漏掉 WDC5 copy table，故此数还须重算，不能当成当前覆盖率。即使重算，它也不是“完整角色 3D 外观覆盖率”。胸、手、腿等外观本来就可能体现为人物基础网格上的分层贴图与 geoset，不要求每件都有独立 `.m2`。因此“身体六件没有独立 `.m2`”不能推出“身体六件不能出现在整人 3D 上”。

先前 **C 判死已撤回**：[Windows 第二包复核](DATA-整人3D-Windows交付初审-2026-10-27.md#五第二包复核本地人物已通旧-db2-行数结论撤回)发现既有解析器漏掉 WDC5 copy table，旧 47.14% 断链其实在非零键中重算为 9,032/9,033 命中；但本站尚未建立经实拍核准的逐物品身体贴图映射，不能据此宣称已能自动、准确地批量烘整套角色。对方的预制全身 GLB 表明“完整人物 3D”在技术上可行，其离线映射链并未公开。

**B 单件预览不是唯一能做的形态**；它只是现有已核数据能较直接支撑的有限方案。即使做 B，头盔、肩、武器等仍须补齐 `.m2/.skin/.blp` 的材质绑定与实拍准确性；不能把 21.4% 当成玩家可见的最终成功率。

## 现阶段能否做成 WCLBox 那样

**能做，目标形态是每套/每阵营离线预制一份完整角色 GLB，再由网页加载、旋转。** WCLBox 的浏览器部分很轻；真正要解决的是离线阶段的 `物品 ID → 外观 ID → 身体贴图与 geoset/附件 → 人物 GLB` 和逐套外观验真。该站的成品不证明这条映射在我们手里已有，也不证明它对每件装备都准确。

本地 Forever 70532 已在 wow.export 实验副本中加载出人物及 DB2，属于这条路线的实质进展。上轮原定胸甲 1488 缺 `ItemSparse` 行，工具无法选择；2870 只搜到、未穿戴；**没有 A/B 截图或 GLB**。另有缺本地纹理时远端回退崩溃的证据，但该次完整原始日志未保存。故目前的准确说法是“人物基础模型已通，整套装备外观与导出未验”，不是“只能做单件”。

最低成功证据是一位固定角色只换两件本 build 可选胸甲（2870/250518），同镜头正背实拍能看到不同胸部外观，其他槽位不变；随后两份 GLB 在独立离线查看器里都带正确材质。任一件缺本地文件或借用了不同 build 的远端字节，必须单列，不能算纯本地 70532 通过。此样本成功后，再整理固定套装所需的完整物品映射、资源闭包与逐套人工对照；动态任意换装是另一阶段。
