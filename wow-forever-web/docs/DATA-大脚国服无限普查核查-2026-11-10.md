## 复用和缺项

- 点 PvP 卡「获取详细数据」进入每日一次激励广告的解锁提示。核查停在提示并点「暂不查看」，详细区服数据未取得。
- 大脚官网及公开入口未发现授权再分发、可供集成的公开 API 或官方数据下载。本站引用范围限当日公开页面的少量汇总数值，注明大脚小程序、筛选范围与原页截止时间。此记录不授予大脚数据许可，不采集角色标识、图表素材或广告后的数据。
- 首版采用「24小时人口」单独展示国服样本，保留原始整数，不据此回推角色数。Everloot 为不同来源和统计窗口，按其原署名许可分开展示。
