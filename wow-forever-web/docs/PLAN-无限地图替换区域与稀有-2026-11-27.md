## 二、OpenMap v0.8.13 实测拆解（读原件源码，非猜测）

实地核查本机 `C:/GAME/World of Warcraft/_forever_/Interface/AddOns/OpenMap`（v0.8.13-CN），其「无限地图」丝滑体验由 **5 个核心机制** 构成：

| 机制 | OpenMap 实现方式（源码出处） | Web 端「无限地图」如何复刻 |
| --- | --- | --- |
| **1. 统一世界坐标系无缝拼图** | `Map/Stitch.lua` 以世界图 `947` 为统一画布，每个区域由 `GetMapRectOnMap(mapID, 947)` 得到归一化矩形 `[l, r, t, b]` 拼在一张画布上，从一区拉远无缝滑到邻区，无页面跳转 | Web 端建立统一 `WORLD_CANVAS`（卡利姆多在左、东部王国在右、海加尔/河林/泽风岛/暗矛群岛按实际方位排布），将仓库已有的 **44/44 张区域图** 按真实地理包围盒拼装成连续可缩放画布 |
| **2. 光标锚定平滑缩放 + 自由拖拽** | `Map/WorldMap.lua` 滚轮以鼠标所在世界坐标为锚点无级缩放，左键拖拽平移、双击进入区域、侧边/搜索点击丝滑飞跃（Glide） | 基于 GPU `transform: translate3d() scale()` + 惯性阻尼实现 `0.7x`（全艾泽拉斯）→ `1.8x`（单大陆）→ `4.2x`（单区域高清）→ `9x`（城镇/街区细节）无级缩放与 Fly-To 飞跃动画 |
| **3. 随缩放层级渐进显隐（LOD）** | `Map/Townsfolk.lua` 为每类图钉定义 `zoom` 显隐门槛：`rare/spirit = 3`、`innkeeper = 4`、`repair/banker/auctioneer/mailbox/classTrainer/stable = 6`、`vendor/profTrainer = 8`；同 NPC 多点巡逻超 6 点自动取几何中心 `Middle()` 避免满屏重影 | 同样引入 **3 档缩放 LOD**（且允许用户勾选「强制显示当前筛选」覆盖门槛）：远景只显区域轮廓/等级/副本/航线与聚落气泡，中景浮现稀有/鸟点/书籍/传承书/营地，近景展开全部城镇 NPC 与单区怪物 |
| **4. 金属青铜风格浮动/侧边筛选面板** | `Map/Panel.lua` 分组勾选面板（`Places` 地点交通 / `Dungeons` 副本 / `Townsfolk` 镇民与稀有），带快捷收藏星标条、搜索定位与实时坐标 HUD | 融合本站「黑曜锻炉」暗金美学：左侧可折叠筛选抽屉（阵营切换 + 四大类图层复选 + 快捷区域目录）+ 顶部全局聚合搜索栏 + 底部实时区域/等级/光标 `(x, y)` 坐标条 |
| **5. 图钉交互与路径分享** | `Map/Pins.lua` 点击图钉弹详情卡、支持自定义标点、右键缩回、Shift 分享坐标链接 | 点击点位弹出黑曜锻炉详情浮层：中英文名、类别、等级、阵营、精准坐标、**一键复制 `/way` 游戏内导航指令**、稀有掉落清单（可直开物品详情抽屉）、**收集/击杀本地打卡**、**一键复制直达 URL** |
