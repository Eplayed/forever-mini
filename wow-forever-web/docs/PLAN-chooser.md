# 选职业问答 · 口径与权重说明（wow-planner）

版本：v1 ｜日期：2026-10-08 ｜状态：**已定（含两处机制纠错，见 §5）**
数据文件：`src/data/chooser.json` ｜页面：`src/chooser.html`
上游依据：`docs/reference-gap.md` 第四节建议第 1 项

## 1. 这个问答要解决什么

玩家进站的第一个问题不是"这个天赋叫什么"，而是"我到底选哪个职业"。问答要在**不依赖任何未核实游戏数据**的前提下给出可用答案，同时不能变成强度榜——那是红线（根 `AGENTS.md` 第五章：不做 DPS 与强度排行）。

所以定位是一句话：**按玩法偏好归类候选，不预测哪个职业强。**

## 2. 权重的三层来源，可信度不一样

| 层 | 内容 | 可信度 | 能不能进权重 |
| --- | --- | --- | --- |
| A 机制事实 | 护甲类型（板甲只有战士/圣骑士）、能不能治疗、能不能驯兽、经典 1.12 谁能坦 | 高，属公开常识级机制 | 能，且是硬约束 |
| B 玩法归类 | 操作复杂度、机动性、单人练级顺不顺 | 中，是本站主观判断 | 能，但必须标明是归类不是结论 |
| C 无限服改动 | 无限服对这些机制具体改了什么 | **未知**（官方未公布，未实测） | **不能**。任何"无限服里某职业更强"的推断都不进权重 |

权重分值只表示"这个选项把这个职业推近一步"，3 = 强相关，2 = 相关，1 = 弱相关或"都行"的兜底。**分值不是强度分，匹配度条也不是排行榜。**

## 3. 七题的设计意图

| 题 | 问的是什么 | 为什么必须有 |
| --- | --- | --- |
| position 站位 | 近战 / 远程 | 最影响日常手感，且是职业硬约束 |
| role 队伍定位 | 坦 / 治疗 / 输出 / 单人 | 决定副本里你做什么动作 |
| pet 帮手 | 要不要宠物或召唤物 | 直接区分猎人与其他职业的核心体验 |
| complexity 操作 | 简单直接 / 连招走位 | 影响长期留存，不涉及强弱 |
| leveling 升级方式 | 单人刷 / 组队下本 | 60 级前最主要的时间分配 |
| armor 护甲 | 板 / 锁皮 / 布 | 事实性约束，玩家能自己验证 |
| mobility 机动 | 要不要位移与变身 | 主观偏好，德鲁伊与盗贼的天然差异 |

选项一律给"都行"这一档（护甲题除外，因为护甲没有"都行"），避免玩家被强行归类。

## 4. 结果呈现的口径规则

1. 前三名固定展示，**并列第一超过三个时用文字说明"并列"，不加名次图标、不发奖牌类视觉**。
2. 每个候选必须回显**归因**（"因为你选了贴脸砍 / 想要板甲"），玩家能据此反驳，而不是只看到一个分数。
3. 分数差距 < 2 分视为同样合适，页面已写这句。
4. 候选卡必须带该职业的数据情况（天赋数、已与官网核对的中文名数、官方词条数），**没核实就写 0，不美化**。圣骑士那张现在如实显示"0 个中文名已与官网核对"。
5. 顶部横幅先说"不是强度排行，也不代表哪个职业更强"，再给结果。
6. 禁止出现的词：最强、T0、梯度、胜率、毕业、版本答案。`tools/site-check.py` 里有一条断言守这个。

## 5. 本轮审核改掉的两处机制错误

| 位置 | 原来 | 改为 | 原因 |
| --- | --- | --- | --- |
| `pet / want` | 德鲁伊 1 分 | 删除 | 经典机制德鲁伊**不能驯兽**，给分等于暗示他能带宠 |
| `role / tank` | 萨满祭司 1 分 | 删除 | 经典 1.12 萨满**没有坦克定位**，这是 A 层事实错误，不是口味问题 |

这类错误比权重高低更致命——它会让玩家按错误信息做职业决定。所以 A 层任何一条被指出与游戏不符，优先级高于其它一切改动。

## 6. 改动流程（谁都能照做）

1. 只改 `src/data/chooser.json`，**不改 `app.js`**（题干、选项、权重都是数据）。
2. `node tools/build-data.js`：会拦题目或选项 id 重复、选项无权重、权重指向不存在的职业、题目少于 5 道、`kind` 没标 `site-opinion`。
3. `python3 tools/site-check.py`：会跑完整问答流程并检查强度话术。
4. 在 `ROLES.md` 记一行，说明改了哪条、依据是 A/B 哪一层。

## 8. 明确不做

不预测版本强度、不给天赋加点建议（那是天赋计算器的事）、不做职业胜率或出场率统计（没有合规数据来源）、不做"最适合新手"这类隐含排名的标签。
