## 二、那张图：一手来源，登记齐了才敢用

站主给的是 `blz-contentstack-images.akamaized.net/.../Skyborne-bg-md.jpg`——
**暴雪自己的 Contentstack 素材库域名**，不是第三方转存，来源硬度比"客户端原画经第三方站"那一条还高一级。

处理：原始件 1600×1500 JPEG 240,903 字节（sha256 `7eff3f4c…`，不入库）→ 缩到 **1280×1200 webp q78 = 95,774 字节**
（sha256 `9a8ba6c2…`），落 `src/img/keyart/skyborne-bg.webp`，`manifest.json` 记来路、抓取日期、
处理链、用在哪、以及**商标词自查结论**：逐字看过，画面里没有「魔兽 / 魔兽世界 / WoW / 暴雪 / 艾泽拉斯」任何字样与标志。

结构上动了一处：这张图是三个 tab 页共用的，不再属于"首页"，所以 `ui-art.json` 里
`home.bg` 撤掉、新增 `tabs.bg`，`home` 只剩四张入口卡。导出层跟着把 `meta.uiArt.bg` 换成 `meta.uiArt.tabBg`。
上一轮那张 `forever-hero.webp`（《无限》宣传画）**文件与登记都留着**，只是界面不再引用它——
要换回去改一行 `tabs.bg` 就行。

分发层那边顺手补了一道卡口：以前只走 `ui-art.json` 的 `home` 那一组，
这次 bg 从 `home` 挪到 `tabs` 时，如果还只走 `home`，新那张就永远不登记——
**界面拼得出地址、bucket 上却没有**，正是 2026-10-22 那次"缺登记 0 条却线上 404"的形状。
现在改成整份都走（只跳过 `meta` 那段说明文字）。

## 三、top 居中怎么摆，以及摆出来才发现的层叠 bug

`mode="widthFix"` + `width:100%` + `height:auto`：按屏宽铺满、高度按原图比例走。
以前首页那张是 `aspectFill` 裁满整屏——这张是 1280×1200 的近方图，裁完只剩中间一条，所以必须换。

先写成 `position: fixed`，实拍发现钉在屏幕中间会把中段名单压在亮的云图上，改成 `position: absolute`
锚在页面顶部、跟着页面滚。

**改完仍然不对，而且是靠像素而不是靠眼睛发现的**：同一页"有底图 / 撤掉底图"两张截图，
DOM 量出来文字位置一模一样（`row0` 都在 100pt），像素上撤掉底图那张有 15 段文字、有底图那张只有 2 段——
**名单整片被暗底糊住了**。原因是 CSS 绘制顺序里，非定位元素会被 `z-index:0` 的定位层盖住；
只给 `.wrap` 加 `z-index` 抬的是"整页相对页面根"，不是"内容相对它自己的那两个底图层"。
修法是三页统一：内容包进 `.fg { position: relative; z-index: 1 }`（首页本来就是这么做的）。

这条已经落成门禁：**每个铺了 `.pagebg` 的页面必须有自己的 `.fg`**，
另外三页各做一次"有底图 / 无底图"像素带比对（`mini-m02-check.js` G 段）。
DOM 读着一切正常、屏幕上什么都没有——这类问题只有像素能回答。

## 四、暗夜精灵：不是漏接，是官方 CDN 真没有

实测（今天，直接打官方 CDN 看状态码）：

| 候选图标键 | 结果 |
| --- | --- |
| `race_nightelf_male` / `race_nightelf_female` / `race_night_elf_male` / `race_darnassian_male` | 全部 **403**（官方 CDN 的 403＝没有这个文件） |
| `race_human_male`（对照组） | 200 |

所以 `races.json` 里暗夜精灵的 `iconKey` 一直是 `null`，不是我们漏填。

库里其实**已经有这张图**：`src/img/art/races/night-elf.webp`（128×128 客户端种族头像，
2026-10-12 那批转存进来的，`art.json.races` 有它、manifest 也早记过来源，网页种族页一直在用）。
于是把种族图标的取图顺序在分发层定成三层，一处生效：

1. 官方 CDN 的 `iconKey`（有就用它，红线口径）；
2. `art.json.raceIcons`——站主 2026-10-20 单独授权的那张插件天裔小图；
3. `art.json.races`——本站已在库的 128 客户端种族头像。

暗夜精灵落在第 3 层，**没有为它新开任何素材授权**；另外 8 个种子的图仍走官方 CDN 那份，没被换掉
（顺序写反的话会把 8 张官方图全换成第三方转存，那是往红线上踩）。

## 五、职业页两处

**种族分两框**：照职业详情那一套复制一份（小程序页面样式互相隔离，只能各留一份，注释里写清"改一边要改两边"）。
联盟在左、部落在右，框体吃 `--fac-alliance-*` / `--fac-horde-*` 令牌；框内一格只有图标与名字，
一行三个、补空位到 3 的倍数（今天实测 5 + 5，各补 1 格，两行）。
框里不写"联盟/部落"那两个字——阵营由框体颜色与位置说，这条与职业详情同口径。

一点不同：职业详情里点格子没有下级动作，这里点一格要看"能练什么职业 + 种族特长"。
**特长那种整句在约 170rpx 宽的格子里压不住**，所以点中的那一族铺在两框下面整宽显示，
框本身只当选择器。没点之前给一句"点一个种族，看它能练哪些职业与它的种族特长"。

**组合卡换种族图标**：数据里 `newCombos` 只有 `raceCn` 没有种族 id，所以这层归并在分发层做——
按 `nameCn` 对到种族条目，给每格补 `raceId / racePortrait / raceIconKey`，界面调 `raceIconUrl`。
天裔两条同名（联盟/部落各一条）取到哪条都是同一张图，不影响。

顺手补了一个洞：第七格「天裔」在数据里 `classId` 是空的（公告原句里它是"首次登场的种族"，
不属于哪个新组合），以前点它**没有任何反应**——按"选项选了要真生效"这条，
现在它会把下面那一族的详情选出来并滚过去，不留一格点了没动静的东西。
