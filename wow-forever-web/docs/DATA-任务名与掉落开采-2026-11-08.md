# 白云飞整合开采：任务中文名层 + 掉落名单（2026-11-08）

承接《DATA-白云飞整合盘点-2026-11-08.md》。站主 2026-11-08 批准的开采范围是**任务中文名层 + 掉落名单**两项（任务经验表未选，没采）。本轮角色 wow-data。两条快照都只落 `app/data/upstream/`，**没动任何成品 JSON**——要不要接进 `dungeon-quests.json` / `dungeons.json` 是合并层下一刀。

## 一、QuestieDB 主库真身（开库结论）

QuestieDB 1.0.12 起**主数据不是 lua 表**，是「baked 模式」：全部实体以 Base64 → zlib → CBOR 存在 `QuestieDB_Forever.toc`（15,513,803 B）的 `## X-*` 元数据行里，运行时经 `GetAddOnMetadata` 读（[src/read/baked.lua](../app) 同目录 `src/read/baked.lua`）。关键行：

| 元数据行 | 内容 |
| --- | --- |
| `X-Quest-IDS(-N)` | 任务 ID 总表，zlib CBOR int 数组（块头 `~16~` 是分块计数，不是数据） |
| `X-l10n-zhCN-Quest(-N)` | zhCN 翻译列块：数组 `[任务名列, 目标文本列]`，列内与 ID 表**按位对齐**（`src/l10n/overlay.lua` 的 provider 二分） |
| `X-Quest-<id>-S` | 单条 Scalar 行，CBOR map 或 `[b'REUSE ME', f1, f2…]` 数组两形态，字段 1=英文名（**主行全英文**，中文只在 l10n 块；另有 `b'p'` presence 键） |

Scalar 行实测样例：id 2 → `Sharptalon's Claw` / zhCN 列块同位 → `沙普塔隆的爪子`。

## 二、任务中文名层（快照 `upstream/questie-quests-cn.json`，652.9 KB）

工具 `tools/extract-questie-quests-cn.py`（内置精简 CBOR 解码器，无第三方依赖）。

- **任务 ID 5,233 个；有中文名 5,011（96%）**：zhCN 列块 4,254 + 白云飞补丁生效 757；无中文名 222（抽查都是 `<NYI>` 未实装任务）。
- **白云飞补丁 757 条全解**（文件自述与实解一致；其中 5 条混着未转义字面 ASCII，解析器按字面并入）。与列块**一致 486、串分歧 271**——分歧时 `cn`=补丁值（运行时 overlay 生效序），`cnBlock`=列块原值，**两个都留**。
- 分歧样例（补丁层在修列块坏串）：id 76156 列块「大地母亲与匿同在」→ 补丁「与大地之母同行」。
- 白云飞 NPC 名 24 条顺手采（`npcNames`）。
- **未采**（范围没批）：l10n 列块列 8 目标文本、白云飞 `QuestObjectives.lua` 749 条目标正文（成段句子，贴「描述文案」红线）、QuestXP 经验表。

**与本站对拍（`dungeon-quests.json` 按英文名桥）**：本站 396 条，英文名对上仅 13（一致 6 / **分歧 7**），对不上 383。分歧全是译名差（本站 wclbox 系 vs 白云飞系）：「远古的宿怨/古老的怨恨」「永不安息的亡者/不眠的死者」「旧铁炉堡入侵/铁炉堡旧城入侵」「惊恐的求援/受惊的请求」「圣光的正义/圣光之裁」「拉斯玛尔之怒/拉斯玛尔的怒火」「憎恶生物/可憎的生物」。

**合并层接这层的坎**：本站任务条目没有 questID，英文名桥只接得上 13 条。要吃这份 5,011 条中文名，得先给本站任务数据补 questID 或按副本建人工名字映射——这是产品/合并层的决定，本轮不擅动。

**分级**：列块与补丁都是「国服客户端串的插件转述」，够不够 datamine_cn 口径升 L0 **未判**，先按 L1 起档，等第二家互证或站主明确口径。

## 三、掉落名单（快照 `upstream/questie-item-drops.json`，413.8 KB）

工具 `tools/extract-questie-drops.py`。

- 源：`support/Forever/DropTables/classicItemDrops.lua`（571,977 B，wowhead 数据自动生成，文件自述）+ `itemDropCorrections.lua`（23,799 B，人工修正）。方向与 DF 那份相反（物品→NPC），已统一成 `(npcId, itemIds[])` 归属对。
- **合计 16,790 对 / 4,404 个 NPC × 1,313 个物品**（wowhead 表 2,032 块 + 修正 153 块，111 对只出现在修正里）。
- **掉率当场丢**（float 与 `DropKeys.WOWHEAD` 引用都只当「归属成立」）——红线：掉落不写百分比。注释里的 wowhead 英文物品名也没要。
- **与 DF 掉落快照对拍（npcId 桥，共同 NPC 106 个）**：归属两源都认 23 对、只 Questie 有 263 对、只 DF 有 464 对。三家名单（wclbox 系 / DF / Questie）分歧确实大，「分歧都留」口径是必要的；哪家更准要游戏内实测，不猜。
