## 一、矩阵四层（每层写清归属与现状）

```
        ┌─ 数据基底（唯一）──────────────────────┐
        │  wow-forever-web/src/data             │  ✅ 已有，且是同行没有的那一格
        │  溯源 + L0–L3 分级 + 两源分歧 + 卡口    │  （jjwow / foreverchanges 都没有）
        └───────────────┬───────────────────────┘
                        │ 只允许从这里导出，任何平台侧不许手写第二份
        ┌───────────────┴───────────────────────────────────┐
        │ 三种形态（同一份数据的三种消费动作）                │
        │ ① 搜索型：web 站 + 小程序 —— 只负责"接住"，不产生流量 │  ✅ 已有（缺域名）
        │ ② 投稿型：图文稿 → 各平台 + 官方征集 —— 彩票，不排工时 │  ⚠️ 产线有、稿子 0 篇
        │ ③ 交付型：CSV 可引用包 / 开工手册 / 表格模板 / 整理服务 │  ❌ 未做，**本轮主攻**
        └───────────────┬───────────────────────────────────┘
        ┌───────────────┴──────────────┐
        │ 两个入口（只留两个，不留四个） │
        │ A 搜索引擎 ← 前置是备案域名    │  ❌ 无域名无备案（全链最长路径）
        │ B 一个内容平台（抖音 or B站）  │  ❌ 未选；小红书/头条降级为"同稿同步"
        └───────────────┬──────────────┘
        ┌───────────────┴──────────────┐
        │ 一个收款口（不进小程序）      │
        │ 网页说明页 + 一对一交付       │  ❌ 未定；前置是 259 号文那道（见 wow-ops）
        └──────────────────────────────┘
```

**为什么是"两个入口"而不是"四个平台"**：你 6 小时/周，每多一个平台就多一份作业；而按你实测，头条半年 153 元、公众号 40 曝光/月、小红书图文不计酬——**多平台铺开在你的量级上不产生收入，只产生工时**。矩阵的价值不在账号数，在"一份数据被几个动作消费"。

**入口 B 我建议选抖音，理由三条**（这是判断不是事实，你可以推翻）：① 同行 jjwow 的引流就在抖音，说明这个赛道的人在抖音；② 图文形态在抖音可以走"图文带货/图文投稿"，不用出镜，符合你选的第一条；③ 若将来"无限"出了专属激励，抖音/创作匠是最可能的落点。**B站的替代优势是长内容更吃"能带走型"稿子**，但它的图文入口（专栏）激励更弱。

## 四、这轮不许破的线（照抄，别自己放宽）

1. **不卖插件 / 宏 / WA / 配置 / 循环提示 / 评分**——9-24 公告逐字点名"付费WA及配置分享付费"并管辖"平台与个人"；合规替身是手工录入的表格模板与排程。
2. **无限小程序不开流量主、web 不接广告**——微信把"含侵权内容"列一级违规（终止展示 + 扣未结算收入），且同一收款主体（含自然人）名下多号违规可整体暂停资格；你名下还有在收钱的 PoE 助手。
3. **小程序里不出现付费入口，不做跨产品互推**——运营规范明文禁止"利用腾讯服务为其他 APP/平台推广跳转"。
4. **商标词不进站名/小程序名/域名**；页脚保留"非官方粉丝资料站，与暴雪娱乐及网易无关"；同时**不许暗示官方认可**（暴雪商标条款）。
5. **AI 生成的图必须显式标识**（《标识办法》第四条 + GB 45438-2025）；导出文件也要含显式标识；纯自绘不落入。这条对图文稿同样生效，发文前先做。
6. **收款不用个人收款码收经营款**（银发〔2021〕259 号，2022-03-01 施行）；年交易额 ≤10 万元免市场主体登记（总局令 37 号）——**免登记 ≠ 免合规收款渠道**，299 元/年约 335 单才触线。
7. **数据不编、不机翻、不写掉落概率**；两源分歧两个都留（副本等级区间与译名那两条已拍板的例外照旧）。
