# 旅途小憩 0.7.2 睡袋首段倒计时

站主确认是自己从背包使用睡袋。实际反馈是刚躺下无海报，接近休息结束才短暂弹出。检查时角色已离开睡袋，保存日志也未覆盖该次铺袋过程。因此用对应事件顺序复现此表现，今天这次现场究竟漏掉了哪一个底层事件仍缺证据。

在模拟中，0.7.1 收到休息状态但没有可读的铺袋施法或引导时无法开表。满层增益刷新到达后，旧版同时创建计时并标记完成，出现短暂闪现。0.7.2 读取睡袋物品 `211527` 刚开始的长冷却，把它作为第二种铺袋信号。仍需同区的户外休息变化和静止条件才启动推断计时。已存在的冷却和公共冷却均不能当作新铺袋。没有活跃计时且只有满层奖励到账时跳过弹窗。有后续叠层时仍可从已确认的层数开始下一段。

Lua 5.1 同一组事件输入中，0.7.1 在刚躺下时未展示，到满层刷新才出现。0.7.2 在奖励到达前展示，刷新确认后收起。共 13 项通过，覆盖冷却比休息状态晚到、可读施法和引导、旧冷却、公共冷却、主城、旅馆、铺袋但未躺、起身和中途叠层。四个 Lua 文件通过语法检查，安装文件和 [0.7.2 ZIP](/D:/project/camp-portrait/dist/CampPortrait-0.7.2.zip) 逐字节一致。

国服待重载后重新铺袋复测。`/campportrait status` 新增 `deploy=spell` 或 `deploy=cooldown`，用来区分铺袋依据。需要在刚躺下时拍海报和倒计时，实际确认首段已出现。
