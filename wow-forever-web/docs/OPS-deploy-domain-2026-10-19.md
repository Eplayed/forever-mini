# 上线这条路 · 域名、备案、成本（2026-10-19 调研）

本轮角色：wow-ops ｜站主问："页面我想部署上去，域名怎么申请，成本多少，备案需要哪些资料"
｜抓取日期统一 **2026-10-19**（阿里云帮助中心 / 腾讯云文档 / 华为云文档 / gov.cn / WIPO / vercel.com 当日访问）

> 这份是决策依据，不是操作手册。凡"查不到权威口径"的地方我直接写明，不编。

## 一、先说三个会影响决策的硬结论

**1. 域名比页面更要避商标词。** 项目红线里"避开魔兽 / 魔兽世界 / WoW / 暴雪 / 艾泽拉斯"在域名上比在页面文字上更严格：页面文字还有"描述性合理使用"的余地，**域名与别人商标完全相同基本没有抗辩空间**。WIPO Overview 3.0 §2.7（D2021-1818 三体宇宙案引用）明确写着：运营粉丝网站的一般权利，**不延伸到注册或使用一个与商标完全相同的域名**，理由是网民会以为该站由权利人赞助或认可。`Warcraft` / `World of Warcraft` 在中国是已注册商标，所以 `warcraft-*`、`wow*` 这类主体串都踩线——**`wowforever-*` 也不行**（UDRP 里"包含商标即可能构成混淆性相似"）。
命名方向：用自造词或本站已有的中文/拼音品牌名，别把商标词根放进域名主体。

**2. 游戏类是前置审批类目，而个人备案拿不到前置审批文件。** 移动云与腾讯云都写明"个人备案不涉及前置审批文件"；上海管局另写"域名前缀带 game 等字样需上传前置审批"。**所以备案前必须先定死网站名称与内容口径**（资料/工具向，不写"游戏"类定性表述），否则大概率被驳回。这一条比广告那条更容易卡住上线。

**3. 广告算不算"经营性"，查不到权威口径。** 法条是硬的（国务院令第 292 号第三条：经营性＝向上网用户有偿提供信息；第十一条：非经营性不得从事有偿服务），但**"站外接广告联盟收入"是否等于"向上网用户有偿提供信息"，工信部与各省通管局没有公开的解释性文件**，我也没找到个人站挂联盟广告被罚的官方案例。网上"月入 500 就认定经营性"那种说法没有任何官方出处，别当依据。
能落地的两条边界：① **ICP 经营许可证个人拿不到**（要求依法设立的公司 + 注册资本 ≥100 万 + 3 人社保）；② 更现实的是**接入商侧**——管局对个人备案明确要求网站不得涉及经营性/产品/价格/商品内容，阿里云答复称个人备案不能放广告类内容。**最可能的结果是整改或注销备案号，不是罚款。**

## 三、ICP 备案（非经营性，个人主体）

**和小程序备案不是一件事，但同源同系统**：都是工信部 ICP 备案，网站 / 小程序 / App **分别提交**，管局审核都是那 **1–20 个工作日**。小程序那条已经在关键路径上，网站这条是另一次提交，不互相顶替。

要准备的材料：大陆身份证正反面（临时证部分省不收）、本人手机号 + 应急号、住址、邮箱、**在接入商 App 上扫码做人脸核验**（主流厂商已取消邮寄幕布）、系统生成的核验单与承诺书、域名证书（华为云仍列为提交材料）。

流程与时限：接入商初审 **1–2 工作日** → 工信部 **12381 短信核验（24 小时内必须点）** → 管局 **1–20 工作日**。**备案本身免费。**

必须绑一台大陆接入资源，这一条最容易踩：阿里云可备案的是 **ECS / 轻量应用服务器 / 云虚拟主机**（要中国内地节点 + 包年包月 ≥3 个月 + 公网带宽，各送 5 个备案服务码）、函数计算套餐包（订单 ≥100 元给 1 码）、建站产品。**CDN、OSS/静态托管、WAF、DDoS、SLB 都不在清单里——纯 OSS+CDN 当不了接入**，得另备一台可备案资源。

数量限制：一个账号一个主体，主体下可多站，但各省封顶不同——**河南 / 湖南 / 湖北 / 安徽个人一次只能 1 个**，黑龙江 / 宁夏 2，福建 / 江西 3，广西 4，陕西 5。腾讯云轻量个人账号同一实例至多 5 个网站。**域名实名主体必须与备案主体完全一致**，后缀和注册商都要工信部批复过的。

备案之后还有两件事：① 页脚中央挂 ICP 备号并链到 beian.miit.gov.cn（《非经营性互联网信息服务备案管理办法》第十三条）；② **开通之日起 30 日内**到全国互联网安全管理服务平台（beian.mps.gov.cn）做**公安备案**，下号后再 30 日内挂公安备案号与图标——不办的后果是警告到停机整顿 ≤6 个月。

## 四、不备案那条路的真实边界

判断标准是**接入/加速范围**，不是域名在哪注册：华为云口径写得很清楚——"域名是否需要备案与域名提供商地域、网站服务器所处地域无关，与加速服务范围有关；服务范围含中国大陆就必须备案，境外服务范围不要求"。所以**解析到境外服务器本身不触发备案**；但把未备案域名解析到境内 IP，会被接入商监测阻断。

可达性实测口径：Vercel 官方 KB 承认大陆无节点无 CDN、`*.vercel.app` 会被阻断或限速，绑自定义域名**可能**改善但不保证可用；Cloudflare 大陆节点是 **Enterprise 单独购买**的，社区实测（非官方，截至 2026-08）`pages.dev` / `workers.dev` 长期 DNS 污染、部分 104.21.x 段被精准阻断，移动宽带最明显；GitHub Pages 各家横评都是"国内最慢"。

**对本站的判断**：这是个纯静态 + 一份 JSON 的资料站，境外托管技术上完全够跑，但目标用户就在国内，**"打不开"等于没有**。所以境外只适合当**验证期**（今天就能上线、零成本、先不看流量），要真做流量必须走备案 + 境内接入。

## 六、我建议的走法（等你拍板）

1. **现在就做**：定域名（自造词，不含任何商标词根）+ 定网站名称与内容口径（资料/工具向，页面与"关于我们"里都不写"游戏"类定性表述）。这两件事不做，备案材料填了也是白填。

## 八、阿里云注册域名的操作步骤（2026-10-19 按官方帮助文档核对）

一手来源：[域名注册快速入门](https://help.aliyun.com/zh/dws/getting-started/quickly-register-a-new-domain-name)、
[第二步：将信息模板关联至域名](https://help.aliyun.com/zh/dws/user-guide/create-a-domain-name-registrant-profile)、
[如何注册域名](https://help.aliyun.com/knowledge_detail/54066.html)。

**顺序很重要：先建信息模板并等审核，再去查域名下单。**
自 2022-02-15 起，注册域名必须关联一个**已通过实名认证**的信息模板；
模板审核官方口径是"通常 1 个工作日，部分 3～5 个工作日"。先建模板，审核期间再想名字，不浪费时间。

1. **账号实名**：阿里云 App 或官网把账号实名认证做掉（个人刷脸即可）。
2. **建信息模板**：域名控制台 → 域名管理 → 信息模板 → 创建新信息模板。
   持有者类型选**个人**；填姓名（与身份证一致）、所属区域、通讯地址（2–128 字符）、邮编、手机号、邮箱，
   并点输入框下方的**邮箱验证**。填完提交，等状态变成「模板实名成功」。
   - 中文填完系统会**自动按拼音生成英文字段**，「吕」会被转成 `lv` 而不是 `lyu` 这类偏差要手动改一下。
   - **别用新顶级域名后缀的邮箱**（如 `xxx@test.club`），官方明写这会让域名订单长时间卡在"处理中"。
3. **查域名**：[阿里云万网](https://wanwang.aliyun.com/) 首页输入名字 → 查询域名。
   结果会并列展示 .com / .cn / .top 等后缀及**首年价格**；"已注册"的可以考虑换名或走交易，别碰溢价词。
4. **下单**：点立即注册 → 选注册年限（1–10 年）→ 选那个已实名成功的信息模板 →（可选）填**优惠口令**压首价 → 支付。
   支付后回到域名列表，等状态变「正常」就是注册成功。
5. **解析**：域名控制台 → 解析，加 **A 记录**指向服务器公网 IP（或 CNAME 指向 CDN 域名）。首次配置基本实时生效。
6. **备案**：阿里云 ICP 代备案系统提交，材料见本文件第三节。
   注意**ECS 按量付费不能备案，要转成包年包月**；轻量应用服务器买的时候就选包年包月。

**给这个项目的两条附加提醒**：① 域名主体串里不要出现 `warcraft` / `wow` / `blizzard` / `azeroth`（第一节那条 UDRP 判断）；
② 域名实名的人必须和后面备案的主体是**同一个人**，中途换人要走过户，白等一轮审核。

`classic` 撞"经典旧世"这条产品线名——不是明着侵权，但被投诉时抗辩空间比自造词小。

| --- | --- | --- |
| `paotu` | "跑图"——玩家自己天天说的词 | 世界页那套点位图、副本入口正是"跑图"要用的东西；两音节、不用拼 |

**选名的四条尺子**：① 拼音能一口读出来、不用拼字母；② 不超过 6–8 个字母，别用连字符和数字；

④ **顺手把同名公众号 / B 站 / 抖音号能不能注册一起查**——他这几条线都在做内容，
名字不一致以后导流会散。

**付钱之前做两件各两分钟的事**：① 在[阿里云万网](https://wanwang.aliyun.com/)查询框里把这几个词一起贴进去看可注册状态；
② 在[中国商标网](https://sbj.cnipa.gov.cn/)按"跑图 / 开图 / 小抄"这类中文词查一遍第 41 类（在线服务）与第 9 类有没有被人注册成商标——
拼音域名撞上别人已注册的中文商标，是国内被投诉的常见路径，比撞暴雪商标的概率还高。

**状态：待用户定名。** 名字定死之前不要提交备案——备案要填网站名称，改一次要走一轮变更。

## 十、"个人能不能给游戏资料站备案"——查到的口径与要走的那条路（2026-10-19）

一手来源：[腾讯云·前置审批相关](https://cloud.tencent.com/document/product/243/36185)、
[腾讯云·网站/APP 信息](https://cloud.tencent.com/document/product/243/19644)、
[阿里云·限制说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/limits)、
[UCloud·前置审批](https://docs.ucloud.cn/beian1/basics/knowledge2)。

**结论：能备，但要按"不涉及网络游戏运营"这条口径把材料做对，且各省松紧不一样。**

1. **前置审批管的是"出版/运营网络游戏"，不是"介绍游戏的资料"。** 腾讯云与 UCloud 都写明：
   游戏类前置审批要的是《游戏版号核发单》，法律依据是《网络出版服务管理规定》第二十七条——
   管的是"**网络游戏上网出版前**"；UCloud 那条写的是"游戏产品正式上线以及**收费之前**需要审批才可以上线运营"。
   本站不运营游戏、不提供下载与充值、零 UGC，按这个定义不属于该类目。
2. **操作口径（腾讯云文档明写）**：网站服务内容选「**其他**」，前置审批项勾「**以上都不涉及**」。
   同一篇还写明"**个人无法办理前置审批文件**"——所以一旦被判定涉及，就是死路，只能改名称与描述。
3. **被要求提供前置审批时的正规出路**（阿里云限制说明里那条"重要"）：
   先去问批复单位（省级新闻出版局），拿到"无需办理"的答复后，
   **在备案初审环节按审核人员要求填写备注信息或提交说明书**。
   说明书要写清这句：本站为公开游戏数据的整理与查询，不提供游戏运营、下载、充值、用户发布内容等服务。
4. **真正的风险在"名称"，不在内容。** 个人备案被以"涉及前置"驳回，最常见两种原因：
   前置审批项没选"其他"；**网站名称里带了会被联想到前置类目的词**（老例子里连"博客/BLOG"都会被驳）。
   所以备案名称建议用中性的「跑本笔记」/「跑本资料库」这一类，不要写"游戏""攻略""社区""论坛""商城"。
   另外重庆管局等口径里"个人备案不能涉及游戏类"写得更粗，**这一条只能问接入商与本省管局**。
5. **后缀这一头没问题**：`.top` 2015 年 4 月获工信部资质审批，可正常备案；
   但 `.game` 这类新顶级域部分地区不支持，别用。

**还没确认的（要站主自己问，我查不到权威统一口径）**：站主备案所在省对"个人 + 游戏资料站"的实际执行松紧。
问法建议照抄这句给阿里云备案客服：*"个人主体、非经营性、网站内容是单机/网络游戏资料整理与查询、
零用户发布、不提供下载与充值，网站名称叫「跑本笔记」，服务内容选其他、前置审批勾都不涉及，
这样能不能过管局审核？需不需要提前准备说明书？"*

## 十一、2026-10-22 补：还要不要买服务器 + 部署一整套缺什么（实测过产物）

站主问：站已发在 GitHub Pages，接下来要不要在阿里云买服务器，一整套还缺什么。

### 11.1 服务器只在一件事上是必需的

**要备案才必须买；买了它也不是拿来放网站的。** 本文件第三节那条清单是关键：OSS / CDN / 静态托管都不在可备案资源里，
纯 OSS+CDN 当不了接入，所以那台轻量的真实身份是**备案门票**。网站文件继续放 GitHub Pages、或搬到 OSS 静态托管，都不需要服务器。

| 你要的是 | 要不要服务器 | 钱 |
| --- | --- | --- |
| 网页能访问、先试有没有人用 | **不要** | 域名首年 14（`.top` 促销）～85（.com），其余 0 |
| 国内打开快 + 微信内稳 + 有备案号 | **要一台内地包年包月 ≥3 个月** | 首年 38～68 促销，**次年回标准价（月付 45 档 ≈540/年）** |
| 把站搬进境内 | 服务器仍是门票，文件放 OSS + CDN | 流量 0.24 元/GB 或 100GB 14 元/年 档 |

**结论：先别买。** 门票是年费、退起来麻烦，而能不能过审还卡在本文件第十节那个电话上。买之前先问阿里云备案客服。

### 11.2 实测：现在这份 Pages 产物缺 4 件基础件

测的对象是 `wow-forever-web/release/ghpages/`（55 MB、21 个 HTML、只有 `.nojekyll`）：

| 缺的东西 | 后果 | 补的成本 |
| --- | --- | --- |
| `CNAME` | **实测线上现状（只读 `gh api`）：`custom_domain` 为 null、build_type 是 legacy（分支发布）——还没绑域名。** 而 `deploy-gh-pages.py` 第 188 行是 `git push --force` 把整棵产物树重推一遍：**绑域名之后再跑一次发布，GitHub 在分支里生成的那份 CNAME 会被冲掉，域名直接掉回默认地址**。所以绑域名那一步必须同时把 `CNAME` 打进发布包，不是只在 Pages 设置里填一下 | 一行文件名 + 发布脚本一处改动 |
| `robots.txt` + `sitemap.xml` | 资料站的自然流量入口就是搜索引擎，这两件没有＝百度/Google 只能靠爬导航发现页面；国内还得去百度站长平台提交 | 由 `build-data.js` 从现有页面清单派生，**不建第二份真相** |
| `404.html` | 玩家输错地址看到的是 GitHub 默认页，上面印着 `Eplayed/wuxian-atlas`——不专业，还把仓库名摆出来 | 一页静态壳 |
| 传输压缩 | **这一条我第一版算错了，按实测更正**：第一次测 `items.json` 我没带 `Accept-Encoding`，拿到的是未压缩的 5.0 MB，于是推出"1 000 次≈5 GB≈1.2 元"。带压缩重测：GitHub Pages **是给 gzip 的**（响应头 `content-encoding: gzip`、`x-github-edge-region: japaneast`），**真实线上字节 570,845 B（557 KB）**，所以流量费比我初判小一个数量级——但"慢"跟压缩无关，见下面那张实测表 | 不用再折腾 br；要做的是**拆片降首屏**，见 11.4 |

#### 实测吞吐（2026-10-22 · 站主这台 Mac + 家宽 · `curl --compressed`）

| 对象 | 结果 |
| --- | --- |
| `index.html` 连打 10 次 | 9 次成功，总耗时 0.65 / 0.68 / 0.74 / 1.65 / 1.71 / 3.0 / 7.5 秒；**1 次 20 秒超时打不开**；TLS 握手从 0.43 秒抖到 6.59 秒 |
| `data/items.json`（压缩后 557 KB）连打 5 次 | 全部 200，总耗时 3.19 / 6.70 / 7.90 / 12.15 / 13.62 秒，**中位数约 8 秒** |
| 首屏 JS bundle（117 KB）连打 3 次 | 1.45 / 1.65 / 2.13 秒 → **有效吞吐约 55–80 KB/s** |

**换算给玩家视角**：打开物品库要拉 首屏 117 KB + `items.json` 557 KB（再点详情还有分片），**约 1.2 MB，按实测吞吐就是十几到二十几秒才出内容**。
两个上限顺手算清：Pages 的 100 GB/月软上限按 1.2 MB/PV 约等于 **8 万次 PV/月** 才撞线，近期不是约束；境内 CDN 0.24 元/GB 档按同口径 **1 万次访问约 2.9 元**，也不是钱的问题。
**所以这条的正确结论是**：瓶颈不是"文件太大要花钱"，而是**这条通道本身只有 55–80 KB/s、还有 1/10 概率直接超时**。
换域名不解决它；分时段多跑几轮才算数，单次采样不代表全国。

### 11.3 备案之后新长出来的义务（现在页脚没有）

1. 页脚中央挂 **ICP 备案号**并链到 `beian.miit.gov.cn`（《非经营性互联网信息服务备案管理办法》第十三条）。
2. **开通之日起 30 日内**做公安备案，下号后挂公安备案号与图标。
3. 现在页脚只有"非官方粉丝资料站，与暴雪娱乐及网易无关"那一行——这两条要加，且加进发布清单防被冲掉。

### 11.4 建议顺序（前两步不花钱、不依赖任何审批）

1. **今天就该补**：`CNAME` + `robots.txt` + `sitemap.xml` + `404.html` 进发布产物。在 Pages 上也立刻生效。
2. **把首屏 1.2 MB 降到 300 KB 以下**——按职业/按页拆 `items.json` 与 `items-detail.json`（gzip 已由 Pages 做掉，这一步不是压缩而是拆片）。这是免费、立刻见效、且比备案优先的一步。
3. 实测国内到家宽打开现站的耗时与成功率（多次采样，不拿单次观测下结论），拿到数据再决定搬不搬。
4. **打那个阿里云备案客服电话**（问法见第十节末尾），问完再决定要不要买门票。
5. 名字定稿 → 买 `paoben.top` → 模板实名 → 等 2–3 天同步 → 提备案 → 管局 1–20 工作日 → 公安备案 → 再接 OSS+CDN。
6. **小程序备案仍然排在网页备案前面**（关键路径没变）。
