# 上线这条路 · 域名、备案、成本（2026-10-19 调研）

本轮角色：wow-ops ｜站主问："页面我想部署上去，域名怎么申请，成本多少，备案需要哪些资料"
｜抓取日期统一 **2026-10-19**（阿里云帮助中心 / 腾讯云文档 / 华为云文档 / gov.cn / WIPO / vercel.com 当日访问）

> 这份是决策依据，不是操作手册。凡"查不到权威口径"的地方我直接写明，不编。

## 一、先说三个会影响决策的硬结论

**1. 域名比页面更要避商标词。** 项目红线里"避开魔兽 / 魔兽世界 / WoW / 暴雪 / 艾泽拉斯"在域名上比在页面文字上更严格：页面文字还有"描述性合理使用"的余地，**域名与别人商标完全相同基本没有抗辩空间**。WIPO Overview 3.0 §2.7（D2021-1818 三体宇宙案引用）明确写着：运营粉丝网站的一般权利，**不延伸到注册或使用一个与商标完全相同的域名**，理由是网民会以为该站由权利人赞助或认可。`Warcraft` / `World of Warcraft` 在中国是已注册商标，所以 `warcraft-*`、`wow*` 这类主体串都踩线——**`wowforever-*` 也不行**（UDRP 里"包含商标即可能构成混淆性相似"）。
命名方向：用自造词或本站已有的中文/拼音品牌名，别把商标词根放进域名主体。

**2. 游戏类是前置审批类目，而个人备案拿不到前置审批文件。** 移动云与腾讯云都写明"个人备案不涉及前置审批文件"；上海管局另写"域名前缀带 game 等字样需上传前置审批"。**所以备案前必须先定死网站名称与内容口径**（资料/工具向，不写"游戏"类定性表述），否则大概率被驳回。这一条比广告那条更容易卡住上线。

**3. 广告算不算"经营性"，查不到权威口径。** 法条是硬的（国务院令第 292 号第三条：经营性＝向上网用户有偿提供信息；第十一条：非经营性不得从事有偿服务），但**"站外接广告联盟收入"是否等于"向上网用户有偿提供信息"，工信部与各省通管局没有公开的解释性文件**，我也没找到个人站挂联盟广告被罚的官方案例。网上"月入 500 就认定经营性"那种说法没有任何官方出处，别当依据。
能落地的两条边界：① **ICP 经营许可证个人拿不到**（要求依法设立的公司 + 注册资本 ≥100 万 + 3 人社保）；② 更现实的是**接入商侧**——管局对个人备案明确要求网站不得涉及经营性/产品/价格/商品内容，阿里云答复称个人备案不能放广告类内容。**最可能的结果是整改或注销备案号，不是罚款。**

## 三、ICP 备案（非经营性，个人主体）

**和小程序备案不是一件事，但同源同系统**：都是工信部 ICP 备案，网站 / 小程序 / App **分别提交**，管局审核都是那 **1–20 个工作日**。小程序那条已经在关键路径上，网站这条是另一次提交，不互相顶替。

要准备的材料：大陆身份证正反面（临时证部分省不收）、本人手机号 + 应急号、住址、邮箱、**在接入商 App 上扫码做人脸核验**（主流厂商已取消邮寄幕布）、系统生成的核验单与承诺书、域名证书（华为云仍列为提交材料）。

流程与时限：接入商初审 **1–2 工作日** → 工信部 **12381 短信核验（24 小时内必须点）** → 管局 **1–20 工作日**。**备案本身免费。**

必须绑一台大陆接入资源，这一条最容易踩：阿里云可备案的是 **ECS / 轻量应用服务器 / 云虚拟主机**（要中国内地节点 + 包年包月 ≥3 个月 + 公网带宽，各送 5 个备案服务码）、函数计算套餐包（订单 ≥100 元给 1 码）、建站产品。**CDN、OSS/静态托管、WAF、DDoS、SLB 都不在清单里——纯 OSS+CDN 当不了接入**，得另备一台可备案资源。

数量限制：一个账号一个主体，主体下可多站，但各省封顶不同——**河南 / 湖南 / 湖北 / 安徽个人一次只能 1 个**，黑龙江 / 宁夏 2，福建 / 江西 3，广西 4，陕西 5。腾讯云轻量个人账号同一实例至多 5 个网站。**域名实名主体必须与备案主体完全一致**，后缀和注册商都要工信部批复过的。

备案之后还有两件事：① 页脚中央挂 ICP 备号并链到 beian.miit.gov.cn（《非经营性互联网信息服务备案管理办法》第十三条）；② **开通之日起 30 日内**到全国互联网安全管理服务平台（beian.mps.gov.cn）做**公安备案**，下号后再 30 日内挂公安备案号与图标——不办的后果是警告到停机整顿 ≤6 个月。

## 四、不备案那条路的真实边界

判断标准是**接入/加速范围**，不是域名在哪注册：华为云口径写得很清楚——"域名是否需要备案与域名提供商地域、网站服务器所处地域无关，与加速服务范围有关；服务范围含中国大陆就必须备案，境外服务范围不要求"。所以**解析到境外服务器本身不触发备案**；但把未备案域名解析到境内 IP，会被接入商监测阻断。

可达性实测口径：Vercel 官方 KB 承认大陆无节点无 CDN、`*.vercel.app` 会被阻断或限速，绑自定义域名**可能**改善但不保证可用；Cloudflare 大陆节点是 **Enterprise 单独购买**的，社区实测（非官方，截至 2026-08）`pages.dev` / `workers.dev` 长期 DNS 污染、部分 104.21.x 段被精准阻断，移动宽带最明显；GitHub Pages 各家横评都是"国内最慢"。

**对本站的判断**：这是个纯静态 + 一份 JSON 的资料站，境外托管技术上完全够跑，但目标用户就在国内，**"打不开"等于没有**。所以境外只适合当**验证期**（今天就能上线、零成本、先不看流量），要真做流量必须走备案 + 境内接入。

## 六、我建议的走法（等你拍板）

1. **现在就做**：定域名（自造词，不含任何商标词根）+ 定网站名称与内容口径（资料/工具向，页面与"关于我们"里都不写"游戏"类定性表述）。这两件事不做，备案材料填了也是白填。
2. **本周可做**：先按 A 档挂境外，把站点跑起来看有没有人用（0 成本，不影响后面备案，域名解析改一下就行）。
3. **有流量迹象再上 B 档**：买 .com 或 .cn（实名到你自己名下）+ 一台轻量（首年 68 元档就够）→ 提 ICP 备案（1–20 工作日）→ 备案下来后 30 日内做公安备案 → 再接 CDN。
4. **广告先别开**。不是不能开，是**在备案号下来之前开**风险最高；等备案过了、站点名称与口径定死了，再单独决定要不要挂联盟，那时候要权衡的是"接入商对个人站放广告的态度"，不是法条。

- **暴雪当年投诉 `worldoflordcraft` 那条是二手转述**（百度百科与百度知道），我没找到 ADNDRC 裁决原文，**按"待核"处理，别当铁证**。商标词的风险判断不依赖这一条——WIPO Overview 3.0 §2.7 那条才是依据。

## 八、阿里云注册域名的操作步骤（2026-10-19 按官方帮助文档核对）

一手来源：[域名注册快速入门](https://help.aliyun.com/zh/dws/getting-started/quickly-register-a-new-domain-name)、
[第二步：将信息模板关联至域名](https://help.aliyun.com/zh/dws/user-guide/create-a-domain-name-registrant-profile)、
[如何注册域名](https://help.aliyun.com/knowledge_detail/54066.html)。

**顺序很重要：先建信息模板并等审核，再去查域名下单。**
自 2022-02-15 起，注册域名必须关联一个**已通过实名认证**的信息模板；
模板审核官方口径是"通常 1 个工作日，部分 3～5 个工作日"。先建模板，审核期间再想名字，不浪费时间。

1. **账号实名**：阿里云 App 或官网把账号实名认证做掉（个人刷脸即可）。
2. **建信息模板**：域名控制台 → 域名管理 → 信息模板 → 创建新信息模板。
   持有者类型选**个人**；填姓名（与身份证一致）、所属区域、通讯地址（2–128 字符）、邮编、手机号、邮箱，
   并点输入框下方的**邮箱验证**。填完提交，等状态变成「模板实名成功」。
   - 中文填完系统会**自动按拼音生成英文字段**，「吕」会被转成 `lv` 而不是 `lyu` 这类偏差要手动改一下。
   - **别用新顶级域名后缀的邮箱**（如 `xxx@test.club`），官方明写这会让域名订单长时间卡在"处理中"。
3. **查域名**：[阿里云万网](https://wanwang.aliyun.com/) 首页输入名字 → 查询域名。
   结果会并列展示 .com / .cn / .top 等后缀及**首年价格**；"已注册"的可以考虑换名或走交易，别碰溢价词。
4. **下单**：点立即注册 → 选注册年限（1–10 年）→ 选那个已实名成功的信息模板 →（可选）填**优惠口令**压首价 → 支付。
   支付后回到域名列表，等状态变「正常」就是注册成功。
5. **解析**：域名控制台 → 解析，加 **A 记录**指向服务器公网 IP（或 CNAME 指向 CDN 域名）。首次配置基本实时生效。
6. **备案**：阿里云 ICP 代备案系统提交，材料见本文件第三节。
   注意**ECS 按量付费不能备案，要转成包年包月**；轻量应用服务器买的时候就选包年包月。

**给这个项目的两条附加提醒**：① 域名主体串里不要出现 `warcraft` / `wow` / `blizzard` / `azeroth`（第一节那条 UDRP 判断）；
② 域名实名的人必须和后面备案的主体是**同一个人**，中途换人要走过户，白等一轮审核。
