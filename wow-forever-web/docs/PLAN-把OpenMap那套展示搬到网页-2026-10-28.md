# 把 OpenMap 那套地图展示搬到网页 · 可行性与范围 · 2026-10-28

本轮角色：wow-planner ｜任务：把站主那句"他这个地图方式很好"拆成可判定的机制清单，定哪几层能搬 ｜产出：本文件 ｜交接给：站主拍范围 → wow-dev 实现、wow-data 补图。

## 一、先把"他的方式"说清楚（读代码，不是看截图猜）

证据来自只读挂载 `/_cn_beta_/Interface/AddOns/OpenMap`（18,176 行 Lua），逐条带 `文件:行号`。他的地图之所以"看着好"，是**六件事叠出来的**，不是一张图：

| # | 机制 | 他是怎么做的（证据） | 我们能不能搬 |
| --- | --- | --- | --- |
| 1 | **分层叠图 + 逐层淡入** | `Map/Stitch.lua:10` 注释直接写 "Layers, bottom to top, and the zoom where each fades in"；`1071-1091` 排了 15 层：海图→世界底图→大陆→区域瓦片→探索覆盖→城市→小地图→未探索压暗→地下洞穴→**文字**→手绘→纸纹→图标 | **能搬做法，搬不了内容**：层顺序与"随缩放淡入淡出"是纯逻辑；但那 15 层里 11 层的图是它自烘的蒙版/色带/纸纹，我们一件都拿不到 |
| 2 | **底图运行时向客户端要文件号** | `Stitch.lua:281` `C_Map.GetMapArtLayerTextures(mapID, 1)`；`347` `tonumber(f) or f`；副本逐层 `Data/DungeonMaps.lua:13` `{ tiles = { 448226, … }, name = "The Courtyard" }`；全目录 grep **没有** `interface\maps\` 路径字符串 | **等价于我们已经判的这条路**：图从客户端按号导，不碰它的 Media。这条正是 #109 那份任务书在做的事 |
| 3 | **地名是运行时画的字，不是烘在图里** | `Data/Labels.lua:1` "The continents' and seas' names, lettered live where Blizzard's map art had them"；坐标参照是**那张图的美术像素**（`Labels.lua:6` "its pixels, 1002 x 668"，每条 `lines={{left,right,baseline,capheight}}`）；字号由 cap 高反推（`Stitch.lua:1562`）；整层随缩放淡出（`58 LABELS_OUT = {3, 4}`）。**没有文字碰撞避让** | **能搬，而且这是我们最缺的一层**：网页画字比 Lua 容易得多（HTML/SVG 绝对定位）。前提还是那句——图上不能有烘死的地名，否则叠两层字 |
| 4 | **给区域染色/补空洞** | `Data/Grade.lua:1` 每区域一组 `{r,g,b}` 乘数，但生效靠它自己的 `MapBand/<id>` 掩膜；`Tones.lua` 每区一个主色；`GapFills.lua:9` 手填补地**直接引用它的贴图** | **搬不了**：这三样都是"它的图 + 一张数字表"，缺图就只剩数字，没有意义 |
| 5 | **无级缩放 + 一堆交互** | `WorldMap.lua:8` "zoom runs from the whole world down to street level, anchored at the cursor"；滚轮步长 56、深度域 `{16,192,8}`；图标按缩放出现（`51 iconsFrom`）；副本侧楼层左右箭头 `Dungeons.lua:409/412`、切翼 `WING_FLOORS:33`、侧栏 floors/bosses/quests/loot `477`、图内缩放 0.5–4；另有画笔、航线、路点、搜索、游戏手柄 | **挑着搬**：楼层/翼切换、图标分级出现、点搜索定位、局部放大——这四样我们能落地；**连续无级缩放搬不了**（见第二节） |
| 6 | **没图时的两级兜底** | ① 空白羊皮纸 + 一句实说：`Dungeons.lua:293` "a dungeon the client has no map of: the map's own parchment, blank, and a word on it"，文案 `302` "WoW Forever has no map of this dungeon yet."；② **自绘示意图 + 图上署名**：`193` 取图顺序 `MapDungeonMaps[id] or MapDungeonDrawn[id]`，`234` `view.credit:SetText("Map by %s")` | **已经在做，但做得没它清楚**：我们有 `bossMapKind: addon-drawn` + 页面标"这张是示意图"；**它多的一件事是给画图的作者署名**，这条值得抄 |

## 二、为什么不能整包搬"无级缩放"

它从世界缩到街级不糊，靠的是**换图**而不是放大：世界底图 → 大陆 → 区域 12 片 → 城市 → 小地图瓦片（`Stitch.lua:1071-1091` 那几层各自是一套文件号），越深换越细的一张。我们手上有什么：

- 区域图：现在是 **560×373** 的成品图；客户端原片是 4×3 片 256 = 1024×768、画面区 **1002×668**（10-28 实测结案，见 `PLAN-区域地图按OpenMap那套重做-2026-10-28.md`）。**只大一档**，放大到 4× 就是糊的。
- 副本图：现在 28 座各**一张**合成图，没有逐层（#109 等回件）。
- 中间那几层（城市级、小地图瓦片）**我们一张都没导过**，也没有对应数据。

所以"滚轮从大陆缩到街级"这条，硬搬的结果是一张糊图 + 一堆空白层。**要搬就得连 LOD 链一起导图**，那是 #109 之外的另一件事，工时在 Windows 侧，不在前端。

## 三、建议搬的四件（按能不能马上做排）

### S1 副本逐层图 + 层/翼切换，只画该层的点 —— 直接修 #108

界面：图上方一排**层名按钮**（`The Courtyard` 这种，中文由我们标），多翼的本再一排翼；点一层，图上只留那一层的点；点首领名跳到它那一层。
现在是什么样：`DungeonPage.vue:129` 只有一个 `PinMap`，`384` 把层号写成一行文字提示，**7 座跨层本的点全压在一张图上**——这就是 #108。
要什么数据：层与翼的对应，`DungeonMaps.lua` 那张表就是（MIT 数据表，可取，须署名）；我们的 `dungeon-geo.json` 里 `bossPos[*].floor` 已有层号（15 座带层号）。
要什么图：**#109 那 756 片回件**。
验收：一座跨层本（选 `bossPos` 层号最多的那座）逐层切换，每层点数之和 = 该座 `bossPos` 总点数；换层时点数不变、位置不串层。

### S2 图上中文标注层（字是我们画的，不指望图里有字）

界面：首领名/据点名以 HTML 绝对定位叠在图上，位置参照**画面区像素坐标**换算成百分比（和现在点位同一套参照物，1002×668 已结案）；字带一层暗底描边保证在羊皮纸底色上可读；缩放或图变小时整层淡出（抄它 `LABELS_OUT` 那个做法）。
能不能用在区域图上：**不能直接用**——A 路实拍那张图里暴雪的地名是烘死的，再叠一层就是两套字。所以 S2 先只做**副本层图**（游戏内副本地图的字本来就是 UI 画的，导出的瓦片理论上干净——**这条要等回件看第一张才能确认**，见第一节第 3 行末尾）。
验收：一张层图上的首领标注数 = 该层点数；标注不超出画面框；关掉标注层图仍可看（做成一个真生效的开关，不许白放）。

### S3 图标按缩放/按选择出现 + 点搜索定位到点

界面：一层点多的时候（贫瘠之地那种 33 点）默认只画首领与玩家当前选中的那颗，其余点收进右侧列表；点列表一行 → 图上那颗高亮并滚进视口。抄的是它 `iconsFrom`（按缩放决定哪级图标出现）这个**思路**，不是它的图。
现在是什么样（先改对，别看截图猜）：**列表与图的联动已经有了**——`PinMap.vue:66` 行上 `:class="{ on: active === … }"`、`:69` 点一行就 `pin(key)` 钉住图上那颗；缺的是**分级**：33 颗一次全画，谁重要谁次要看不出来。所以 S3 只补"默认收哪些、点开列表才画哪些"这一层，不是从零做联动。
验收：默认态点数 ≤ 该层首领数 + 1；点列表任一行，图上恰好一颗高亮且命中测试可点中；关掉分级后其余点仍画得出来（防"选了看不见"）。

### S4 借它一句兜底话 + 给示意图署名

界面：没有图的副本，那块不再只是"序号位置画个 `—`"，而是**一张我们自绘的羊皮纸 + 一句"《无限》客户端还没有这座本的地图"**；用插件作者自绘示意图那 3 座，在图脚下加一行 **"图由 <作者> 绘，不是游戏里的地图"**。
现在是什么样（按代码）：没底图时这块**不是空白**——`PinMap.vue:59` 会出一行"地图编号 NNNN"、`:70` 每行序号位置是 `—`，列表照给；也就是说它把"没有图"这件事说成了半个内部字段，玩家看到的是**一排 `—`**，不是一句人话。
依据：它 `Dungeons.lua:302` 与 `234` 就是这么做的（一句人话 + 作者署名）；我们红线本来就要求"缺数据显示待实测、示意图就地标注"，这条只是把标注做完整。
成本：纯前端 + manifest 里已有作者字段，**不等任何回件，现在就能做**。

## 四、这一轮明确不做

- 连续无级缩放、街级 LOD、探索度压暗、区域染色/色场、海图、画笔与航线、游戏手柄——**都依赖它 Media 里的图或我们没导的层级**。
- 抄它的任何一张贴图（含 `MapArt` 手清图、`MapBanner` 城市横幅）——许可边界已定死，见 `DATA-插件盘点-2026-10-28.md` 第五节。
- 手机端另开一套地图交互——站主 2026-10-28 定「手机网页版不做」。
