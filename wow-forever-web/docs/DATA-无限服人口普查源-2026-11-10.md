# 无限服人口普查数据源

2026-11-10，北京时间。主角色 wow-data。

## 已接入的社区样本

从 Everloot 的公开人口汇总 API 读取近 7 天正式服窗口，数据截至 2026-11-10 09:10（北京时间）。来源公开约 14,950 个观察角色，样本来自 13 个插件安装。联盟约 3,290，占 22.0%，部落约 11,660，占 78.0%。职业人数与占比取 API 的全样本九职业分组。只保留两个阵营和九职业的汇总值。 [公开汇总 API](https://everloot.app/api/tools/population?window=week) · [统计页面](https://everloot.app/census)

统计范围是来源的 `scope.id=all`。地区与规则集未分组，因此页面写「Everloot 社区样本」，国服单独显示「暂无已核样本」。来源每个公开人数独立四舍五入到 5 的倍数，本站沿用来源公布的占比。缺失或隐去的单元格禁止补零、从总数反推或拼接其他网站数据。13 个安装代表记录来源数量。两阵营人数也只描述这个样本的构成。 [采样方法](https://everloot.app/methodology#population)

## 署名和更新边界

- 共享基底为 [population-census.json](../app/data/population-census.json)，本文件内的 Everloot 汇总及其归一化数据按 CC BY-SA 4.0 发布，署名 Everloot contributors，附来源及许可链接。站内只重排职业顺序、映射站内 ID 和格式化显示比例。来源程序、图标和个体观察行均未导入。 [Everloot 使用条款](https://everloot.app/terms) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 当前无分阵营职业分布，因此小程序首版只画全样本九职业表。下次更新继续取同一个公开汇总端点，逐项核定窗口、日期、规则、地区范围、署名和公开的样本格。数据源不可用时保留已核快照日期。
- Raider.IO 的大陆区目前无覆盖样本，公开页面的自动化和商业复用有其使用条件。WoWCensus 和亚服阿莫比继续用于对照方法。查核时本机未有运行中的游戏客户端，未做国服双阵营实测。国服统计等到有允许复用的独立汇总或同规则集双阵营样本再接。 [Raider.IO 统计](https://forever.raider.io/cn/population) · [Raider.IO 使用条款](https://raider.io/terms-of-use) · [WoWCensus](https://wowcensus.io/forever/) · [阿莫比方法](https://wowamobi.com/method)

## 小程序发布口径

本地只读聚合可以开发。职业固定顺序，页面只有样本阵营与职业人数或比例、时间范围和出处，无角色查询、职业强弱判断、用户投稿或外部页面跳转。提审前按实际开放类目复核。 [腾讯云类目说明](https://cloud.tencent.com/document/product/1078/43316)
