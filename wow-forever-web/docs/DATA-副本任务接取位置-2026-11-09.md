## 全量合并口径

- 输入为当前共享任务表、`questie-quests-full.json` 的任务与 NPC ID，以及本机 DungeonsForever 的 `Data_QuestStartLoc.lua`、`Data_NPCLoc.lua`、`Data_DungeonQuestFlow.lua`。源文件 SHA-256 记在 [接取快照](../app/data/upstream/df-quest-pickups.json)。
- 批量候选先用任务中英文名原文与任务等级锁到唯一 Questie 任务 ID，且须仅有一个接取 NPC，没有同时列出的接取物品或场景物件。插件按任务记录有点位时，NPC ID 须与 Questie 一致。插件只有 NPC 定位记录时，用前述已核 NPC ID。既有接取人和来源中的中英文名无法对上、地图名无法唯一核定、坐标不完整或为双零的行留给人工核对。
- 合并脚本按副本 ID 与任务中文名挂接已核快照，保留原任务列表。较早推得且与 NPC 地图不同的接取地区留作异值。任务开始者是物品的行保留原口径。
- 396 条任务中，接取人 336→346，地点 300→370，新增 187 组坐标。补充快照含 188 条、覆盖 26 座。其余 209 条无核实坐标。50 条无接取人的条目包含由物品等方式开启的任务。
