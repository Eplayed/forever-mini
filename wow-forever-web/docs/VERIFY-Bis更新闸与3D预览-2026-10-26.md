## 二、3D 侧：不碰客户端也能验的那一半，全验穿了

参考站的做法是"每套一个预烘 GLB + three.js 懒加载"。模型文件要等 Windows 那次探针（B3），
但**前端这一半不需要真模型**，所以本轮用**本站自己生成的占位模型**把这条链接通：

| 环节 | 落点 | 说明 |
| --- | --- | --- |
| 模型从哪来 | `tools/build-bis-placeholder-model.py` | 纯几何体自己拼：6 块身体 + 18 个按部位命名的装备件，9.4 KB。**不含任何游戏客户端资产，也不含第三方站的模型文件** |
| 怎么登记 | `tools/register-bis-models.py` → `art.json.bisModels` | 页面不许猜文件在不在；台账里没有自产模型（`origin != self-generated`）→ 那个按钮**根本不渲染**。脚本名只留在 `img/models/manifest.json`，抄进 `art.json` 会被禁词闸拦下（本轮真被拦了一次） |
| 部位怎么对上 | `app/src/lib/bis-model.js` + `app/tests/bis-model.spec.js` | 中文部位 → 节点名一张表，**6 条单测直接拿真 `bis.json` 跑**：38 套里出现过的每个部位都要映射得到、两边节点名互为全集、两枚戒指/饰品分落两格、认不出的进 `unmapped`（界面上如实列出来，不硬塞到别的格子冒充） |
| 前端 | `app/src/components/ModelViewer.vue` | three.js 与 GLTFLoader **全在 `onMounted` 里动态 import**；染色读 `tokens.css` 的 `--q*`（不抄第二份色值）；这一套没穿的部位直接不画 |
| 界面 | `BisPage.vue` 中间那一栏 | 默认还是职业原画 + 一个「旋转 3D 模型」按钮，点开才换 3D，再点回图片。**"这是占位模型、不是游戏里的样子"这句话写死在界面上**；这句和"没 WebGL 退回原画"那句都放在图**下面**——第一版浮在图上，实拍发现它把模型本身盖掉一半，而"看效果"要看的正是模型 |

**实测到的三条事实**（都是量出来的，不是"看着像"）：

- 懒加载成立：不点按钮时 3D 相关请求 **0 条**；点下去才下 `three.module-*.js`（746.95 KB）、
  `GLTFLoader-*.js`（46.62 kB）、`placeholder.glb`（9.4 KB）。
- 渲染器真的在跑：canvas 上 `data-engine="three.js r186"`，328×300。
- **两帧对比 37.3%**（判据 ≥8%）：开 3D 与退回图片，中间那块内容确实换了。

**这条像素判据是本轮最值钱的收获**：第一版 `paint()` 没判 `isMesh`，
把 `gltf.scene` 那个**带名字的根组节点**当成"这一套没穿的部位"整个藏了——
于是 canvas 在、分包下了、按钮 `aria-pressed` 翻了、脚本报错为零，
**屏幕上却只有背后那张原画**。只看 DOM 一律查不出来，是看截图才发现的。
所以门禁那条判据故意做成"必须比出像素差异"，而不是"canvas 存在"。
（顺手记一笔：`readPixels` / `drawImage` / `toDataURL` 在这套 headless 里读到的全是 0，
试过给渲染器加 `preserveDrawingBuffer` 也一样——所以判据走**元素截图 + PIL 比像素**，
那面旗没留下任何作用，已经从组件里删掉。）

## 五、没验到的 / 不该算我验的

1. **真模型长什么样**——占位模型只证明"前端这条链通了"，不证明装备能烘出来。
   门槛①（`ItemDisplayInfo` / `CharSections` / `PlayerKit` 在本服客户端里有没有）仍要 Windows 跑一次（待办 #103）。
2. **真机手感**：拖拽旋转、帧率、低端机是否掉帧——只在 headless 里量过静态一帧。
3. **没有 WebGL 的浏览器**：降级路径代码写了（`fail()` → 退回原画 + 一句原因），
   但本轮没构造出"真的没有 WebGL"的环境跑通它——现在门禁那台浏览器反而**有**了 WebGL。
4. **自动重烘**：参考站凌晨还在重烘模型，我们这边转换器是 GUI（无 CLI），做不到同一条；
   真要铺 38 套，得先解决批量烘法（待办 #104 的红线之外，还有一条工时线）。
5. 375 那一档本轮按站主 10-25 的决定**不作门槛**，但配装页自己的 375 断言仍拦红，
   新按钮已纳入那条 44px 判据（`@media (max-width:720px)` 抬到 44）。
