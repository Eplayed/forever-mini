## 四、几何：坐标能不能落，这一条是好消息也是坏消息

**好消息**：63 张整层图的内容框**全部实测为 (0,0)→(1002,668)、比例 1.5000**，和 10-28 区域图那一格结案的是同一个参照物。留白没被裁掉。

**坏消息（这就是 #108 的真障碍）**：

- 我们 `dungeon-geo.json` 里**没有 `instanceMapId` 这个字段**——`shadowfang-keep` 顶层只有 `entry / bossPos / bossMap / bossMapKind / bossMapRatio / provenance`，`entry.mapId` 是 **1421（银松森林，那是入口所在的区域图号，不是副本号 33）**。也就是说这 25 座**接不上号**。
- 现有首领坐标是**另一张图的百分比**：`bossMap = img/art/dungeonmaps/dmap_shadowfangkeep.webp`、`bossMapRatio = 512/512`——一张 512 见方的 XR/DF 底图。新图是 1002×668 的官方层图。**百分比不能直接搬**，搬了就是第二次犯 #108。
- 我们的 `floor` 号来自 DF，OpenMap 的层序是它自己那张表的序号，**两套层号是不是同一套，正是盘点文档第六节要求"逐座证明"的那件事**，哈希与文件对不出来，只能逐座核。

**所以**：包合格 ≠ #108 可修。#108 还差一层人工对照（中文本名 ↔ 英文本名 ↔ 层号语义 ↔ 每座至少一个可识别锚点），这层没做完之前，不许把这 63 张接上线把旧点直接叠上去。

## 五、两个改动既有判断的发现

### ① 层图**烘着中文本名横幅**，而且图是本地化的

`RESULT.notes` 的 EXTRA FINDING 说这 756 片本身带 baked text——副本名横幅。我打开 `33_1.png` 亲眼看到顶部横幅写的是**「影牙城堡」**（简体），不是英文也不是韩文。

- **对 S2 的影响**：副本名**不用我们标**（标了就是双份字）；要标的只有**首领名与层名**。
- **对素材登记的影响（新增硬要求）**：这批图的**文字内容随客户端语言变**。同一号在英文客户端导出会是 "Shadowfang Keep"。所以 manifest 每条必须记 **build + 语言/branch**，否则以后换客户端就不知道自己换没换素材。这条原来没有。

### ② 10-22 那条 CascLib 导出路**不可靠**，对方给了证据

`RESULT.notes` 里写明：CascLib 本地索引只认 756 个号里的 **440** 个，其余 316 报 `Local index missing`；两边都产出的 440 个里 **8 个字节不一致**；其中 **4 个不同 fdid（447590 / 447638 / 447806 / 449568）被解成完全相同的字节**——内容寻址的文件不可能这样，是 CascLib 把 encoded ekey 解错了。最终交付走的是 wow.export 自己的 CASC reader（`app-e10` 那份补丁副本）。

**我回查了站内现有图片资产有没有中过这一招**（找"不同文件名、内容哈希完全相同"）：

- `app/img/icons/`：3,491 份里只有 1 组重复（天裔胸甲与长袍两个键同图），而这份 manifest 写明**全部来自暴雪官方 CDN**，不是客户端解包——不是这个坑。
- `app/img/art/maps/` 那 37 张：来源是 `wowforever.wclbox.com/ditu-xiao/…`，也不是客户端解包。
- `app/img/art/dungeons/` 那几组同内容（斯特拉霍姆两门、DIR 三片、血色四片、黑石两塔）：**是同一座本多翼共用一张载入图**，属正常。

→ **现有资产没被 CascLib 污染**。但**以后按号导一律走 wow.export 那条**，任务书里那句"用现成的 `wowfexport get … id`"要改掉——那条命令底层就是 CascLib。

### ③ 对方主动披露的一次联网事故（要记进红线）

未打补丁的 CascLib 在探测阶段**尝试向 `level3.blizzard.com` 发 HTTP GET** 找它本地没有的文件（CascLib 的 `OpenFile` 无视 `CascLib.UseOnlineFallbackForMissingFiles` 也会兜底联网）。全部 Forbidden/BadGateway、没拿到远端字节、那批探测产物已删；打补丁后重跑的日志里零 HTTP 行（`logs/crosscheck-casclib.library.log`）。

**这条改的是我们任务书的一个空白**：以前只写"只读、不外传"，**没写"不许联网取字节"**。以后每份导数任务书都要明文加一条：导出过程不得向任何远端请求文件，日志里出现 HTTP 行即整包作废。
