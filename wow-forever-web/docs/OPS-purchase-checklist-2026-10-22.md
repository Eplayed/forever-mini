# 买什么、按什么顺序买、备案注意什么（2026-10-22）

本轮角色：wow-ops ｜站主问："我想部署到域名上，应该怎么买阿里云的服务。网站不涉及交易，只做资料查询。备案要注意什么"
｜附图为阿里云万网 `paoben.top` 下单页（首年 ¥14，勾了"15 元同步开通 AI 建站：下单后再送 1 年 .CN + 备案服务码"，应付 ¥29）

一手来源全部是阿里云帮助中心当日页面（2026-10-22 抓），不是第三方攻略站：
[备案服务器检查（含可备案产品与服务码规则）](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check)、
[填写网站/App 的接入信息](https://help.aliyun.com/document_detail/114326.html)。
成本与流程的上一轮调研见 `docs/OPS-deploy-domain-2026-10-19.md`，这一份只补"今天这一单怎么下"。

## 一、一句话结论

**那个 15 元的 AI 建站先别勾，只花 14 元把域名拿下；能备案的门票去买一台轻量应用服务器。**
理由不是贵，是**接入资源要和你真实部署的地方对上**——我们的站是自己写的 Vite 静态站，
不是用万小智拖出来的建站，拿建站的服务码去备案、实际跑在别处，属于自己给自己埋核查风险。

## 二、今天这一单：怎么点

1. **取消勾选**「15 元同步开通 AI 建站」→ 应付回到 **¥14**。
   官方文档里"建站服务"确实是可备案资源之一，但备案填网站信息时**产品类型要选「智能建站」**，
   而且它假定你的站就是那个建站产品跑的。我们不是。**除非客服明确说"万小智的服务码可以用在自行部署的站上"，否则不要走这条路。**
2. 年限选 **1 年**。别一次买多年：`paoben.top` 这 ¥14 是首年促销，续费按标准价（.top 大致 30–35/年），
   而且下单页自己第 8 条写着——"域名注册后，**可能发生无法备案或在中国大陆境内域名解析请求被运营商拦截**的情形，阿里云不因此承担责任"。
   先一年试，能备案再续。
3. 下单前确认**信息模板状态是「模板实名成功」**。自 2022-02-15 起，注册域名必须关联一个已通过实名认证的模板；
   模板审核官方口径"通常 1 个工作日，部分 3～5 个工作日"。这一步没过去，订单会一直卡在"处理中"。
4. **域名、服务器、备案三件事必须在同一个阿里云账号下。**
   官方文档明文：**个人认证账号不能给他人授权备案服务码**（要授权必须先转企业认证）。
   分两个账号买，服务码给不过去，白花钱。
5. `paoben.top` 这个名字本身合规：不含 `warcraft` / `wow` / `blizzard` / `azeroth` 任何商标词根，
   也不含 `game`（有些管局对前缀带 game 的域名要上传前置审批材料）。
   但**送的那 1 年 .CN 别顺手用**——备案主体、网站名称、域名三者要一致，多一个域名就多一处要解释的地方。

## 三、接着买什么（门票 = 机房，一台解决）

| 买 | 选什么 | 钱 | 为什么必须是它 |
| --- | --- | --- | --- |
| **轻量应用服务器** | **中国内地节点** + **包年包月 ≥ 3 个月** + **必须勾公网带宽** | 新用户首年 38（秒杀）/ 68（不用抢）档，次年回标准价 | 官方可备案清单里就三类够用：ECS（包年包月≥3个月+公网带宽）、**轻量应用服务器（同上）**、云虚拟主机。同一账号下**备案时不用提前搞服务码，系统自动生成** |
| 域名解析 | 加 **A 记录**指服务器公网 IP | 0 | 备案要核验域名指向 |
| HTTPS 证书 | 阿里云免费 DV 单域名 | 0，但 **90 天要自己续** | 别买付费的 |
| OSS / CDN | **这一轮先不买** | — | 见下面第四节，它们不是备案接入资源 |

**不要买**：SLB / 容器服务 ACK / ACS —— 官方文档明写"不属于可备案的云产品，不能直接申请备案服务码"。
**不要单独买服务码** —— 文档原话："**单独购买服务码无法完成备案操作**"，必须绑实例。

## 四、OSS + CDN 这条路为什么不能当备案入口

官方对这两个产品的规则是同一句式：**"域名需在工信部存在 ICP 备案号"**，
并且"ICP 备案信息**不强制要求接入阿里云**"。翻译过来：
**OSS/CDN 不给你发备案门票，它只要求你已经有备案号。** 所以顺序只能是
"先有一台可备案资源 → 拿到备案号 → 再谈要不要挂 CDN 加速"。

还有一条警告要记住：**"如果源站部署在阿里云，用于回源访问的域名需在阿里云完成『新增接入』，否则您的域名将会被阻断访问。"**
也就是说以后接 CDN，回源那个域名也要在阿里云做接入，不能只备案主域就完事。

## 五、时间顺序（错一步就多等一轮）

```
① 账号实名（刷脸，当天）
② 建信息模板 → 等状态变「模板实名成功」（1，部分 3–5 个工作日）
③ 买域名 paoben.top（¥14，关联那个模板）
④ 等实名信息同步到工信部 —— 下单页第 3 条官方原文：
   「备案域名核验数据上报需要 3 个以上工作日，请在域名实名认证成功至少 3 个工作日后再提交网站备案」
⑤ 买轻量应用服务器（内地节点 / 包年包月 ≥3 个月 / 带公网带宽）
⑥ 阿里云 ICP 代备案系统提交 → 接入商初审 1–2 工作日
⑦ 工信部 12381 短信 —— 24 小时内必须点，漏了要重来
⑧ 管局审核 1–20 个工作日（和小程序备案是两次提交，同源同系统，不互相顶替）
⑨ 拿到备案号：页脚中央挂上并链到 beian.miit.gov.cn
⑩ 开通之日起 30 日内做公安备案（beian.mps.gov.cn），下号后再 30 日内挂公安备案号与图标
```

期间**境外那份（现在挂的 GitHub Pages）可以继续跑**，不冲突，也不影响后面备案——
备案看的是"境内接入的域名有没有号"，不是"这个站在不在网上"。

## 六、备案表单上要注意的（个人主体 + 只做资料查询）

1. **主体类型选个人，"是否经营性"只能选非经营性。** 个人拿不到 ICP 经营许可证
   （要求依法设立的公司 + 注册资本 ≥100 万 + 3 人社保）。你说不涉及交易，这一点正好站得住。
2. **网站名称不要带"游戏""社区""论坛"，也不要把站点定性成网络游戏类。**
   游戏是**前置审批**类目，而个人备案拿不到前置审批文件——这一条比广告更容易把备案卡死。
   口径统一写成"资料查询 / 信息检索类个人站点"，服务内容选信息查询那一类。
3. **域名实名的人必须和备案主体是同一个人**，中途换人要走过户，白等一轮审核。
4. **网站名称、实际内容、备案填写三者要一致。** 管局核验会打开站点看，
   所以正式域名解析到境内那台机器时，页面上别出现与备案口径不符的东西
   （交易、价格、招募、评论区——我们本来就没有，零 UGC 是这条的天然优势）。
5. **各省对"一个个人主体能备几个网站"上限不同**（河南 / 湖南 / 湖北 / 安徽一次只能 1 个，
   福建 / 江西 3，广西 4，陕西 5……）。**这一条按你身份证归属地的管局当天口径为准**，提交前在备案系统里会提示。
6. **广告在备案号下来之前别开。** 不是不能开，是那时候风险最高：接入商对个人站放广告的态度
   比法条更现实，最可能的结果是整改或注销备案号，不是罚款。等备案号下来、站点名称与口径定死了再单独决定。
7. 材料一次备齐：大陆身份证正反面（临时证部分省不收）、本人手机号 + 应急号、通讯地址、邮箱、
   接入商 App 上扫码做**人脸核验**（主流厂商已取消邮寄幕布）、系统生成的核验单与承诺书、域名证书。

## 七、成本落到多少钱（只算第一年，按活动价）

| 项 | 钱 |
| --- | --- |
| `paoben.top` 首年 | 14 元 |
| 轻量应用服务器首年 | 38–68 元（新用户） |
| ICP 备案 | 0 |
| 免费 DV 证书 | 0 |
| **合计** | **约 52–82 元把站挂进境内** |
| 第二年往后 | 域名 30–35 + 轻量回标准价（月付 45 档 ≈ 540/年）≈ **570–580 元/年** |

**这条年费曲线要在下单前想清楚**：首年 60 元很便宜，稳定运行是 570+/年。
一个资料站第一年值不值这个钱，取决于备案之后有没有真实流量——
所以我的建议还是那一条：**先 14 元买域名 + 38~68 元买轻量把备案排上，CDN/OSS 等有流量再说。**

## 八、这次没查到、要问客服的一句话

> "阿里云 AI 建站（万小智）随单赠送的备案服务码，能不能用在**不是**由该建站产品生成、
> 而是我自己开发并部署在别的服务器上的网站？"

问的时候把"自己开发、部署在别的服务器"说清楚，别只问"送的服务码怎么用"——
官方文档只写了"建站产品可备案 + 备案时产品类型选智能建站"，
**没写"服务码可以脱离建站产品用在自行部署的站上"**，这条不能替他推断。

**时间**：下单页第 3 条要求"实名认证成功至少 3 个工作日后再提交网站备案"。以 10-22（周四）为起点，
满 3 个工作日是 10-27（周二），**提交按 10-28 起算稳妥**，早交通常被初审退回。

**网站名称这一格**（个人主体、非经营性）：本文件第五节写过红线——不带"游戏 / 社区 / 论坛"，
不把站点定性成网络游戏类（游戏内容属前置审批，个人拿不到）。中性候选三个，任选其一：

1. **跑本资料站** —— 与域名同源，最短，最好解释
2. **跑本查询笔记** —— 带"笔记"，符合个人非经营性的常见写法
3. **跑本信息整理** —— 强调"整理已有信息"，不暗示原创内容或经营

**但别为了过审编一套跟内容不符的说法**：管局若追问，如实答"某款游戏的中文资料查询站，
不含下载、不含账号交易、不做运营与收费"——这三条本来就是我们的红线，站得住。
要避开的是"攻略""教学""代练""装备交易"这类会被认定经营性或需前置审批的字眼。
