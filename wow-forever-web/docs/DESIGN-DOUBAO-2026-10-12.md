# 按豆包设计稿还原 · 规格与口径 · 2026-10-12

稿子位置：`/Users/zhangyajun/Doubao/chats/2026-10-12/new-chat/wow-infinite-site/`（用户从豆包导出的整包）。
本文件是**还原时的唯一依据**：哪些照抄、哪些必须改、哪些不做。规格由 8 页 HTML 逐块实测抽出。

## 一、稿子是什么形态（决定"还原"怎么做）

- 8 页：`index / classes / talents / changes / items / dungeons / raids / search`，固定画布 **1440×N**，
  **100% 内联 style、没有 CSS 文件、没有 JS、没有任何交互态**（`:hover` 零处、`<script>` 零处）。
- 导航 68px 且**绝对定位浮在 banner 上**，所以每页第一块必须是全幅图带；没有图带的页要自己让出 68px。
- 内容宽恒 **1280px**（左右各 80px）；只有 `nav` 用 40px、`footer` 用 80px。
- 卡片**没有 box-shadow**，层级全靠边框色 + 渐变明度；**卡片没有圆角**，全靠 `clip-path` 切角。
- 结论：稿子给的是**视觉语言与逐页版式**，不是可运行前端。还原 = 把这套语言搬进我们的
  令牌层 + 版式件，页面继续由 `src/data/*.json` 驱动，响应式与交互态由我们补（稿子里根本没有）。

**这次换轨推翻了一条昨天的决定**：2026-10-11 把琥珀金从品牌位撤下、换成无限蓝；稿子要求铜金回到品牌位，
所以 `--accent` 现在指向金色，无限蓝留成 `--azure` 只作辅助语义色。分级 L0–L3、品质六色、导航分组色

是故意的"金属断口"，不要改用 `overflow:hidden` 或补伪元素去"修好"它。

## 四、内容口径：稿子里哪些是画上去的字，不能当数据

稿子的 `build/gen_*.py` 里大量字符串是**字面量**，不在它的 `data/*.json` 里。逐页核过，下列槽位
还原时必须换成我们的数据或空态：

| 稿子写的 | 事实 | 我们怎么做 |
| --- | --- | --- |
| 团本三名：深穴 / 海加尔峰 / 奥妮克希亚的巢穴 | 前两个是**拟译**，官方没发过中文定名；`dungeons.json` 三条 `nameCn` 全是 null | 卡面写英文原名 + "中文定名未公布"，不采纳拟译 |
| 首批团本 **12 月 10 日**开放 | 官方英文回顾给的是 **12 月 9 日**（`timeline.json`，L1） | 日期一律读 `timeline.json` |
| 三张团本卡的描述句（"深入地下深穴，挑战未知首领"等） | 全是字面量，`data/` 下没有 raids.json | 换成数据事实：人数两说、名单未收录、有没有排队条目 |
| "开放时提醒我" | 稿子里就是个 `div`，点了没反应；且属于需要账号/推送的能力 | 红线不做，换成跳时间表页的链接 |
| 5353 新增物品 / 6102 改动物品 / 9 史诗 / 2 传说 | 写死，稿子数据里 grep 不到 | 读数全部由 `build-data.js` 现算 |
| 天赋页"等级 60 / 已分配 23 / 51 / 三系 23·0·0" | 假加点表 + 写死总点数（51 是随手定的） | 继续用我们的计算器与 `rules.totalPoints` |
| "6 个地下城开放中" | 稿子数据里没有"开放状态"字段 | 没有可信说法就不写 |
| 页脚"魔兽世界 World of Warcraft … 为暴雪娱乐商标"、导航副行"WOW FOREVER DB" | 与我们的商标词红线冲突 | 页脚继续用固定那句"非官方粉丝资料站，与暴雪娱乐及网易无关" |
| 全稿没有任何来源展示位、没有 L0–L3 | 我们的硬规矩是每条数据带 provenance + 分级 | 来源轨与分级徽标一件不撤，压在新版式之上 |

## 五、素材：稿子的图一张都没搬

- 稿子里 175 处 `<img>` 全部热链 `https://aka.doubaocdn.com/s/…`，违反"素材一律本地留存、禁止热链"。
- 反查 `build/urlmap.json` 后分两类：
  - **123 张客户端图标与副本载入图**（`tubiao/` 93 张、`dungeons/` 29 张）——逐文件名比过，
    我们 `src/img/icons/`（2014 个）与 `src/img/art/dungeons/`（36 张）**全都有，而且我们的更细**：
    稿子靠复用凑 35 张卡（`art-diremaul` 一张用三次），我们是一副本一张。→ 用我们自己的。
  - **3 张 `changjing/` 全幅底图**——`asset-manifest.json` 写着 `production_method: image_generate`、
    带完整 prompt 与"无文字与标识"验收条件，**但页面实际用的三张 URL 不在 manifest 登记的那一批里**
    （manifest 是 2730×1536 那组，页面用 1920 那组），等于这三张没有可登记的来源记录。
    → 一张都不搬。按 brief 第八节同规格自己生成三张，落 `src/img/gen/`：
    `hero-ruins.webp`（首页 hero）｜`banner-cloudsea.webp`（内页 banner）｜`cavern-hall.webp`（地下城/团本氛围）。
    出图右下角带"Qoder AI 生成"角标，入库时统一裁掉底部 128–130px，`manifest.json` 记提示词与处理步骤。
    这三张并进 `art.json` 的 `gen` 键，由 `build-data.js` 检查文件存在；页面上凡用到就标
    "示意图 · 本站自生成，非游戏原画"，不冒充任何一座本的真实画面。
