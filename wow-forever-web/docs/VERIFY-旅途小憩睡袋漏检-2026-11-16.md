# 旅途小憩 0.7.1 睡袋检测回归

站主在无限服使用睡袋后报告没有出现人物海报。磁盘上的 0.7.0 已保存 `auto=true` 和小地图按钮角度。当前游戏内状态没有读到，Computer Use 两次启动均报 `registered runtime ownership is missing`。磁盘设置不能证明当前会话内存值。

## 复现与修复

模拟从移动到静止，客户端在最后一次移动后 0.15 秒送达休息状态变化，未提供可读的睡袋引导，有同一地图及子区域的铺袋事件。0.7.0 的 0.6 秒静止条件拦下首帧，下一次轮询已没有新的休息状态变化。区域切换冷却内也存在相同漏检。

0.7.1 在 5 秒内保留一次新观察到的休息变化，让轮询在静止和区域条件满足后继续判断。保留同区铺袋、户外、非主城、无帐篷等前提。推断成功时从休息变化时刻计时。退出休息、移动清理、区域基线刷新时清除此记录。`/campportrait status` 增加检测是否运行、海报是否被手动隐藏、睡袋是否已结算收起的字段。

## 验证

真实事件入口的 Lua 5.1 模拟中，0.7.0 在快速躺下和区域条件未满时均未显示。0.7.1 用相同输入会显示。原先有明确引导、首层增益、正常铺袋检测也通过。旅馆、主城、无铺袋记录、已休息后初始化、中途起身、关闭自动展示均未误弹。四个 Lua 文件通过编译，ZIP 与本机无限服安装逐字节一致。

新版已安装到本机，需要结束现有休息后重载，再重新铺袋躺下。安装包位于 `D:/project/camp-portrait/dist/CampPortrait-0.7.1.zip`。本轮实机根因与重载后复测待确认。
