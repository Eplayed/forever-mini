## 二、真正要补的数据（5 项，按建议顺序）

### ① 物品库（最大缺口）—— **一期名录已采（2026-10-13，wow-data）**
- **已完成**：全量名录 21,077 件落库。抓取走 `/wupin/liebiao` SSR 名称索引（106 页 × 200 件，`tools/scrape-wclbox-items.py`），`tools/merge-items.py` 合并出 **`src/data/items.json`（5.1MB）**：id / 名称 / 品质 / 类型（slot+材质）/ 物品等级 / 需要等级 / 状态 / 图标文件名（iconKey 去扩展名，与掉落 IconCell 同套路）。状态分布：新增 5,346 / 改动 6,102 / 不变 7,678 / 无限没有 1,944 / **重建 7**（上游标 ic-rebuilt，其首页统计并进"新增"，我们单独留值）。cat 一期四档：护甲 9,150 / 其它 6,312 / 任务 3,394 / 武器 2,221（推导规则见 classify）。build-data 已收物品段（数量守恒 / id 唯一 / status 白名单 / 禁词自动扫描全绿）。
- **红线执行**：名称索引行没有描述文案，天然合规；单源 L0（wclbox 转述客户端，同 datamine_cn 口径）带 url+抓取日期；21k 条译名逐字回查不现实，采用抽检口径（audit-translations 抽物品名，见后续 VERIFY）。
- **二批（待做）**：详情 tooltip 增量抓（属性效果行数值化，先装备类武器 995+护甲按等级段分批）；副本掉落与稀有掉落反链物品页；物品进全站搜索索引（21k 全进会把 search.json 撑大，一期物品库页自带搜索，不进全站索引）。
- **原型（2026-10-13，wow-ui）**：`docs/prototypes/items-page-prototype.html` 单文件可交互原型（57KB，零外部请求）——334 件真实抽样内嵌，状态/分类/材质/部位/等级区间/搜索/排序/分页全可用，桌面表格 + 375px 卡片化；图标走真实本地图标库相对路径、缺图如实渲染品质色占位块（本机相对路径，发布版走同套 IconCell 逻辑）。实测：50 行/页、筛选搜索通过（搜"护腕"8 条）、375px scrollWidth 375 无溢出、无脚本报错（资源 404 是缺图占位的预期路径）。截图 `docs/screenshots/check-2026-10-13/proto-items-*.png`（桌面/筛选态/移动端 ×2）。**图标实数**：21,077 件 → 去重 2,988 个 iconKey，本地库已覆盖 1,597，缺 1,391（无限新增占大头，验证 10-08"新物品图标 CDN 没有"）。物品无背景图概念，原画体系（img/art）不涉及。
- **修卡口一处**：禁词正则 `null` 加 `\b` 词边界（icon 文件名 spell_nature_nullward 等 4 件误伤，词表本意是防渲染事故字面量）。

### ② 法术书补全（86 → 420）
- **是什么**：abilities.json 从 86 条核心技能扩到 420 条全量 + 257 条改动对照。
- **可采性**：同物品——数值可采；法术功能性描述是否可采需 wow-data 按"描述文案"红线判一条边界（建议：数值与机制条目化，整段文案不抄）。
- **接入路径**：扩 `wclbox-spells` 抓取 → merge-abilities 扩量 → skills 页补筛选/搜索；**顺带解锁缺口 ⑤**（治疗法术各级蓝耗）。

### ③ 成就清单 + 本地进度勾选
- **是什么**：区域探索成就 + 传承挑战成就清单；勾选进度是纯 localStorage 本地功能，**不算 UGC**，可做。
- **接入路径**：`wclbox-achievements` 快照 → `achievements.json` → 新成就页（分区域分组 + 勾选框 + 进度条）。小体量，可早做。

### ④ 猎人宠物
- **是什么**：新增宠物种族（狐狸）+ 9 类新宠物技能，小体量事实数据。
- **接入路径**：小快照 → 并入 abilities 或单列 `hunter-pets.json` → 挂 classes 页猎人段或独立小页。

### ⑤ 降级施法小工具
- **是什么**：治疗法术每一级的蓝耗/效果对照（哪级最省蓝）。
- **依赖**：② 的法术数据补全后才能算。做成独立计算小页（与天赋计算器同级的工具）。

### 另：团队增益补全
- systems.json 已有 4 组，对齐 wclbox 的"12 增益小队变全团"清单补全，并消掉 10 条待核实。并入 systems 页即可，不算独立板块。
