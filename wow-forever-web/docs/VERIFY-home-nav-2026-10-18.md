## 一、三个毛病的成因，与"为什么门禁一条都没红"

| 症状 | 真因 | 为什么没被抓到 |
| --- | --- | --- |
| 点了没反应 | 首页 12 处链接走 `legacyUrl()`，产出 `/talent.html` 这类**路径式**地址；这些页已迁哈希路由，`:8821` 是 `vite preview`，未知路径回 200 + `index.html` | 不是 404、不报 JS 错、地址栏确实变了；旧断言只查"有没有 href"，不查 href 长什么样 |

## 二、改了什么

**链接**：`app/src/lib/nav.js` 新增 `hrefOf(file)`，与 `linkFor()` 共用同一张 `MIGRATED` 表——
已迁页返回 `#/route?q=…`，未迁页才回落 `legacyUrl()`；旧的 `#锚点` 转成 `?to=` 查询参数。
换掉的调用点：`HomePage` 12 处、`ClassesPage` 的 `racesHref`/`bookHref`、`TalentPreview` 的
`const legacy = hrefOf`。`UpdatesPage` 认 `?to=` 并在下一帧滚到那一节。

**两条九格轨**：`.hrail` 与 `.cls9` 都从 `auto-fit` 改成**写死 9 / 5 / 3 列**（`minmax(0,1fr)`）。
不用 `auto-fit` 的实测理由：1000px 时它算出 8 列，第 9 格单独掉到第二行最左边、
右侧空 821px，看着像漏了一格。职业条每格补一行天赋节点数。板块轨与职业条之间留 24px，
不再贴成一条。

**导航带**：全部只写进 **app 独有的 `src/css/board.css`**，一行没碰 `app.css`
（`.ngrp`/`.hrail` 两栈共用类名，改共享文件会动到已冻结的旧站）。渐变底、组名小标签、
组底 2px 指示条（悬停/命中时从左边长满并亮本组色）、当前项金字 + 金色下划线、
`:focus-visible` 描边、`prefers-reduced-motion` 全关。窄屏（<900px）撤掉下划线、
保留 44px 点击高度。

踩到一条：`nav.main .in` 从 `align-items:flex-end` 改成 `stretch` 后，"首页"那格没有组名、
高度只有别人的一半，被垂直居中顶得比其余入口高 16px（顶边 59 vs 75）。补
`.ngrp.solo { justify-content:flex-end }`。

又踩一条：`app.css:1183` 本来就给当前项一条 `border-bottom:2px solid var(--accent)`，
新的金色 `::after` 叠上去，桌面成了一条 4px 的脏线。改成桌面把底边设透明、只认 `::after`，
窄屏（<900px，那里 `::after` 是 `display:none`）反过来把选中态交还给底边。

## 三、新增断言（`tools/site-check.py` 的 `[16] app` 节，共 6 条）

1. `#main a[href]` 里不许出现既不以 `#` 开头、也不是 http 的地址。
2. 1440 下整页 `scrollWidth - innerWidth === 0`，且 `.hrail/.cls9/.modgrid/.chipsrow` 各自不溢出。
3. `.cls9` 底边到 `.hrail` 顶边 ≥ 12px。
4. 导航一条带：组名同一行、入口同一行、带高 44–96px、当前项文本是"首页"、
   它的 `::after` transform 不是 `scaleX(0)`（下划线画没画只能量出来），
   并且它的 `border-bottom-color` 必须是透明——`app.css:1183` 那条 2px 实底边
   和金色下划线叠在一起会变成一条 4px 的脏线，桌面只许留下划线。
5. 375 下整页不横滚、`.cls9` 与 `.hrail` 都是三行、没有格子被切到视口外。
6. 375 的选中项 `border-bottom-color` 必须**不**透明——窄屏把 `::after` 关成
   `display:none`，选中态只能落回那条底边；两边都关掉就没人告诉你"当前在哪一页"。
   第 4 条和第 6 条是一对，只钉一边，另一边就没人管。

反向验过第 4 条：改回 `align-items:stretch` 之前 `line` 恒等于 2，那条断言当时就是红的，
不是写完就绿的摆设。
第 6 条的判据是探针量出来的两个状态：只给桌面加 `border-bottom-color:transparent` 时，
375 的 `bb` 是 `rgba(0, 0, 0, 0)`（选中态没了）；在 <900px 里补回 `var(--gold)` 后变成
`rgb(200, 163, 92)`。这两次都用 `/tmp/navfix.py` 实跑过，不是推断。

# 追加：导航带又换了一版（同日，站主看完 3.50 那版说"换个设计风格"）

上面第一～五节说的是 3.50 那版（渐变带 + 组底指示条 + 金色下划线），已经提交推送。
站主看过之后要求换风格，给了三个方向（A 文档站风一行细字 + 悬停下拉 / B 胶囊分组 / C 图标主项 + 大下拉面板），
**他选 B**。规格、签名动作与三处实测数写在 `docs/UI.md` 3.51，这里只记过程与证据。

## 六、这一版踩到的三件事

1. **八颗丸塞不进 1148 的内宽，1440 下折成两排。** 第一版 `margin:0 4px` + 入口 `padding:0 10px`
   算出来总宽 1158 > 1148，带高从 50 涨到 94。收成 `margin:0 3px` + `padding:0 9px` 后是 1122，留 26px。
   **这条是量出来的，不是看图看出来的**——`/tmp/pillprobe.py` 直接打印 `rows` 与 `lastRight`。
2. **丸没给上下内边距，填充药丸顶到丸的内边，贴得看不出是两颗。** 1440 实拍里"首页"那颗
   几乎填满整颗丸。补 `padding:3px 4px 3px 12px`，丸比入口高 6px 就分开了。
3. **「新」角标压字。** `app.css` 那套是"绝对定位 + 给链接留 17px 右内边距"，在 30px 高的丸里
   「新」直接盖在"首页"的"页"上（实拍可见）。改成行内小标（`position:static` + `margin-left:5px`），
   丸自己长够宽。

**外加修掉一个老问题**：`app.css` 的组色只写到 `.ngrp.g6`，新站导航第七组「工具」拿的是 `g7`，
**一直没有自己的颜色**，落回默认灰。上一版组色只出现在 2px 短横上看不出来，改成丸描边后立刻露馅。
补令牌 `--nav-7:#8f9bb3` + `.ngrp.g7`（只加在 app 独有的 `board.css`，不动已冻结的旧站）。

## 七、断言跟着换：钉形状，不钉配色

上一版那两条（桌面底边必须透明 / 375 底边必须不透明）随方案一起作废，换成五条：
八颗圆角胶囊（半径 ≥ 半高、1px 实描边、有底色、入口一行、带高 44–96）、当前项是丸内一颗圆角填充
且字色现场解析 `--gc` 比对、上一版三样伪元素确实没在画、**七个分组七个互不相同的颜色**
（少定义任何一组 Set 就少一个——这条把「工具」那个老问题钉住）、375 选中项仍靠填充标出且底边为 0。

当前项字色那一条特意**不把 rgb 抄进断言**：在丸的作用域里插一个 `color:var(--gc)` 的探针读它的
解析值再比。令牌改了断言不跟着改，也不会退化成"只比个非空"。

## 十、站主看过胶囊版又说：不接受胶囊前面有圆点
