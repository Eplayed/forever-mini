# 《魔兽无限》伴随小程序方案（个人主体 / 静态资料 + 开荒工具）

制定日期：2026-10-06。目标上线窗口：2026-11-05（国服与全球同步口径）。

---

## 一、先定三件事，其余都是执行

| 决定 | 结论 | 为什么 |
| --- | --- | --- |
| 产品形态 | 纯静态资料查询 + 本地开荒清单，零用户内容、零角色数据、零收费 | 个人主体唯一能过审的门就在这条线上 |
| 命名 | 自造品牌词，**不出现**"魔兽 / 魔兽世界 / WoW / 暴雪 / 怀旧服" | 商标词可被投诉，后果是清空昵称 + 下架，超 7 天申诉期名字永久拿不回 |
| 时间 | **备案必须本周提交** | 通管局审核 1–20 个工作日，这是整条链上最长的一段，拖到第二周就赶不上 11/5 |

### 坏消息：个人主体不能选"资讯"类目

微信官方《开放的服务类目》里，个人主体可选的一级类目只有：物流、教育、交通、生活服务、餐饮、旅游、**工具**、商业服务、体育。**"资讯 - 信息资讯" 只出现在非个人主体那张表里**（网上流传的"资讯类目无资质要求、个人也能选"是错的，那是对企业成立）。所有带"游戏"字样的条目一律要企业资质，其中"电子娱乐服务"要求营业执照含"互联网游戏服务"。

另外两条官方硬规则要记住：
- 一旦选成游戏类目**不可变更**（常见拒绝情形 2.1.3）
- 类目不符可"限制能力直至下架"（5.7）

### 好消息：`工具 - 信息查询` 正好是我们的形状

该类目资质栏是"/"（不需要任何许可证），适用描述就是"提供信息查询功能"；配套的清单/打卡页语义落在 `工具-备忘录`，其官方说明是"不涉及用户原创内容的传播及公开访问"——这恰好是我们打算做的（本地打卡、不发帖）。2023 年 9 月起新增的小程序备案环节里，"工具（含信息查询）"被明确标注为"**个人备案：可选，符合个人性质**"。个人主体上限 5 个小程序，够用。

变现也不受影响：流量主开通条件是"累计独立访客（UV）500 以上且无违规记录"，**没有主体门槛**，个人可以开。个人主体真正拿不到的是微信认证和手机号快速验证组件（这两个都要求非个人主体），而这两样对纯资料工具都不是必需品。

### 一条必须接受的代价

**零 UGC。** "社交 - 社区/论坛""笔记""问答"这些类目只在非个人主体表里，且需《非经营性互联网信息服务备案核准》并送主管部门（约 7 天）。已有开发者实测被拒理由是"存在个人主体小程序未开放的服务类目……属社交-笔记范畴"。所以：不能有评论区、不能有玩家投稿、不能有攻略论坛。冷启动只能靠**分享卡裂变 + 你在 NGA/B站/抖音发帖导流**，跟你现在做流放助手的打法一致。

## 二、为什么这个时点值得做（也是最大的不确定性）

官方口径：无传统服务器与大区，改按规则集（普通/PvP/RP/专家）匹配；新增露营系统与传承系统；媒体汇总为**永久 60 级**、3 个新区域、1000+ 任务、**9 座新地下城**、10/20 人团本、新种族"天裔"，有游戏时间即可玩、不另收费。国际服 Beta 9/17 已开，**国服 Beta 今天（10/6）开，需 388 元天裔史诗礼包**，官网称 11/5 全球同步上线（个别媒体写 11/4，口径有出入）。

需求侧的证据很硬：WeakAuras、Hekili 这类循环提示插件因底层接口变更被禁，玩家缺战斗统计和循环指导；WCL 类工具在国内社区被压（NGA 相关帖删帖禁言）。需求外溢的方向正是**离线资料查询、掉落表、副本路线、配装与任务进度**——也就是我们打算做的这一类。

反面也要说清：游戏可能延期、国服可能不同步、上线后官方口径可能改（暴雪政策来回变过：2026 年 7 月封禁四个月后放宽接口限制）。所以里程碑按"内容可回退"来排，不按"赌它准时"来排。

## 三、明确不做的四件事（这是护栏，不是偷懒）

1. **不做角色查询。** Battle.net 官方 API 的区域列表里没有中国区，国服角色数据无官方接口可查。唯一先例是 Raider.IO 在 2025-07-16 接入国服"英雄榜数据"——那是它自己的通道，我们复制不了。硬做只能靠爬英雄榜页面，覆盖面窄、口径不稳。
2. **不读玩家账号、不读本地战斗日志。** 国服 2026-08-25 公告把 BiaoGe 免费版这类工具定性为**违法工具**（含违规代码、泄露隐私），违者封号且官方不担责。"泄露隐私"在这款游戏上是刑事级红线。
3. **不做 DPS/成绩排行/评分。** 官方有"禁止评分插件"的专门公告（2026-08-26），这类功能是最容易被判"违规辅助"的。
4. **不做付费会员、不在游戏相关内容里塞广告。** 国服 2026-09-24《付费插件及违规商业化专项治理公告》要求插件必须免费、**不得含广告**、禁止牟利，并保留"民事索赔、行政举报及刑事控告"。虽然条文针对游戏内 AddOn，但运营方态度会外溢到伴随工具。流量主广告只在详情页延迟出现，沿用 `src/config/ads.js` 的默认关闭策略。

另外：不要拿这个产品去蹭官方 H5 活动页的流量入口，也不要引导玩家用任何游戏内注入类工具。

## 四、界面清单（MVP，6 页）

| 页面 | 内容 | 数据来源与口径 |
| --- | --- | --- |
| 首页 | 版本进度、本周新增内容、四个工具的入口、复访摘要 | 自建摘要 JSON，一个文件搞定，避免小程序多源请求 |
| 地下城手册 | 9 座新地下城 → BOSS 列表 → 技能与掉落 | 人工整理 + Beta 实测校对，逐条标注核对日期 |
| 配装速查 | 按职业/部位列 BIS 与过渡装，给出获取途径 | 60 级配装是社区成熟知识，自己重排成结构化表 |
| 任务与路线 | 升级路线、声望顺序、露营系统节点 | 官方 forever 页 + 人工梳理，只写"去哪、做什么、拿什么" |
| 开荒清单 | 可勾选进度，只存本地 | 完全复用现有 `pages/checklist` 的结构 |
| 名词速查 | 中英/新旧术语对照 | 完全复用现有 `pages/dictionary` 的做法 |

复用你现有的东西（省下的就是 30 天里最值钱的时间）：OSS 读取与缓存层、分包结构（`pages-sub`）、分享卡生成、主包 2048 KiB 的预算纪律、"前台不暴露内部术语"的文案规范、图标转存到自有 OSS 的流程。

**不复用的东西**：不要把魔兽数据塞进现在这个 appid（`wxe78a1b5f1a1b7472`）。两款游戏的人群和审核历史不同，一旦魔兽内容出问题会连坐流放助手。参照你现在 POE1/POE2 的隔离方式再往下推一层：**新开一个小程序账号 + OSS 新命名空间 `wow/{env}/`**，manifest、缓存 key、上传脚本全部独立，并且**不要调用 POE2 的 `auto_browser/upload_to_oss.js`**（照 POE1 那样单开一个上传入口）。

## 五、数据怎么来（不靠爬别人站）

`工具 - 信息查询` 需要的只是"有可查询的内容"，所以内容生产走你已经在 POE1 开荒 BD 上用熟的那条路：**人工整理成结构化源 → 覆盖率门槛卡发布 → 转 OSS → 小程序只读**。具体：

- 地下城/BOSS/掉落：以官方 forever 页与 Beta 实测为源，人工录入 JSON，每条带 `verifiedAt` 字段。
- 装备与配装：60 级装备属性属于公开常识级数据，自己重排成表，不逐字搬任何第三方站的成品页面。
- 图标：**不能直链 Wowhead 或任何外部 CDN**（小程序 request/downloadFile 域名必须 HTTPS + ICP 备案），必须转存到自己备案的 OSS。同时清楚一层风险：游戏美术素材有著作权，图标量级小、实用性强，但自绘或统一尺寸重绘是更稳的做法，至少要预留"收到投诉就整体替换素材"的回退方案。
- 发布链加两个覆盖率门槛（照 `npm run poe1:coverage` 的做法）：BOSS 与掉落条目 100%、装备名 95%。**查不到权威中文名的就保留英文，禁止逐词硬造**——这条你在 POE1 上已经吃过教训。

## 六、30 天里程碑

**W1（10/6–10/12）｜把最长的路先跑起来**
定名（自造词，先查商标重名）→ 注册小程序 → **提交备案**（这是本周唯一硬任务）→ 建 OSS 命名空间与空 manifest → 类目选 `工具-信息查询`。

**W2（10/13–10/19）｜内容**
Beta 里把 9 座地下城过一遍并录结构化源；配装表成型；路线成型。产出：`wow/dev/` 下能读出非空 JSON，且带更新时间。

**W3（10/20–10/26）｜界面**
六页全部接通数据，分享卡接好，广告位默认关闭。验收：`npm run build:mp-weixin` 通过 + 主包体积在预算内 + 真机尺寸看过 + 至少一张页面截图（界面改动要有渲染证据，构建通过不算完成）。

**W4（10/27–11/2）｜送审**
提审，预留一次被拒的返工时间（重点自查：简介里不能堆搜索热词、不能出现商标词、不能有任何 UGC 入口、不能有付费入口）。

**11/5 上线日**：切 release 数据；内容以"上线当天能改"为前提组织，不要一次性把 9 座本写成不可编辑的长文。

如果备案到 W3 还没下来，退路优先级：①**H5 承载全部资料、小程序只做入口跳转**（不受小程序类目限制，但同样受侵权规则约束）；②注册**个体工商户**——注意它并不能解锁 UGC 和名额，只有确定要收费或买量时才值得（见第七节）；③并入企业主体账号做第二入口。

## 七、主体：个人 vs 个体工商户（2026-10-06 复核，结论：先不办）

| 项目 | 个人主体 | 个体工商户 | 差值 |
| --- | --- | --- | --- |
| 工具-信息查询 类目 | 可用，无资质 | 完全相同 | **无** |
| 社交-社区/论坛/笔记/问答（UGC） | 不可 | **仍不可**（需 ICP 类前置审批，个体户申请不了；ICP 经营许可证主体必须是公司） | **无** |
| 可注册/备案的小程序数量 | 5 个 | 官方原文"企业、政府、媒体、其他组织 50 个；**个体户和个人类型主体 5 个**" | **无** |
| 名称侵权风险、审核速度 | 相同 | 相同（侵权处置不看主体类型） | **无** |
| 微信认证 | 不支持 | 支持，**300 元/年**，审核 1–5 工作日 | 有 |
| 手机号快速验证组件 | 不支持 | 支持（且需已完成认证） | 有 |
| 微信支付商户号 | 不支持 | 可开，费率 0.6%，不强制对公账户 | 有 |
| 小程序虚拟支付（内购/会员） | 不支持 | 支持（iOS 已放开，需微信 8.0.68+） | 有 |
| ADQ/腾讯广告投放 | 不支持 | 接受个体户执照 | 有 |

**办与不办的成本**：注册无登记费，线上 1–3 个工作日出照，卡点是经营场所证明（2025-07-15 施行的市场监管总局令第 103 号规定**集群/共享地址不得作为住所**，"1000–2000 元/年托管地址"那套老办法不成立了；"仅通过网络经营"可向住所所在地申请绕开，住宅则需有利害关系业主一致同意）。后续义务：每年 1/1–6/30 年报（逾期列入经营异常并可罚 100–1000 元）、按季报增值税与经营所得个税、月销售额 4 万以下可不建账。税负量级：增值税起征点月 10 万/季 30 万延续到 2027-12-31，流量主月入几百到几千的话增值税为 0、附加为 0、经营所得个税核定口径约 180 元/年。注销走简易注销免交清税证明，推送 10 日无异议即办。

**判断线**：
- 打算在这款产品上**收钱**（会员/内购/付费查询）或**花钱买量** → 值得办，但必须**在注册新小程序时就以个体工商户身份注册**，别事后变更。
- 只吃流量主（UV 满 500 即可开，无主体门槛）→ 个人主体直接办，别为一年 300 元认证加记账报税提前上。

**实操坑**：小程序主体名必须与执照全名一字不差，含"(个体工商户)"后缀，否则驳回。

**绝对不要拿现有流放助手做主体实验**：个人→个体工商户支持（反向"变更为个人类型"官方明确不允许），审核费 300 元，验证方式若选公证书需**双方共同到公证处签署**且个人主体变更不可委托代理；最致命的是备案 FAQ 明确"主体变更须先注销原备案、新主体重新备案"，**重审期间小程序不可访问**（第三方口径全程 7–15 工作日）。为了一个不解锁类目的认证去停一周线上服务，不划算。

## 八、还没被证实的三件事（别当成已知）

1. 「萨格拉斯」小程序的全名、appid、主体、类目——**公开渠道零记录**，所以它的做法目前是不可知的。想看清只需要在微信里打开它、点右上角「…」看资料页，那里腾讯会直接展示名称、账号主体、类目、版本号，这三个字段基本就能反推它走的哪条合规路。（我没做任何反编译，也不建议。）
2. 网易/暴雪是否真会对一个个人主体的纯资料工具发商标投诉——**无可核验个案**，但 2025–2026 年暴雪密集起诉第三方工具方，态度明确，所以按"必被投诉"来设防。
3. 流量主与 iOS 虚拟支付的最新门槛数字——官方页面 JS 渲染抓不到原文，只取到第三方口径。真要开变现前，以你小程序后台的实时提示为准。
