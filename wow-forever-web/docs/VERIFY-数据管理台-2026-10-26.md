## 目标和边界

资料站继续使用 `127.0.0.1:8821`；站主本机的数据管理台使用 `127.0.0.1:8830`。二者是独立进程。管理台留在 `tools/admin/`，不会被 `app-assets.py` 复制到玩家站发布包，也不接小程序、OSS 或 GitHub Pages。

数据真相仍是 `app/data/`；`app/data/upstream/` 是来源快照；`tools/admin/review/` 是本机待审区，已由 `.gitignore` 排除。页面不直接改一条成品 JSON，也不允许输入命令、文件路径或任意 URL。现有已核刷新场景可从页面启动，但执行后不自动提交、推送、部署或上传 OSS。新专题来源只标为“候选”，不会因为对方网页有数字而直接建库。

## 页面和操作流

1. **板块与来源**：16 个板块现读成品数量、来源、抓取或生成日期、客户端版本、上游快照是否存在；超过 14 天的日期作提示。全域任务、猎人宠物、PvP 军衔标为候选，页面没有伪造的刷新按钮。
2. **条目检索**：按当前成品的 ID 或名称搜索，每页 20 条，打开只读原始字段用于溯源核对。纯数字按 ID 精确匹配。不同板块展示当前主集合；世界页现查区域、副本任务现查任务行。复杂子集合和字段级编辑暂不开放。
3. **缺口提示**：名录缺物品详情、稀有缺坐标、副本无首领、宏和插件条目数从当下成品现算，不抄旧报告数字。原有 32 份顶层基底、58 份上游快照表与 38 座副本字段台账保留。
4. **物品拉取待审**：调用[新手盒子公开物品 API](https://wowforever.wclbox.com/api/open/v1/docs)，每页 100，约 4 次/秒，必须逐页完整且 ID 唯一、有序才原子替换本机 `tools/admin/review/items-api-latest.json`。只保留事实字段和图标文件名，不取说明文案、不热链图片。结果按 ID 比新增/移除，按名称、状态、品质、装等、需求等级比同 ID 变动。`null` 与 `0` 的“无需求等级”视作同一事实。待审结果重启管理台后仍可读，成品数据完全不变。
5. **已登记刷新链**：世界、改动、副本、专业、传承、天赋、配装走 `tools/refresh.sh` 的白名单分支，即抓取→合并→现有门禁。执行前检查 `app/data`、`app/img` 是否有未提交改动，避免覆盖其他会话工作；一个时刻只允许一个拉取、刷新或门禁任务。执行日志和改动文件回到页面。失败可能留下半成品，因此必须人工审阅，不能发布。
6. **尚无一键链**：物品名录、物品详情、法术、副本任务、成就和人工指南保留“待建立流程”。物品目前只拉到待审区；插件属性优先级仍按仓库根规则，不会被社区 API 整表覆盖。

## 数据源口径与后续扩展

每个板块的成品文件、快照文件、来源链接、动作白名单维护在 `tools/admin/catalog.py`。页面只展示该登记，数字与日期现读文件。来源分为：国服官方中文、GI/XR 插件、社区客户端解包转述、双源天赋、人工核作者原帖；本轮没有新增来源授权，也没有把候选专题升成 L0。数据采编下一步应先处理已拉出的 125 个物品新增 ID 和 10 个同 ID 字段变动，逐条核对并设计 `items` 的抓取→合并→门禁链；详情、法术、副本任务、成就再各建安全的刷新入口。任务全域库先补 quest ID 方案，宠物与 PvP 先做字段可信度样本，不直接批量导入。

建议以后增加统一的来源适配器接口（探测版本→拉取临时快照→字段差集→数据采编批准→合并→门禁），并把天赋、法术、详情、专业、副本任务、成就纳入逐板块过期表。当前管理台对这些未覆盖板块只显示成品/快照日期，不假称已受构建过期闸保护。

## 日常使用与资源开销

每天先看板块日期与缺口，只有来源版本变化或准备写内容时才拉取待审；每周由数据采编审差集、记录“采用/不采用及理由”，开发在工作树干净时跑对应刷新链，再验成品和页面。发布仍沿原有独立流程。管理台使用本机 Python 标准库、现有脚本和现有数据文件，**没有新增常驻云服务费用**；物品全量待审这次耗时约 84 秒、生成 3.4 MB 本机快照，按公开 API 每秒最多 5 次的约束将速率压到约 4 次。实际人工采编时间取决于差集数量，本轮 125+10 不能按按钮一次完成入库。

## 启动与验收命令

```bash
cd wow-forever-web
python3 tools/admin/server.py
# 浏览 http://127.0.0.1:8830/
python3 -m unittest discover -s tools/admin -v
```

当前管理台已在这台机器的 8830 启动。8821 的玩家资料站进程未改。管理台进程结束后按上面的命令重启即可；待审快照仍在本机 `tools/admin/review/`。

**没验到的**：共享工作树不干净，故没有实跑任何会改成品的完整刷新链，也没有发布网页、小程序或 OSS；物品新增 125 件与变动 10 件仍是待审差集，不代表已核入库。管理台只在本机验证，未设计远程登录与多人权限。
