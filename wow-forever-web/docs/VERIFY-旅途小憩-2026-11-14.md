## 0.3.0 动作和位置

站主确认手动海报已在国服显示，要求人物轮播跳舞、攻击和跑步，海报默认靠屏幕左侧居中并可自由拖动。

在海报的 PlayerModel 上播放三类动画，攻击段会重播短动作。底部动作按钮可以提前切换，模型缺少某个动作时会跳过。按住标题拖动，松开后保存位置。窗口尺寸变化时约束海报留在可见区域。`/campportrait reset` 恢复左侧默认位置。

Lua 5.1 模拟验证通过自动顺序、攻击重播、手动切换、跳过不支持的动作、关闭时停止轮播、默认锚点、拖动保存、重开恢复、尺寸变化和复位。安装文件已对哈希，归档完整性检查通过。提交 `45d31f5` 已推到 main，见 [0.3.0 试用包](https://github.com/Eplayed/camp-portrait/releases/tag/v0.3.0)。玩家可用 `/reload` 后手动预览，实机动作构图和拖动手感待复测。

动画依据见 [模型 API](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/FrameAPICharacterModelBaseDocumentation.lua)、[动作编号](https://trinitycore.atlassian.net/wiki/spaces/tc/pages/2129958/AnimationData)和 [ElvUI 的模型播放](https://github.com/tukui-org/ElvUI/blob/main/ElvUI/Game/Shared/Modules/Misc/AFK.lua)。

## 0.4.0 完成提示和日志

Lua 5.1 模拟通过预览推进、帐篷先完成时保留、最后一层晚于引导结束、全部完成关窗、移动立即关窗、日志内容与上限。安装文件对哈希及 ZIP 完整性通过。提交 `bdf618e` 已推送，见 [0.4.0 试用包](https://github.com/Eplayed/camp-portrait/releases/tag/v0.4.0)。尚未取得国服新版自动触发、奖励提示和日志窗的实机截图。

## 受击边缘 HitGlow 0.1.0

独立本机源码 `D:/project/hit-glow/HitGlow`，ZIP 在 `D:/project/hit-glow/dist/HitGlow-0.1.0.zip`。四边中央由外缘橙红过渡到内侧透明，沿边在两端渐隐，整体以两段呼吸衰减。支持逐边预览和事件状态查看。默认没有实战提醒，玩家可以启用无方向提示，它只响应确实送达的自身 `UNIT_COMBAT/WOUND`。状态命令能显示注册和本次可读事件计数。

现阶段真实方向阻塞于缺少攻击者方位信号。客户端 UI 源码中的 `COMBAT_TEXT_UPDATE` 只有文字分类参数，数据读取依赖当前选定的战斗文字单位，代码只将它用作观测，不改变该单位。使用目标位置无法证明目标是实际攻击者。项目约定不加战斗日志解析。参考 [原生 API 声明](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/CombatTextDocumentation.lua) 和 [Forever 客户端 API 差异记录](https://github.com/Osso/wow-ui-sim/blob/master/docs/wowforever-1.60.1-ui-api-deltas.md)。

Lua 5.1 模拟覆盖单边播放、淡出、默认关闭、忽略他人和不明受击文字、本人的可读受击触发和关闭按钮。已安装并校验本机文件及 ZIP。实战事件是否送达、四边屏幕效果尚待国服验证。重启后用 `/hitglow right` 看效果，用 `/hitglow status` 看事件。

## HitGlow 0.2.0 受击不亮

站主实战报告窗口未亮。读取本机已落盘设置为 `HitGlowDB = {}`。用相同设置和模拟玩家自身受击事件重现旧版不亮。旧版要求开关为真，首次加载未赋默认值。落盘设置不能代表游戏仍在运行时的内存值。

新版将未设置的实战开关初始化为开，保留明确关闭。玩家 `UNIT_COMBAT/WOUND`、明确绑定本人的伤害文字事件、可读生命值下降都能请求四边呼吸提示。血量变化包括环境伤害，隐藏或未知数值不参与比较。跨事件限频避免同一次受击反复触发。`/hitglow status` 显示开关、已亮次数、最近来源、各事件注册和送达情况。文字事件归属参考 [客户端生成的 CombatText API 文档](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/CombatTextDocumentation.lua)，Forever 对相关事件的实际使用参考 [Comix Forever 作者说明](https://www.curseforge.com/wow/addons/comix-for-forever)。

Lua 5.1 回归中旧版失败，新版通过空设置与自身受击路径、伤害文字归属、忽略治疗和非本人、可读掉血、隐藏数值后的重建、最大生命变化、手动关闭、动画结束。已覆盖本机安装并校验文件哈希与 ZIP 完整性，试用包为 `D:/project/hit-glow/dist/HitGlow-0.2.0.zip`。游戏需重载。国服事件送达和屏幕效果待玩家复测，真实攻击者方位仍缺公开信号。

## 主城海报与四边受击提示

站主确认旧版国服受击会四边一起亮，并反馈进入旅馆或主城时误弹睡袋或帐篷海报。旅途小憩 0.6.0 收紧睡袋补充检测。依赖休息状态的分支需要最近在同一地图和子区域铺袋，当前还须在户外且不在主城。有明确引导或增益变化仍可进入睡袋路径，帐篷仍根据专属光环检测。新区域清理旧会话与铺袋记录。

设置增加「主城内停下时展示人物海报」，默认关闭，与睡袋帐篷开关各自保存。打开后在六座主城的休息区静止约 1.5 秒会显示普通海报。移动关闭，继续静止可再次展示。手动关闭时，本次进城不再自动展示。地图编号 1453 至 1458 已与本机 QuestieDB Forever 地图表对照，父地图可识别子区域。

HitGlow 0.3.0 将未知方向的四边提示改为默认关闭。受击事件仍计入 `/hitglow status`，`/hitglow unknown` 可恢复四边后备显示。现有公开受击事件只有受击单位及类型，无法将当前目标等同于实际攻击者。[Forever Combat Text 的作者说明](https://www.curseforge.com/wow/addons/forever-combat-text)

Lua 5.1 已模拟户外普通休息、先铺袋再进入旅馆、拥有睡袋时的户外补充识别、主城选项开关与子地图、移动和再停下、睡袋和帐篷双计时。HitGlow 已模拟未知方向默认不点亮、单边预览与显式开启后备。两份本机安装均校验文件哈希和 ZIP。旅途小憩提交 `ae48ede`，见 [0.6.0 试用包](https://github.com/Eplayed/camp-portrait/releases/tag/v0.6.0)。HitGlow 本地包 `D:/project/hit-glow/dist/HitGlow-0.3.0.zip`。两份新版仍待国服重载实拍。
