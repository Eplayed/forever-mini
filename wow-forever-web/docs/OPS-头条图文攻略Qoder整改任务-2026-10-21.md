# 头条图文攻略：继续做，但先修成能让玩家照做

日期：2026-10-21。主角色：wow-ops。状态：**已定**（内容方向与整改优先级）；**待 Qoder 实施与 Codex 验收**（代码和样稿）；**待人工核对**（当前平台页面与上传图片）。本文件是给 Qoder 的任务书，不表示已发送、已修复或已重新发布。

## 给号主的判断

图文攻略可以继续做。它能让读者收藏、照步骤操作，也比单纯复述资讯更适合积累信任。现在先别追篇数：抽查发现“待核数字上图”“信息概览叫攻略”“正文和图卡相互矛盾”“发布配文截断”。这些比配色、封面和 AI 评分更影响读者能不能用。头条先验证问题是否有人看、积累粉丝；按现行口径不在头条图文里硬导流或带货，也不把阅读量直接算作收入。

每篇只解答**一个明确问题**，采用这个最小结构：适用版本和人群 → 操作前提 → 按顺序做什么（菜单、地点、数值来源可定位）→ 做完应看到什么 → 失败/不适用时怎么办。关键步骤配真实截图，标清“操作前/操作后”和箭头位置；没有路线、入口或实测结果，就把标题改为“介绍/观察”，不要硬叫攻略，更不能编步骤。先用一篇“老电脑画面设置”做可复核样稿：限定硬件和游戏版本，核对每一个选项名称，统一“视野”建议；没前后对比测试就不承诺 FPS 或“毛边全消”。

证据见 [成品抽查](OPS-头条图文攻略审阅-2026-10-20.md)：87 的“46亿”被原整理稿标为疑点，却进入文案和图；85 的“5年/5%/20%”缺足够来源，却变成装备建议；83 的“视野别一次拉满/推荐拉满”互相冲突，配文在“帧数提升幅”处截断。`video2text/output/toutiao/_platform_items.json` 的历史抓取快照能证实三篇的**当时发布文字**，不能证实当前页面和当时上传图片。先核当前线上版本，再决定人工修订；不要自动操作平台。
