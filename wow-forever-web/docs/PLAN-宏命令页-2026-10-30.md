# 宏命令页 · 策划与界面口径 · 2026-10-30

本轮链条：wow-data（数据线，已完成）→ wow-planner + wow-ui（这一份）→ wow-dev（实现与门禁）
站主指令："素材库中有魔兽无限的宏命令素材，先整理好数据，然后在网页端导航条添加宏命令入口，设计宏命令页面。"

## 一、数据到手的是什么（先说能做什么、不能做什么）

`app/data/macros.json`：**245 条宏 / 9 职业 / 38 个用途分组**，每条带
`classId · group · title(中文) · titleEn · note(中文一句) · noteEn · minLevel(几级能用) · foreverNew(《无限》新技能) · body(可直接粘的宏正文) · spellIds · nameFrom · rankMarker`。

三条边界，界面上必须说清楚，不能装得比数据更多：

1. **整批 L1**：一家第三方插件（GearInsight 无限版 0.5.6）整理，它自报来源是 foreverdb.net 与 classicwowforever.com；
   本站**没有一条进游戏实测过**。页顶那句直接读 `meta.pageNote`，不另抄一份。
2. **41 个法术 ID 本站技能表里没有**，那部分名字是退回插件烘好的写法（逐条记 `nameFrom=addon`，
   名单在 `meta.unverifiedSpellIds`）。203/245 条宏的名字全部出自本站技能表。
3. **5 条宏带 `(Rank N)` 等级标记**（如"2 级圣光术"）。中文客户端里等级的写法不一定是这个字样，
   这 5 条要标出来，别让玩家粘了以为一定能用。

## 二、这一页要回答玩家的问题

"我这个职业、我这个等级，能一键粘进游戏就用的宏有哪几条？"
所以排序逻辑不是"按热度"（我们没有热度数据，也不做强度评价），而是**按职业 → 按用途分组**，
每条给"几级能用"和"这条做什么"，正文一键复制。

## 三、导航入口

`lib/nav.js` 的「工具」组加一格（这一组原来只有「排行」）：

```
{ file: 'macros.html', t: '宏命令', d: '9 职业宏库：按用途分组、几级能用、一键复制正文' }
```

- 旧站没有 `macros.html` 这个文件，所以走 `MIGRATED` 表里加一条 `'macros.html': '/macros'`，
  与 `items.html` / `bis.html` 同一做法（导航因此走站内路由、正确高亮）。
- 导航从 12 格变 13 格，`site-check` 的名单断言跟着改（那条钉的是"名单与顺序"，不是数量写死）。
- **首页不加卡**：站主这次只说导航加一格。要加再说，别顺手改首页布局。

## 四、页面结构（自上而下）

| 块 | 内容 | 数据来源 |
| --- | --- | --- |
| 页首卡 | H1「宏命令」+ 一句口径 + 计数行「245 条 · 9 职业 · 38 个用途分组」 | `meta.pageNote` / 现算 |
| 职业条 | 9 颗芯片，各带该职业条数；当前职业高亮；点一颗筛这一职业 | `macros[].classId` |
| 用途分组 | 只出**当前职业真有的**组，各带条数；再点同一颗回"全部" | `macros[].group` |
| 搜索 + 等级 | 搜宏名/说明/正文里的法术名；「我现在的等级」数字框 → 只列 `minLevel ≤ 等级` | 现筛 |
| 宏卡列表 | 每条一卡：标题（+《无限》新 / 带等级标记 角标）· 组 · 几级能用 · 一句说明 · 宏正文（等宽、可粘） · 「复制宏」按钮 | `macros[]` |
| 空态 | 「没有匹配的宏，换个词或把等级放宽」——不许出现空白屏 | 现算 |

三条硬口径（都是这一站犯过或钉过的）：

- **选了必须真生效**：每颗芯片、搜索框、等级框都要能改画面；筛完为空的芯片**不许出现**（不给白放的选项）。
- **不写死的数**：所有计数（总条数、每职业、每组、滤掉几条）一律从数据现算，
  导航说明里也不放条数（那个数会随采集变）。
- **正文不许被排版吃掉**：宏体用 `<pre>` 原样呈现（换行、`;`、`[mod:shift]` 这些是语法不是文案），
  复制出去的字符串与页面上看到的**逐字相同**——这条由门禁量，不靠眼看。

## 五、红线对照（根 AGENTS.md 第五节）

| 红线 | 这一页怎么做 |
| --- | --- |
| 宏与 WA 可以分享，但**一律不收钱** | 页面没有任何付费位；不进会员/兑换 |
| **标来源**（作者 / 原帖 / 抓取日期），指不出的按待核不发布 | 页顶一句写明"第三方插件整理 + 其自报上游 + 核对日"；溯源页新增「宏命令」一段（`SECTION_CN` 已登记） |
| **不分发插件本体**、不给执行入口 | 只给宏文本与"复制"，没有下载链接、不引导装插件 |
| **不做循环提示**（"下一个技能打什么"） | 只列单条宏做什么，不排输出顺序、不做"该按哪个"的建议；`note` 是这条宏自身的行为说明，不是循环表 |
| 不做强度评价 | 没有 DPS、没有"最好用的宏"排序 |
| 禁词 | 页面上不出现"插件目录 / 脚本 / 上游 / 口径"这类开发词，`build-data` 与 `site-check` 两处一把尺子扫 |

## 六、明确不做

- 不做"按专精筛"：数据里没有专精字段，硬造就是编。
- 不做 WeakAuras 字符串：这批素材里没有，红线也要求指得出作者才发。
- 不进顶部全站搜索索引（`data/search.json` 是另一条顺序表）——留作下一步，先保证这一页自己能用。
- 不做手机端专门适配（站主 2026-10-28 定：手机网页版不做）。
- 小程序那一侧的宏查询是 2026-10-30 那条计划里的另一件事，本轮不碰。

## 七、验收（人眼 + 门禁）

1. 导航「工具」组里出现「宏命令」，点进去是 `#/macros`，当前项高亮。
2. 默认看到战士的 22 条；换职业、点分组、搜索、填等级，四种操作画面都真的变，计数行跟着变。
3. 随便挑一条点「复制宏」，粘出来与页面上那段逐字一样（含换行）。
4. 带 `(Rank N)` 的那 5 条有角标，说明为什么标它。
5. 页顶那句口径在，且没有"我们已实测"这种话。
6. 门禁：`site-check.py` 新增 `[6g] 宏命令` 一节；`node tools/build-data.js` 的宏卡口已建并用五种坏数据反面钉过（半成品占位 / 缺来源 / 冒充 L0 / 等级 90 / 待核名单被清空，全部拦红）。
