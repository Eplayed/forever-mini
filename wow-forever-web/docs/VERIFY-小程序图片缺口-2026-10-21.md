# VERIFY · 小程序"副本没图、技能没图标"是什么问题

日期：2026-10-21｜主角色：wow-dev｜性质：诊断（本轮不改代码、不传素材）

## 一句话结论

不是图坏了、也不是路径写错——**小程序这一层从来就没有图**。三处断点叠在一起，
其中"技能没图标"还多一层原因：小程序根本没有技能页。素材本身在仓库里是齐的，
缺的是"把素材发到 OSS + 界面画出来 + 域名白名单"这一整条链路，它没做过。

## 二、三处断点，逐个给证据

| # | 断在哪 | 证据 |
| --- | --- | --- |
| 1 | **数据层主动把图字段摘了** | `wow-forever-web/tools/oss-release.js:79-82` 的 `DROPPED_DETAIL_FIELDS` 明确摘掉 `art` 与 `bosses[].portrait`；构建批次里 38 份详情分片**一个 `art` 字段都没有**（实测字段并集里没有 art/portrait）。摘它的理由写在指针里：`droppedFields[].reason = "客户端原画素材本轮没有传到 OSS，站内相对路径在小程序里打不开"` |
| 2 | **分发层没有素材这一层** | `oss-release.js` 与 `for-mini/services/oss-manifest.js` 里搜不到 `assets` 这个词；bucket 上只有 `wow/{env}/v1/builds/…` 的 JSON。而且有一条硬卡口：批次文件里出现 `img/`、`src/`、`static/` 开头的路径就**构建失败**（`oss-release.js:339`），所以站内图路径根本进不了小程序的数据 |
| 3 | **界面一个 `<image>` 都没有** | `grep -rn "<image" for-mini/pages/` → 四个页面（首页 / 速查 / 副本列表 / 副本详情）零命中。M01 那两页是按 PRD §4.6「首单默认文字卡、图片是可选增强」做的纯文字版 |
| 4 | **技能线在小程序里还没做** | `for-mini/app.json` 的 pages 只有 home / glossary / dungeons / dungeon 四项；技能书在首页「还在整理」chip 里，点它只弹一句"官方中文稿只覆盖 4 职业，其余待采"。所以"技能没图标"的第一层是**没有技能页** |

顺带一条同源的：速查页那 215 条词条 `iconKey` 是 **0/215**——基底里词条记录本来就没挂图标键，
不是丢了。要给词条配图，得先从 `spells.json` / `items.json` 那边把 `iconKey` 带进词条记录。

所以数据侧其实只差"文件传上去 + 界面画出来"。

## 四、为什么当初要摘（不是偷懒）

- 红线：素材一律本地留存、**禁止热链**；小程序没有站内静态目录，`img/art/xxx.webp` 这种相对路径
  在微信里就是 404。与其给玩家一个碎图，不如在分发层明确摘掉并在指针里写"为什么没有"。
- 红线：客户端原画**不打进主包**（`for-mini/AGENTS.md`、根 `AGENTS.md`），只能走 OSS。
- 所以 M01 的选择是：先交一条纯文字、能离线、字段诚实的查询线，图片留给素材批次。
  这条决定写在 `for-mini/docs/DATA.md` §三 与 M01 验证文件 §6.5。

## 五、要补的话，怎么做（三个决定点）

**A. 素材批次怎么发**：加 `wow/{env}/v1/assets/{icons,art,portraits}/<文件名>` 一层。
图标文件名本身就是内容键（`iconKey`），不需要批次号，直接 immutable 长缓存；
`art`/`portrait` 把站内路径 `img/art/...` 映射成 `assets/art/...` 保留字段，
卡口从"出现 img/ 就失败"改成"必须重写成 assets/ 前缀，否则失败"。上传走同一道写闸（`WOW_ALLOW_CROSS_CREDS=1`）。

**B. 界面怎么回落**：`<image src="{{base + path}}" lazy-load mode="aspectFill" binderror="...">`，
取不到就退回跟网页 `IconCell` 同款的自绘块，不许出现碎图；首领头像缺失继续写"没有这张头像"。

**C. 两个前置条件（这两条我碰不到）**
1. **域名白名单**：小程序里 `<image>` 走的是 **downloadFile 合法域名**，必须在公众平台后台
   把 `poe2-all-class.oss-cn-hangzhou.aliyuncs.com` 加进去，且该域名需已 ICP 备案。
   现在这把 appid（`wxfd9a2b985a6cedc3`）能配了，但**配之前真机上所有图都是空的**——
   即使素材传上去、代码写好也不显示。这条要先验，别做完才发现。
2. **版权口径要跟着进来**：原画是第三方转存的客户端画面，副本内部底图里有插件作者**自绘的示意图**，
   根 `AGENTS.md` 要求这类图"就地标注这不是游戏里的地图"、带 manifest、留"整目录删除即回退"的下线方案。
   网页端已经做了这套；小程序要上图，这套标注必须一起做，不是拷文件就完事。

**成本**：存储 3.3 MB ≈ 每月几分钱；按 PRD 那组示例单价（¥0.50/GB 外网下行）算，
一次详情页 ≈ 原画 21 KB + 头像 4×2.8 KB + 掉落 8×2.3 KB ≈ **50 KB**，1 万次约 0.5 GB ≈ ¥0.25/月。
钱不是问题，**域名白名单与版权标注才是**。

## 六、状态

`已定`：成因定位到三处断点（数据层摘字段、分发层无 assets、界面无 `<image>`）+ 技能页未做；
素材库存与引用覆盖率已量清（掉落 546/547、技能 392/393、原画 36/38、头像 146/228），需上传约 3.3 MB。
`待用户确认`：① 要不要开这一单（素材批次 + 三处界面加图 + 回落自绘）；② 先去后台把 downloadFile 域名配上并验真机能取图，
还是先做完代码等你配；③ 词条要不要配图（要先在基底给词条挂 `iconKey`，那是数据侧一单）。
`阻塞（原因）`：域名白名单只能你在公众平台后台加；真机验证还需该 appid 的预览权限与备案进度。
