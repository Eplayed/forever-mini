   `#showtooltip 猎豹形态\r\n/cancelform\r\n/cast 猎豹形态`，正文**一字不差**，只是 Windows 的 CF_TEXT 把 `\n` 交成 `\r\n`；
   逐字节等式在这一台机器上永远不成立。已改成**只允许差别落在换行符上**（`got.replace('\r\n','\n')==txt` **且** 多出来的字节数正好等于 `\n` 的个数），
   多一个字符、少一个字符、差在别处都照样红——**这是收紧，不是放宽**；明细里现在会写"剪贴板差别只在换行符（Windows CF_TEXT）"，不把原因藏起来。
   顺带记一条产品事实：**从 Windows 复制出去的宏带着 `\r`**，游戏里粘进去是否受得住，没人实测过（等站主或进游戏核）。
