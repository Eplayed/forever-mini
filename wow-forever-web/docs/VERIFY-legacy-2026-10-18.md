## 一、改了什么（四块）

1. **主卡**：四颗小方框读数改成一行"数 + 单位"的读数带（数全部现算）；
   三棵树切换改成与导航带同一套语言的胶囊，胶囊上带"7 格 · 未公开 2"；底下加一行页内锚点。
2. **树卡**：格子仍按客户端 `row × cols` 摆（数据事实，不重排），每排左边挂"第N排"。
   原来**空格与"未公开"都画虚线框**，两种完全不同的东西读起来是一回事——
   现在整页只有"未公开"用虚线，空格子只剩一点轮廓；有前置的格子角上挂"有前置"。
3. **详情栏不再空盒子**：没选时显示这一棵树的三行读数 + 三条图例；
   选中时显示大图标 + 名字 + 层数点条 + 属于哪棵树 + 第几排第几列 + **前置可点**
   （前置在另一棵树时先切树再选中）。换树清掉上一棵的选中态。
4. **六组挑战改成可折叠**：默认只开第一组，`v-show` 不是删（66 行始终在 DOM）；
   搜索时命中的组自动展开，清空后回到用户自己点开的那两组。

**整页高度：1440 下 4949 → 3029 像素；375 下 5446 → 3501。**

## 二、两个坑

- **锚点不能写 `href="#ltree"`。** 这一页在哈希路由里，裸 `#id` 会把整条路由换掉——
  和首页那批"点了没反应"是同一个坑（见 `VERIFY-home-nav-2026-10-18.md` 第一节）。
  做法：`href` 走 `hrefOf('legacy.html#ltree')` 出合法的 `#/legacy?to=ltree`，
  点击时 `preventDefault` 只做平滑滚动。断言钉"三个 href 必须以 `#/legacy?to=` 开头"。
- **排号被折成两行。** "第 1 排"带空格、`.lge-rail` 给 40px 不够宽，实测折成"第 1"/"排"。
  改成"第1排" + `white-space:nowrap` + 46px。

## 三、写断言时被数据绊了一次

**"未公开"的格子也带 `perk` 号**（形如 `unknown-113508`，不在这 21 个专长里）。
第一版断言用"slot 有没有 `perk` 字段"挑真专长，直接 `KeyError`。
正确判据是 `perk 存在 且 不是 empty 且 不是 unknown`——已写进代码注释。
这条不是测试写错了才发现的废话：**它说明界面上"未公开"那一格确实占着一个真实坐标与真实编号**，
以后谁要把"未公开"改成不占位，会先撞这条。

## 五、没验到的 / 要你定的

1. **真浏览器手点没做**——上面是无头 Chrome 的断言。折叠、跳前置、锚点这三条交互
   建议你手点一遍，尤其是"点前置"这种第一次做的行为。
2. **这一页仍然回答不了"点这个专长有什么用"。** 站主这轮明确不补，那就留着；
   什么时候要补，走的是"再开一次红线"或"客户端导出"两条路，不是改版式能解决的。
3. **顺带发现一句玩家可见文字里带着商标词**：挑战明细里有一条
   「参与过《魔兽世界：无限》测试 给 16 点」，这是客户端里的原文照录，
   不是我们起的名字。红线要求"站名、小程序名与素材避开商标词"，
   引用游戏内原文算不算"素材"没有明确判例。**本轮没动这条数据**，等你定：
   留着（是原文）、还是改写成"参与过本服测试"。
4. 三棵树的数完全一样（都是 7 格 / 2 未公开 / 2 前置 / 23 层），
   所以"胶囊上的数"这类断言目前区分度不高——不是断言写松了，是数据恰好一样。
