1. 在 Windows 本地 `wowf/1.60.1.70532` 上先做两阵营逐槽预检：每个 item ID 能否从 Item/ItemSparse 解析、能否走到外观/纹理/附件、哪些槽本来不可见；逐行给 `item ID → appearance/display ID → 资源 FDID → ekey → 本地可读`。特别查肩甲 `2278` 上轮 ItemSparse 缺行的原因。缺件继续核其他槽，最后给完整缺口清单；**不得换相似物品顶替**。
2. E4 对同 FDID 的已装变体进行替换时，请同时核该 rootType 的 localeFlags/contentFlags；若替代项不符合 zhCN、低暴力等原选择条件，单列为“本地可读但外观真实性未核”，不要记为准确模型。记录每次实际用到的变体与规则。
3. 只有全部可见槽都能按原 item ID 解析，才先导**联盟猎人**整人 GLB、同角度正背截图、独立查看器截图和逐槽映射；联盟通过再导部落。附原始 GLB 与可选的网页优化版，优化版必须在同角度视觉对照，不能因压缩丢装备细节。无法得到完整套装则交可复现的部分证据，状态 `BLOCKED(具体槽位)`，不要称为完整模型。
4. 仍只在独立工具副本和输出目录操作；客户端只读，`allowCacheCollection=false`，禁止 CDN 回退和跨 build 混用。不改网站、不公开发布资产。交新的 ZIP、包外字节数/SHA-256、ZIP 内逐文件哈希、原始日志、工具精确 diff、实际未验项。
