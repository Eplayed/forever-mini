## 能否抓取：可以，但按用途收窄

1. 对方 `robots.txt` 对公开网页及 `/api/open/` 开放，明确不开放 `/admin` 与一般 `/api/`。`/api/open/v1` 是**只读、免登录**的物品 API；OpenAPI 文档写每 IP 每秒最多 **5 次**，列表每页最多 100 件、`ids` 一次最多 100 个。优先用这套公开 API 做增量 ID/事实字段核查；不碰未开放的接口、不绕过登录/限流、不持续高频抓整站。
2. 依仓库红线，只取 ID、名称、等级、坐标、图标**文件名**、掉落归属等事实字段；BiS 只按已批准的名单窄例外。对方 `llms.txt` 要求引用“新手盒子·魔兽世界无限数据库”并给页面网址；每条入库还须抓取日期、页面 URL、来源等级和字段冲突留档。公开访问与可大量复制文字/图片不是一回事。
3. 不搬对方攻略、介绍、技能效果整句、任务说明、页面设计与图片；不热链。一般图标从官方 CDN 本地取，取不到按项目规则处理；客户端原画只走已批准的本地 manifest/回退机制。最新插件明确提供的物品属性仍按 GI/XR 既定优先级，第三方站只作缺字段兜底或核对。
4. 译名若据其客户端解包转述升 L0，逐条保存可点开的来源 URL 与日期，并跑 `audit-translations.py` 逐字校验；冲突保留 `nameAlt`，不能把 `70532` 当作自动升档理由。
