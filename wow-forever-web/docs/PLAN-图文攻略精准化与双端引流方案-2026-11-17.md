## 二、为什么 `video2text` 一直「内容不准、配图不好」？（实查 #121 / #123 / #124 根因）

我刚通过 SSH 连上 MacBook（`192.168.0.101`）调取了最近生成的 `#121`、`#123`（《魔兽无限地下城装备收藏指南》）、`#124` 的 `manifest.json` 和成品 PNG，并与你这台 Windows 电脑上的数据库逐条比对，根因非常明确：

### 1. 为什么「一直不准确」？——把抖音口播当成了「事实源」，而不是只当「选题源」
- **倒果为因的流水线**：现在 `video2text` 是先拿抖音博主视频做语音转文字（ASR），再让大模型从口播稿里提炼装备名、属性和副本经验。
- **三个必然出错的漏斗**：
  1. **ASR 谐音与口误**：博主口播说快了或方言口音，转写出来的地名、BOSS 名、装备名天然带错字；
  2. **内测旧版本数据污染**：抖音视频库里大量混着 9 月、10 月测试服（30 级封顶期）的视频，导致 `#124` 出现过时的等级限制和旧副本经验数值；
  3. **口播残缺不全（缺关键属性与获取条件）**：以 `#123` 成品图为例——
     - 讲死亡矿井「铁匠短裤」，口播只写了「熔炼时间缩短25%」，漏掉了本机数据库 `items-detail.json`（ID `5199`）里明明白白的 **`76 护甲、+7 耐力、+5 精神`**；
     - 讲「大副的戒指 + 良配之戒」两件套（`ID 284715 + 284716`，本机 `Sets.lua` 套装 ID `2131`「同谋佳偶」），口播完全没写另一件「良配之戒」加 **`+10 耐力、+18 力量、+12 精准`**，也没交代获取方式；
     - 讲哀嚎洞穴「滑行腰索」（ID `273089`），漏掉了 **`22 护甲、装备：法力值恢复 +3`**。

### 2. 为什么「图片配图配得不好」？——去压缩视频里抠糊帧，放着本地高清库不用
实查 `#123` 的 5 张成品图（`poster_p1.png` ~ `poster_p5.png`），视觉上有 4 个致命伤：
1. **抠出来的视频帧带重影、糊且残缺**：`#123` 封面和第 2 页的「隐修之福披风」是从抖音视频里截的局部框，背景里还透着另一件装备「蛇眼万花筒」的蓝色重影字，且连装备图标都没截进来；
2. **「场景参考图」完全文不对题**：`#123` 第 4 页讲「暴风城监狱 · 铁指虎（布鲁高·铁拳掉落）」，底下配的 `page-4.png` 是一张乌漆嘛黑的英文私服/外服战斗远景（怪头顶英文 `Defias Captive`，玩家名 `<Little Guppies>`），读者在图上根本找不到铁指虎，还一眼看出不是国服画面；
3. **同页条目冷热不均**：一页列 3–4 件装备，只有中间 1 件贴了张小截图，另外 2–3 件全是干巴巴的白字框，连个装备图标都没有；
4. **封面重复且无抓手**：封面（`poster_p1.png`）只是深绿底色写一行标题，再把第 2 页那张糊掉的「隐修之福披风」原样贴一遍，在信息流里滑过去毫无点击欲望。

2. **卡点② 清单生成层只抄残缺口播，没有按实体 ID 自动挂载结构化事实**：
   - 主播口播往往漏掉前置条件、接取坐标或基础属性；需在清单层识别出条目对应的物品/副本/任务/技能后，自动从真源表拉取**标准属性、坐标、等级与阵营标签**供勾选确认。
3. **卡点③ `src/checklist_frames.py` 把配图限制死为「每页只准从原视频抽 1 张帧」**：
   - 导致非实操类攻略（副本路线、职业改动、装备盘点、任务清单）一旦原视频那一秒没停在清晰界面上，就只能拿模糊的跑路/打怪远景充数，且同页其余条目全无图标。
4. **卡点④ `src/poster_typeset.py::typeset_checklist_reading`（第 1035 行）只画纯文字框，没画条目图标与分类组件**：
   - 3:4 阅读版在渲染卡片时只调了 `draw.rounded_rectangle` + `paint_lines`，连 `icons_cn.json` 里的图标都没画上去，视觉单调。
