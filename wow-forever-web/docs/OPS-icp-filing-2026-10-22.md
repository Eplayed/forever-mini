# 阿里云 ICP 备案 · 流程、资格与本线风险

日期：2026-10-22 ｜角色：wow-ops ｜状态：**待用户确认（要不要走国内接入）**

规则全部取自阿里云帮助中心与工信部公开页面，抓取日期 2026-10-22，来源清单在文末。网上那些"备案攻略"博客里的数字（尤其"3–7 天必过"）我没采信。

## 0. 先给结论

1. **我们现在不需要备案。** 阿里云文档原话：域名仅解析至非中国内地的服务器，不要求备案。站目前在 GitHub Pages（境外），属这一类。
2. 备案换不来"站能存在"，只换来两件事：**国内打开快** 和 **微信内打开稳**。这两条是不是我们当前的瓶颈，得先量——见第 5 节。
3. **小程序那条线卡的不是阿里云备案**，是微信公众平台里的"小程序备案"（另一套表单、同样 1–20 个工作日的管局审核）。关键路径仍然在它，别把两件事混成一个待办。
4. 备案本身**不收钱**。要花钱的是"备案资格"：必须有一台中国内地、包年包月满 3 个月的云资源。

## 1. 域名要同时满足四条（这是最容易踩的部分）

| # | 要求 | 对我们的含义 |
| --- | --- | --- |
| 1 | 后缀已获工信部批复 | `.org` 明确未获批、不能备案；`.top / .com / .cn / .net` 可以。以工信部"中国互联网域名体系"页为准，别信注册商页面 |
| 2 | **注册商必须是工信部已批复的内地机构** | 在阿里云**国际站**、Namecheap、Porkbun 注册的域名**不满足**，必须先转入内地注册商。阿里云自己（中国站）注册的直接满足 |
| 3 | 域名实名信息与备案主体**完全一致** | 个人备案 = 持有人名称、证件类型、证件号码都得是你本人的身份证。实名或过户后**同步工信部要 2–3 天**才能提备案（阿里云自己注册的可以先提交，初审通过后系统自动延期再报管局） |
| 4 | 域名距到期 **> 45 天** | 首年只买 1 年、到期前才想起备案会被这条卡住 |

补充两条实操：只备主域名（`example.com`），备完所有子域名（`www.`、`api.`）不用再单独备；阿里云**一个账号只能有一个备案主体**。

想"先在国外买便宜域名、以后要备案再转进来"——能转，但有代价：ICANN/注册局规则要求**域名注册满 60 天才能转注册商**，转入流程 5–7 天，且转入要再付一年续费。所以打算备案的域名，一开始就在内地注册商买省事。

## 2. 可备案资源（拿"备案服务码"的条件）

硬条件：**中国内地节点 + 包年包月，购买时长 > 3 个月（含续费累计）**。

- 满足的：ECS 实例（要买公网带宽，**免费试用的不算**）、轻量应用服务器、云虚拟主机 → 每台送 **5 个**服务码；万小智 AI 建站（选中国内地节点，轻量版 1 / 标准版 2 / 高级版 3）；云·企业官网 5 个；函数计算套餐包（订单 ≥ 100 元且包月 ≥ 3 个月）1 个；云市场建站产品（首购 ≥ 12 个月且 ≥ 99 元）1 个。
- 不满足的：**按量付费**（要先转包年包月）、负载均衡 SLB/NLB/ALB、容器服务 ACK——这些不给服务码，绑在后面的 ECS 上才能备。
- **OSS、CDN、WAF、高防自己不提供服务码**，但用它们加速的域名必须在工信部有备案号。也就是说"套个 CDN 当国内接入"绕不开备案，反过来源站在阿里云的话回源域名还得在阿里云做"新增接入"，否则被阻断。
- 备案账号和资源账号同一个 → 服务码自动关联，不用手动领；不同账号需要资源方授权，而**个人认证账号不能授权给别人**。

最便宜的拿资格方式大概是促销档的轻量应用服务器（2026-09 阿里云开发者社区那篇活动文写 2核2G 38 元/年，**这只是活动价，下单页为准**）。真实年度总账按 2026-10-19 那轮我查的口径：域名 + 轻量 + CDN 稳定跑起来约 670–770 元/年。

## 3. 流程和时间线

| 阶段 | 做什么 | 官方口径耗时 |
| --- | --- | --- |
| 准备 | 阿里云账号实名 → 建域名信息模板并实名 → 买内地资源 | 模板实名一般 1 个工作日，部分 3–5 个；实名同步工信部 2–3 天 |
| 提单 | ICP 代备案管理系统"开始备案"，5 步：基础信息校验 → 主办者信息 → 网站信息（含接入信息）→ 上传资料与真实性核验 → 确认提交 | 你自己填，半小时到几小时 |
| 初审 | 阿里云审核专员核信息，**可能打电话**（要接听）；个别省还要邮寄资料 | 1–2 个工作日 |
| 短信核验 | 工信部发 12381 验证码，**24 小时内**在工信部备案管理系统填码确认，逾期订单作废 | 卡在这一步的人最多 |
| 管局审核 | 省通信管理局终审 | **一般 1–20 个工作日**，各省差别大 |
| 备案后 | 网站底部挂 ICP 备案号并链到工信部；**30 日内**到全国互联网安全管理服务平台（beian.mps.gov.cn）做公安联网备案 | 公安备案漏了会被催办 |

顺利 2–4 周；被驳回一次起码重来，加一周以上。**部分省份要求身份证与备案地一致**，不一致要当地居住证或换备案省份。

## 4. 本线的两个真问题（比流程难，这是我要你拍板的地方）

**4.1 游戏类内容 + 个人备案 = 冲突。**
个人备案的网站名称不得涉及行业、企业、产品信息，全国通用禁用词包括 博客 / 论坛 / 社区 / 交流 / 在线 / 资讯 / 网站 / 网络 / 平台 / 爱好者 / 作品展示 / 个人空间 等，部分省（华为云列的广东口径里也出现过）明确把 **游戏** 列为个人备案禁用词；各省还各自加词。名称又要"与实际网站内容一致"，管局初审会核对网站内容——我们的站正文就是游戏资料。两头堵。

可行的做法是把名称和备注做成"个人资料整理与查询"这类中性表述（3–10 个汉字，不含上述词，不用人名、地名、成语），备注强调无用户发布内容。**但这一条我没有实测过，只是按规则推演**，最坏结果是被驳回、改词重来。真要走这一步，建议先用一个中性名称过审，域名与站名随后再统一改（改域名要走备案变更，不是改解析那么轻）。

**4.2 域名名字还没定，且必须先过商标词红线。**
站名与域名不能出现 魔兽 / 魔兽世界 / WoW / 暴雪 / 艾泽拉斯。2026-10-19 试下单的 `foreverclassic.top` 里 `forever` 是官方版本英文名、`classic` 是另一条产品线名，两个都还没拍板。**备案会把域名和主体一起进工信部的公开库**，名字撞商标词的代价比在 GitHub Pages 上高，这一条要在备案之前解决。（2026-10-22 站主报了新候选「跑本集合石」+ `xxx.top`，逐项判断见第 7 节，本节 4.1 与 7.3 的口径以第 7 节为准。）

**4.3 前置审批**：新闻、出版、教育、医疗保健、药品和医疗器械、文化、广播电影电视节目、网络预约车、电子公告类等行业需另办前置审批。我们零 UGC，按"信息查询"不该撞"电子公告类"；**一旦将来上评论区或投稿，就撞**。

## 5. 我的建议（顺序，不是并行）

1. 先量：现在的站从国内（家宽 + 微信内打开）到底多慢、会不会白屏。这是唯一能证明"值不值得花 670–770 元/年"的证据。我可以写一个脚本，从这台机器多次采样 `github.io` 与自定义域名的连接耗时与失败率，跑 20 次取分布，不拿单次观测下结论。
2. 慢得不能接受 → 再决定"搬内容到内地"还是"只把数据接口搬到国内 OSS（默认域名已在阿里备案名下，需实测能否满足微信校验）"。后者便宜得多，也可能根本不用备网站。
3. 无论 1、2 结论如何，**小程序备案和名称先跑**（关键路径，1–20 工作日），网页备案排在它后面。

## 7. 具体判断：站名「跑本集合石」+ 阿里云 xxx.top（2026-10-22 补）

站主报的具体方案：主页名称「跑本集合石」，在阿里云买 `xxx.top`。逐项判：

**7.1 名字这一关：大概率能过。**
形式上它合规——5 个汉字、不是人名地名成语、不是纯英文或域名、不含全国通用禁用词（博客/论坛/社区/在线/资讯/网站/平台/爱好者/作品展示/主页/工作室/导航/分享/个人空间），也不含企业名与行业词。"跑本集合石"对不玩游戏的人是生造词，这恰好是个人备案名称最安全的形态。

**但名字过关不等于内容过关。**管局和阿里初审都要求"名称与实际内容一致"，审核员会打开站看——看到的是副本、掉落、天赋、职业，就会往"游戏类"归。个人备案下真正敏感的正是这三个字。所以**卡点不在名字，在内容性质那一格**。

**7.2 `xxx.top` 这一关：能备，有三个代价。**
`.top` 在工信部批复的后缀列表里（阿里云备案文档附录确认），阿里云中国站注册 = 注册商已批复，实名模板用本人身份证 = 满足"域名实名与主体一致"。代价是：

- 首年约 13–14 元、**续费 32–35 元**（2026-10-19 实测口径），备案要求域名距到期 > 45 天；**域名到期不续，备案号会跟着注销**，低价域这个坑最容易踩。
- 实名或过户后要**等 2–3 天**同步到工信部才能提备案（阿里云自己注册的可以先提交，系统自动延期）。
- 低价新通用顶级域在微信内打开和搜索信任度上都偏低，个别省对这类后缀会多问一句（**这条我没实测，只作提醒**）。

**7.3 比名字和后缀都大的两个风险。**

1. **经营性那一格。**个人备案必须是非经营性。而 2026-10-10 已拍板"两端可开广告/流量主"、10-22 要定 ¥9.9 付费资料包——页面一旦出现收费或广告分成，性质就往"经营性互联网信息服务"偏，那要 ICP 经营许可证，**个人主体办不了**。2026-10-19 查过：挂广告算不算经营性**没有权威口径**，属灰区；但备案表里这一格必须选，选了"是"，个人备案到此为止。所以**付费与广告的决定，排在备案名字之前**。
2. **页面上现在写着"魔兽世界"。**实测：`app/src/router.js:57` 首页 `meta.title` 是《魔兽世界：无限》中文资料，`src/data/*.json` 里"魔兽世界"共 24 处（races 10、timeline 4、abilities 2、legacy 2，其余各 1）。这两条线都撞——一是我们自己的红线（站名与标题避开商标词），二是备案审核看的第一眼就是这个。**现有禁词闸 `tools/copy-banned.json` 只管维护者措辞，不管商标词，所以这个问题门禁看不见。**建议：站名与标题位置改成"跑本集合石 · 无限服资料"，页面里作为官方原话引用的那 24 处保留（它们带来源与免责说明，性质是引用不是自称）。

**7.4 备案表可抄的填法（初审电话会按这些问）。**

- 主办者性质：个人；证件：本人身份证；手机号保持 7×24 可接（**阿里初审会打电话**）
- 网站名称：跑本集合石
- 服务内容/类别：**其他**——不选"游戏"，不选"资讯/媒体"
- 前置审批：新闻/出版/教育/医疗/文化/广电/电子公告类 **全选"否"**（前提是真的零 UGC，现状符合）
- 备注写这三点，别写第四点："个人整理的资料查询页，内容只读，无需注册与登录，不含用户发布内容，不涉及在线交易与收费"
- **不建议隐瞒内容性质**。写含糊骗过初审，后续核查发现"网站内容与备案信息不符"是注销备案 + 阻断解析，代价比被驳回重来一次大。

**7.5 将来还要过第二道名字关。**"跑本集合石"如果要做小程序名，走的是微信公众平台的名称审核（个人主体、重名与商标占用会驳），和 ICP 备案是两个体系、互不代替。

**7.6 建议顺序。**① 先把首页标题里的商标词拿掉（域名、备案、商标三头都受益，且是我们自己能做的一步）→ ② 拍付费/广告那条 → ③ 买 `.top`、做实名、提备案 → ④ 小程序备案仍在关键路径上，别被网页备案挤后。
