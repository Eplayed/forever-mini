## 一、先纠正一件事：网页端现行令牌不是 UI.md §2.0 那套

`wow-forever-web/docs/UI.md` 第 2.0 节写的是 2026-10-11 的「中性黑 + 无限蓝」，但
`wow-forever-web/src/css/tokens.css` 头部记着 **2026-10-12 已经换轨**成
「史诗奇幻 × 暗黑金属」：深蓝炭黑底 + 铜金描边 + 羊皮纸文字 + 衬线标题 + 切角铭牌。
UI.md 是流水账，tokens.css 才是单一事实源——**这次小程序对齐的是 tokens.css 的现行值**，
不是 UI.md 那段历史，也不是我自己新造一套。

结论很省事：官网气质和网页现行体系是同一个方向（深蓝黑 + 金 + 羊皮纸），
小程序要做的不是"换风格"，而是**把还停在 2026-10-11 之前的一套冷黑暖金，接回主线**。

## 三、判定表：现在这套为什么不成立

| 现状 | 判据 | 处理 |
| --- | --- | --- |
| 首页 6 个模块入口，4 个点了只弹 toast | 首屏 2/3 是死按钮，玩家以为产品坏了 | 待补项从"入口"降级为"还在整理的一行 chip"，点了直接说明缺什么，不再伪装成能进的模块 |
| 数据完整度 L0–L3 四条进度条占满首屏 | 那是我们的台账，不是玩家的任务；玩家进来是"查一条" | 收成一行四个读数 + 点开看口径，首屏让给入口卡 |
| 副本线藏在首页二级 | PRD 定的 P0 高频路径 | 提成底部第三个 tab |
| 徽标 L0 绿 / L1 蓝 / L2 黄 / L3 灰 | 只靠色相承载"可信度"这一层有序信息，色盲与暗光下读不出高低 | 换成网页同一套 `--lv0…--lv3` **明度阶梯** + 徽标形状 + 文字三通道 |
| 冷黑 `#0e1013` + 暖金 `#e0a96d` | 与网页 10-12 之后的深蓝黑 + 铜金已经不是一个气质 | 全量替换令牌；页面里 5 处裸 `rgba(...)` 一并收进变量 |
| `for-mini/AGENTS.md` 还写着"暗底 #0e1013 + 暖金 #e0a96d" | 文档与实现会长期打架 | 本轮**不改那份文件**（它有别的会话未提交改动），在这里登记：待那次改动落地后由站主或下一轮 wow-dev 同步这一行 |

## 四、签名动作（这套设计"像谁"的四件事）

1. **切角铭牌**：入口卡与主按钮用 `clip-path: polygon()` 切右上角（`--cut-cta 10px`），
   这是网页那版稿子里 54 处共用的形状语言；不支持 `clip-path` 的老基库自动回落成直角 + 铜金描边，不塌版。
2. **铜金 30% 描边**：卡与面的边界一律 `rgba(200,163,92,.30)`，不再用白色半透明或冷蓝灰实线。
3. **羊皮纸标题 + 系统字重**：标题 `#f2ead8`、正文 `#e9e2d2`、次要 `#aeb6c4`，层级靠字号与字重，不靠颜色堆。
4. **顶部一道金色发丝线 + 底部皮革面 tabBar**：`#2a1c1c` 那档皮革棕只出现在这两个位置，
   让"上下边框"成为可辨识的产品轮廓，而不是每处都金。
