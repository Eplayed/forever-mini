## 二、签名动作（只有一套，铺到所有表格页）

1. **板块表 `.board`**：固定列宽 + 名字列带图标 + 状态 chip + 分组头吸附。
   新增样式全部走**新类名**（`.board / .board th / .chip-st / .grp2`），
   旧站不产出这些类名 → **旧站一个像素都不变**（这是"冻结"能落地的技术前提，
   因为两栈共用 `src/css/app.css`，不隔离就会把旧站一起改了）。
2. **板块头 `.bhead`**：标题 + 一句读数 + 筛选控件同一行。
3. 移动端 `@media` 里把编号/英文原名降级成名字下面的一行小字。

不做的：不引组件库、不引图标库、不改数据口径、不动 `src/` 的页面结构、
不在内容页恢复分级徽标与"来源"按钮（`UI.md` 3a 那条仍然有效，状态 chip 讲的是**游戏内容**
"这条与经典旧世比变了没"，不是讲我们数据可不可信，所以不违反那条）。
