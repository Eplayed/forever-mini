# 魔兽无限项目思维导图（大纲）

## 魔兽无限 中文资料项目（WoW: Forever · 2026-11-05 上线）
  - 产品定位
    - 静态资料 + 开荒工具
      - 副本手册 / 开荒清单
      - 配装·路线·术语后补
    - 个人主体小程序
      - 类目：工具-信息查询
      - 零 UGC（无评论无投稿）
    - 明确不做
      - 角色查询（国服无接口）
      - DPS / 评分排行
      - 付费与内购
      - 读账号与战斗日志
  - 合规与门槛
    - 备案 1–20 工作日＝关键路径
      - W1 必须提交
      - 个人只需身份证件
    - 资讯/游戏类目不对个人开放
    - 名称避开商标词
      - 不用 魔兽/WoW/暴雪
      - 冲突后果：改名+下架
    - 个体工商户只解锁支付与投流
      - 不解锁社区与名额
      - 变更主体会停访问
    - 流量主 UV≥500，无主体门槛
  - 时间窗
    - 国际服 Beta 2026-09-17
    - 国服 Beta 2026-10-06（388 礼包）
    - 全球上线 2026-11-05
    - 上线后 48 小时强制重核
  - 数据源

      - 职业深度解析＝译名权威
      - 在线修正＝改动报警器
      - Beta 公告 / 座谈会
    - 官方英文站（可自动化）
      - 9 新本官方名单
      - forever 页结构化数据
    - 人工参照，禁止搬数据
      - Wowhead /forever 专区
      - wowclassicforever.info
      - foreverchanges.pro
    - 旁证：17173 蓝贴转载
    - 开放数据 cmangos GPL

      - 不取掉落与数值
    - 实测：B站 ASR + 关键帧 OCR

      - 470 节点：名/系/上限/部分前置
      - 89 条名与官网一致
      - 行列坐标不可信，未采用
