# 还要从客户端出的东西 · 清单（2026-10-19）

站主定："提取副本入口和本内首领坐标，**然后我们自己从 DB2 出缺的**"。
前半句已经做完（见 `docs/VERIFY-dungeon-geo-2026-10-19.md`），这份是后半句：
**现在站内还缺什么、它在客户端的哪一层、导出来我们拿它干什么**。

一句前提：**插件帮不上"图"这件事**。DF / XR / GI 三个插件加起来 148 个图片文件，
全是它们自己的东西（UI 贴图、勾选箭头、自绘副本图、渠道 logo），
我们缺的区域底图、物品图标、首领头像一张都没有。贴图只能从客户端出。

## 二、导出的时候请一起带上这三样，不然我们对不上账

1. **每张图写清它是哪个地图号**（文件名用地图号，例：`1440.webp`）。我们现在这套就是按这个约定走的。
2. **一份来源说明**：客户端版本号（`foreverBuild`，现在是 1.60.1.70425 那一档）+ 导出日期。
   红线要求每条素材能回查"从哪一版取的"。
3. **别整目录打包**，只列上面这几类。客户端目录里 90% 是我们用不到的，混进来反而要多一道筛。

## 四、一条边界再写一遍

DF 那份插件的 LICENSE 是「保留所有权利」。这一轮从它那里拿的只有**坐标与地图号**两层，
它的成段说明、任务目标文本、攻略句子、自绘副本图与载入图**一张/一句都没进**——
这条已经写进快照 `meta.boundary` 与 `docs/wow-infinite-sources.md` §二十，
`build-data.js` 里也加了一道"坐标文件不许出现百分号"的闸。
以后要动它别的表，先过站主。

## 五、逐类核对：插件里到底有没有这些图（2026-10-19 重算，脚本对文件名）

把三个插件目录整个扫一遍：**157 个图片文件**（去重名 145 个），构成是
`ClassIcon_*.blp` 职业图标 9+9、`FactionIcon_*` 阵营图标、UI 素材（勾选圈、问答标记、图钉、线弧、箭头）、
插件 logo 与九个渠道二维码 `.tga`、**5 张自绘副本图**（领主大厅 / 洛丹伦废墟 / 挖掘场 / 达拉然 / 哀嚎洞穴）、
**2 张奥妮克希亚载入图**。

| 我们缺的（本轮重算的数） | 缺多少 | 插件里有吗 | 拿文件名去对的结果 |
| --- | --- | --- | --- |
| A 区域底图（需要 45 张，本地 37 张） | **9 张**：1424 希尔斯布莱德丘陵 / 1430 逆风小径 / 1440 灰谷 / 1449 安戈洛环形山 / 1451 希利苏斯 / 1453 暴风城 / 1457 达纳苏斯 / 2548 河林 / 2652 辛德拉 | 没有 | 插件里**没有任何一张以地图号命名的图**，0 命中 |
| B 副本内部图（首领坐标要画在哪张图上） | **28 座**，本地 0 张 | 只有 5 张作者自绘的 | 那 5 张是**作者画的画**，不是客户端底图，且 LICENSE 保留所有权利 → 不能用 |
| C 首领头像（228 个首领） | **82 张** | 没有 | 插件里一个头像文件都没有，0 命中 |
| D 物品 / 专业图标 | **82 个键**（其中 **81 个官方 CDN 也取不到**，实测 403/404） | 没有 | 拿这 82 个键去对插件的图片文件名，**0 命中** |
| E 副本载入图 | **2 座**（巴罗夫地穴、海加尔山） | 只有奥妮克希亚两张 | 这两座是还没开放的团本壳，**客户端本来就没有**，不是导出能解决的 |

**所以"插件里能不能用"这个问题有两层否决**：内容上它没有这些图（0 命中），
许可上它那些图也不让用（DF 明写保留所有权利，XR 那 5 张 CustomMaps 同理）。
**唯一出路还是从客户端出**：区域底图与副本内部图在客户端的 MapArt 贴图里，
物品图标客户端有真文件（CDN 缺的那 81 个正是靠这条路），
首领头像要看 `CreatureModelData` 有没有专图——**很多怪本来就没有头像图，这一类可能永远补不齐**，
补不齐的界面继续用自绘字母块，不猜图。
