# 参考站对照与下一步（wowclassicforever.info）

调研日期：2026-10-07。方法：真实浏览器抓全站链接（39 个板块）+ 逐页取标题结构与条目数。
结论先行：**值得抄的是它的三个结构，不是它的内容。** 内容我们仍然只能自己采。

---

## 一、已采纳的三个结构

**1. 每篇内容页固定带「还没确认的」+「来源」两段。** 参考站每个页面末尾都有 `Still unconfirmed` 与 `Sources`。我们已落地：天赋页、副本详情、系统页都会自动列出本页哪些字段是空的、为什么空（缺官方来源还是没实测），来源逐条可点。这比单独一个溯源页更能建立信任。

**2. 职业技能按「新增 / 改动 / 删除 / 未变」四态组织。** 它把每个职业的技能拆成 New / Changed / Gone / Unchanged 四类，25 行表格。这正好是我们 PRD 里"与原版 60 差异清单"的正确形态——之前我们只想到"记一张差异表"，没想清楚按状态分组才是玩家能用的形式。**建议照做，但需要实测数据才能填。**

**3. 公开方法论页。** 它有 `/beta-datamine/methodology`，写清用了哪两个客户端、什么算"新"、怎么分组、以及"客户端测不出什么"。我们对应的是 `溯源` 页，但目前只写了来源清单，**缺方法说明**，建议补一页。

## 三、本轮已顺手补进数据的东西

- **3 座团队副本**：The Barrow Deeps、Hyjal Summit、Onyxia's Lair。参考站口径，标 L2/L3 线索，官方未证实；BOSS 数与开放时间留空。原"团本名单三源矛盾"这条待办已关闭。
- **天裔英文名 = Skyborne**，子族 High Order / Windshaper 与官方中文稿的「高阶会 / 塑风者」对上了。
- **第 4 个新区域 Shen'dralas = 申多雷**（官方中文稿有这个词），此前我们只知道 3 个区域。
- 站点新增 `系统与新区域` 页（15 张卡片，分规则/区域/种族/装备名四组），数据由基底导出。

## 四、建议的下一批（按性价比排）

1. **职业选择问答**（对应 `/choose-class`）：纯前端逻辑，不依赖任何未核实数据就能做，是拉新和分享卡的最佳载体。工作量小。
2. **技能四态表**（对应 `/classes/{c}/abilities`）：先把结构与"未确认"标注搭好，数据等实测或官方稿。这是玩家真正会反复看的页面。
3. **专业页**（对应 `/professions`）：官方无限稿里已有露营与专业相关描述，能采到一部分真内容；开荒期"练什么专业、配方在哪"是刚需。
4. **方法论页**：把"我们怎么拿到数据、哪些刻意没拿、错了怎么办"写成一页，和溯源页配套。
5. **传承系统规划器**：差异化最强，但需要官方公开 Legacy 点数来源与挑战清单，目前只有名词，先等。

## 五、明确不做的（避免以后被加回来）

DPS 天梯与任何排行、宏与循环提示、需要玩家账号或角色数据的功能、新闻流、评论与投稿、抢名字提醒。理由同 PRD：官方对辅助与评分类工具态度明确，我们只做静态资料与本地工具。

## 六、2026-10-08 按 zh-hans 版复核后已落地的三项

用真实浏览器重看了 `wowclassicforever.info/zh-hans/`（35 个板块），结论修正为：**它强在内容编排与逐页来源披露，不是数据更全**——领主大厅页 0 个物品链接、无掉落表；技能页有 21 条"改动"但说明文案有未翻译残留；图标热链 Wowhead CDN（`wow.zamimg.com`），我们不改成本地就不碰。

本轮据此做了三件事：

| 项 | 状态 | 落地位置 |
| --- | --- | --- |
| 逐条来源展示 | **已做** | 术语速查、技能书、天赋页各加"来源"展开（`.srcbox` / `button.info`），PRD 那条"2 次点击内看到来源"现在成立 |
| 上线时间表单页 | **已做** | `src/timeline.html` + `src/data/timeline.json`，11 个时间点全部带官方原文引用；**官方英文 11/4 15:00 PST 与国服 11/5 两个口径并存**，本站按 16 小时时差换算标 L2 推断，不替玩家选一个 |
| 技能四态表 | **已做（真数据）** | `src/data/abilities.json` 38 条 + 技能书页「与经典旧世的差异（四态）」。由 `tools/extract-abilities.py` 从国服职业深度解析稿按小标题分段整句抓取（新增 28 / 改动 5 / 改名 3 / 移除 1），12 条带层级线索、8 条带里程碑点数；**"未变"官方不写，页面明写"未统计"** |

四态表附带挖到的线索：官方稿里出现"从第1层下移至第2层""第1层新增天赋""新增第16点关键天赋""里程碑在 11/16/21/31 点"等表述，共 12 条带层级信息——这是 `rules.tierUnlockCost` 目前唯一有官方文字支撑的线索，但仍不足以填出完整门槛表（我们的树是 7 行，官方只零散提到第 1/2/4/5/6/7 层的移动），**不填，继续留 null**。

明确不参考的：`tier-list`（强度榜）、`bis`（毕业装备）、`macros`（宏）、热链图床、它自翻的技能说明文案。
