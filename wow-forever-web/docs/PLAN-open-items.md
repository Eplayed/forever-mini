## 三、决定永远不做（写在这里，免得每轮重新讨论）

- **强度排行 / DPS / 胜率**：没有战斗数据，个人主体类目也不允许；网页只放"资料完整度排行"，且写明是本站整理。
- **宏、循环、打法攻略正文**：属攻略性质，红线不搬别人的判断。
- **掉落百分比**：上游只给"谁掉什么"，官方说过无限服重做过掉落。
- **角色查询、战斗日志、需要登录的能力、web-view**：类目与合规都不允许。
- **新闻流、评论区、投稿**：零 UGC，不做内容 feed。
- **热链第三方图片**：素材一律本地留存；参考站的图不搬。
- **小程序侧的动态流与排行**：个人主体 + `工具-信息查询` 不做，只在网页有。
