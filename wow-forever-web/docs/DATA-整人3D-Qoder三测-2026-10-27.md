本轮角色：wow-data。输入为 [第二包独立复核](DATA-整人3D-Windows交付初审-2026-10-27.md#五第二包复核本地人物已通旧-db2-行数结论撤回)。状态：**已定（样本与停手线）／待实测（胸甲外观与 GLB）**。

把下面整段交给 Windows Qoder：

> 继续 Forever 客户端 1.60.1.70532 的**最小本地诊断**。输入是上轮 `run-20261027-120705.zip`、原工具和实验副本；安装根为 `C:\GAME\World of Warcraft`，产品必须是本地 `wowf`，不要指向 Classic/Retail。原胸甲 A=1488 因 `ItemSparse` 缺行已取消。新 A/B 仅用 **2870（亮银胸甲）与 250518**：上一轮原始 IMA 显示两者都是胸槽，分别通向外观 64064/120468、IDI 9695/712824；IDI 是 copy table 的复制 ID。此链仅是数据可解析证据，仍要实际穿戴验证。
>
> 固定同一位**人类男性**、同一肤色/脸/发/姿势/镜头与灯光，除 Chest 外其余装备槽全保持空白。先分别在 Chest 选择器按 ID 搜 2870 和 250518，确认精确物品 ID（不可用立刻停并交日志）。分别点击穿上，记录界面是否显示该 ID、是否实际改变胸部像素、是否出现缺本地文件、远端回退或崩溃。两状态同角度各留正面和背面截图；保存 A/B 配置与截图命名对应表。不要以搜索结果截图冒充穿戴结果。
>
> **只在两件均能在本地 70532 完整渲染，且胸部外观肉眼不同、其他设置相同的前提下**，各导出一份 GLB。把 GLB 在与 wow.export 独立的离线查看器打开，同角度正背截图；记录是否带材质、身体贴图、头发与必要 geoset。若某件引发 `Local data file ... not cached, falling back to CDN`，先保存**该次完整原始日志与屏幕截图**并停手；可在工具临时副本里做单独的“禁止远端回退”诊断来列缺件，但不可用 `wowf/1.60.1.70630` 远端字节拼成“纯本地 70532”的通过结果，不要编辑客户端文件。上轮 12:25 的回退原文只留在 README 摘录，这次要确保崩溃前后日志原件写到结果包。
>
> 结果目录放在 `C:\GAME\World of Warcraft\ziliao-export\character-probe-2026-10-27\` 的新 `run-*` 子目录。交 `README.md`（每步时间/首个失败/结论）、`RESULT.json`（机器可读状态）、两件逐跳 ID 表、工具原始完整日志、精确工具临时补丁与前后 SHA-256、正背截图、若成功才有的 2 个 GLB 及其离线查看器截图。`RESULT.json.files` 对除自身外逐文件写字节数与 SHA-256；打 ZIP 后 testzip，ZIP 外另写 `PACKAGE-*.txt` 记录大小与 SHA-256。明确写 `A/B_NOT_TESTED`、`PARTIAL` 或 `PASS`，不要把“人物能显示”当成“穿装备导出通过”。
